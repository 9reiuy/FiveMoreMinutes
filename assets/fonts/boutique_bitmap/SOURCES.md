# Boutique Bitmap / 精品点阵体

游戏 UI 与交互文字使用 9x9 Bold 1.9；9x9 Regular 1.9 和 7x7 1.7 保留为可选字体。
二进制来自用户提供的 Enter-The-Nyangeon-main/fonts，字形未修改。
本次不调整 UI 布局或字号，保留 Fusion Pixel 旧资源。
