## Important Mode Rules

- **剧情模式**：老虎机不出现武器本体；武器通过卧室 Dream Browser 切换已解锁项；解锁来源 = 天数（霰弹）/ 迟到（光束）/ 旷工（太刀）/ 结局（榴弹）。
- **无尽模式（Endless）**：进入前 Weapon Selection 全武器解锁；老虎机可出现已解锁武器条目；结果不计入剧情存档。
- **数值成长**：敌人 HP/伤害随梦境时间线性成长；玩家基础数值只由卡片升级决定。
- **版本标识**：UI 显示 `V0.4.7`（大写习惯保留），Git Tag / GitHub Release 统一 `v0.4.7`。
