# 夜潮海岸：在 Godot 中编辑

打开 `res://scenes/preview/night_coast.tscn`，切到 **3D**。本场景已经保存了 420 个子节点，进入运行前即可选取、移动、旋转和保存；脚本启动时不会再重建这些物件。若原来的空场景页仍开着，请重新加载磁盘版本。

选中场景树里的节点后按 **F** 聚焦。远处风机、月亮离出生点很远，适合从场景树定位。日常布置不必运行游戏。

| 要调整的内容 | 场景树位置 | 使用方法 |
| --- | --- | --- |
| 岸边礁石、十字消波块 | `WaveBreakers` | 移动整个物件；子节点 `GreyOutline` 是描边，随父节点移动。复制完整物件会保留它的水流障碍半径。 |
| 山坡装饰 | `DuneDressing` | 移动物件后，启动时从当前位置读取行走碰撞范围。半径在元数据 `walk_obstacle_radius` 中。 |
| 单座水中吊塔 | `WaveBreakers/TowerCrane` | 保留最新保存的摆放与朝向。移动整个节点，或展开 `Mast`、`LongJib`、`Cables`、`Cabin`、`Hook` 编辑组件；灰描边随父组件移动。 |
| 左右风机 | `OffshoreAtmosphere/Turbine_*` | 移动、旋转、缩放整部风机；`Rotor` 的初始旋转会叠加到运行时旋转上。转速在其元数据 `angular_speed` 中，单位弧度/秒。 |
| 雾带 | `OffshoreAtmosphere/SeaFog_*` | 调整位置、网格尺寸及材质；共享材质会一起变化，需要独立效果时先设为唯一资源。 |
| 海平线远灯 | `OffshoreAtmosphere/SoftHorizonSignal_*` | 移动点、线光斑，调整 QuadMesh 尺寸。材质的 `long_signal` 区分点与长串。亮度仍由轻微连续变化驱动。 |
| 月亮 | `WorldMoon` | 调整世界位置，运行时天空会按真实 Camera 投影它，云和月光随之计算。 |
| 月光 | `MoonLight` | 调整颜色、能量、阴影；保存的能量作为晴朗时的基准，云量会降低它。方向跟随 `WorldMoon`。 |
| 环境光 | `CoastEnvironment` | 编辑 Environment 资源中的环境颜色和亮度。 |
| 初始镜头 | `CoastCamera` | FOV、平移和旋转调整会在运行时保留；跟随镜头会继续应用这个构图偏移。 |
| 跟随镜头过程 | `CameraRig/HighOffset`、`LowOffset`、`SeaLookTarget` | 前两者是相对角色的高/低机位偏移，后者是海面观察目标。根节点关闭 `Follow Player Camera` 后可以使用完全静止的 `CoastCamera`。 |
| 玩家出生点 | `PlayerSpawn` | 移动标记，运行时会把角色放到该位置对应的地形表面。角色节点 `Player` 的位置由行走控制器管理。 |
| 行走美术 | `WalkerCapture/CoastWalker` | 原角色贴图的头、衣服、双脚、双手组合，经过透明视口显示到 `Player`。行走按实际移动距离驱动，停步回到站姿，暂停时冻结。编辑器内 `Player` 仍使用原静态预览。 |
| 地形、海水和材质 | `SandRidge`、`Water`、`FarWater` | 网格及材质均为保存的外部资源，可在检查器中查看。修改共享资源会影响引用它的物件；要单独修改时设为唯一资源，并保存资源。 |

**保存与试玩**：Ctrl+S 保存 `night_coast.tscn`。运行 `night_coast_display.tscn` 或双击 `tools/run_night_coast.cmd`，即可用原有 640×360 像素显示、鼠标映射和完整动态效果试玩。`night_coast_display` 是显示外壳，布置工作在 `night_coast` 内进行。运行中的“远程”节点修改仍只对当次运行有效。

**地形边界**：目前地形是保存的规则高度网格，不包含雕刻笔刷。角色与流动网格已经直接读取其三角面高度，平移、高度与水平缩放可被读取；请保持地形直立、保留现有网格拓扑。海岸轮廓与可走路线仍有独立的参数规则，替换整个地形造型时需要同步调整这些规则，不能只换一个任意模型就获得新的海岸。

**海浪范围**：24×20 米细网格保留近岸注水、染色和障碍绕流；另有 240×210 米连续的粗网格覆盖当前游戏 Camera 中的前方及左右中近景，根节点 `Near Surf Origin` 可调整它的世界原点。可见白浪来自水面挤压与曲率产生的泡沫，按局部流速输运并消退；近海粗网格以 15Hz 更新，实际内部步长受 CFL 条件约束。它没有分成几个可见矩形区域，远处白浪随距离逐渐减弱。`Water`/`FarWater` 材质的 `whitecap_strength` 控制显示强度；浪头数量随运动和消退变化。远海仍使用低强度的海浪着色表现。

海浪、云、风机旋转、角色移动和灯光变化仍在运行时播放。编辑器中看到的是保存的静态状态，动态观感以试玩 Camera 为准。
