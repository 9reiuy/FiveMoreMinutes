# 像素敌人布偶倒地与接触推动

## 已接入的行为

保留敌人既有头、身体、双手、双脚 Sprite2D 和正式 3D 显示桥，不替换美术为三维人形。致命受击仍沿原击退与落地流程执行；落地后关节旋转改为阻尼自由衰减，保留实际摊开姿态，不再用弹簧拉回站立角度。平移保持解剖连接锚点及小范围约束，旋转分别限制头、手、脚与躯干。全部关节速度与身体转速衰减后停止布偶计算。

新增敌人子节点 `CorpseContact`，无碰撞层、不作为伤害区域、不阻挡玩家。检测玩家与家具碰撞层；只接受当前玩家的走动及同时具有 `damageable_props` / `pushable_prop` 标记的移动家具，包含旋转家具的表面速度。静止或远离的玩家不施加推动。掉落武器、敌人和子弹不能调用此接触路径。停稳后的接触重新唤醒四肢与身体运动，不延长尸体生命。

尸体地面移动采用 7px 圆形连续扫掠，墙、门扇、家具阻挡，正式整层有效地板判定限制地图边界。角色自身不重新启用碰撞/受伤层；玩家能走过。现有地面像素接触校正继续随旋转更新。尸体所属接触区随敌人一起暂存、回滚或清理。

血迹颜色、扩散、尸体跟随出血、武器掉落、断肢概率、伤害和约 15s 尸体消失时间没有修改。旧 2D 关卡不恢复。此实现是受约束的像素部件布偶，不是换用 Skeleton3D / 三维人体刚体。

## 正式摄像机证据

RTX 5070 Ti / Compatibility，1280×720。正式随机楼层、种子 42001；脚本控制动作序列，正式接触区检测真实玩家重叠，非直接调用推动函数。玩家接触阶段尸体实际移动约 91.72 游戏单位。倒地、受推与停稳画面的可见像素底部距地面约 0.012 世界单位。截图已查看，没有发现本序列中穿地；不能据此声称全部家具、全部关卡的人工验收或性能目标已完成。
