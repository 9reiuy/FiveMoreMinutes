# 玩家默认空手双拳

空手继续使用玩家原图的双拳切片 `37,16,5,4` / `52,16,5,4`，没有重绘用户图集或新增可见几何。原逻辑已经按空武器 ID 显示双手；本轮将其明确为抬高 3 个源像素的默认双拳姿态，出拳位移仍叠加在该姿态上。握持武器时恢复原位置并隐藏空手双拳。

空手显示每次角色姿态刷新时同步，禁攻只关闭攻击，不隐藏拳头；移除禁攻刷新对 `dream_world` 必须为 Node3D 的依赖。回血层和被动 3D 捕获使用同一双拳位置与可见状态。接待区、随机楼层、独立轿厢共用玩家脚本。没有改初始武器配置、拳击数值、判定范围或电梯禁攻规则。
