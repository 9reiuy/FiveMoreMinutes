## 原始证据与纠错

原工具 `find_fd_callers.py:36` 从每个符号地址固定反汇编 8000 字节，没有在函数结束处停止。短函数后的其他对象事件因此会被记成该函数的调用。本次按 PE `.pdata` 的函数范围读取；对于编译器拆开的连续范围，只追踪显式分支和正常延续，并以随后注册的 GML 符号限制边界。无 unwind 范围的单字节 RET 单独识别，无法识别者保留为未知。

| 原报告中的证据 | 按真实边界核对 | 结论 |
|---|---|---|
| `scr_on_headburst` 调用流体 create/update/shift | 实际函数 1769 字节，仅发现 GML `instance_create`；没有这些直接调用 | 旧调用证据来自后续函数 |
| `objPartSELowerArm1` Create/Step 持续建立流体场 | Create 165 字节、Step 100 字节；均没有流体库直接调用 | 不能据此声称断臂使用独立流体场；对象继承 `con_ragdoll_parent` |
| `objFluid` Step 与 Draw 都更新流体 | Step 321 字节没有 fd 直接调用；Draw 6314 字节有 pressure/update/draw | 流体库确实存在，但旧报告把 Draw 的调用错算进 Step |
| 血滴、血泊、喷溅、涂抹均参与流体 | 对应已恢复事件内没有 fd 直接调用 | 明确存在独立精灵效果层，不能把库存在等同于普通血液使用它 |

全表按边界扫描发现 8 个非 fd 库的直接调用者，包括 `objFluid` Create/Draw，以及若干旧子弹、追踪球、SlashProjectile、TestSmoker 的事件。库具体在何种运行路径中使用、各次调用注入哪种物质，仍需追踪参数和运行期观察。静态“未见直接调用”不能排除脚本间接调用或动态分发，也不能单凭名称认定全部属于血液或黏液。

## 当前项目已经具备什么

已从当前代码与实际 Camera 图像核对：现有血液是橙色。`BlackBloodEffect` 负责飞溅、地面像素、墙门血迹与逐格血泊增长；`CorpseBloodEmitter` 负责落地后跟随渗血，按游戏时间减弱。地面血迹按空间索引局部合并，单块最多 8192 格，落定后停止处理，增长捕获最多 30Hz。

`BloodGroundCapturePool` 已经复用 128×128 与 224×224 的被动捕获载体，不能把“新增对象池”当作尚未实现的收益。落定冻结、复用载体、避免重复像素拷贝也已经存在。当前 `_draw()` 仍会逐个像素格发出绘制命令，增长和合并后仍需构建/刷新捕获，这些才是值得继续实测的候选成本。

本轮性能工作已做逐滴射线 query 对象复用，49 项回归通过；复用的仅是参数对象，每次位置、mask 与真实相交查询仍然更新。没有改变血量、颜色或碰撞。

## 优化与类似效果的具体路线

1. **优先验证等价绘制压缩。** 对固定 1px 地面格缓存同一行连续区间，用较少矩形覆盖完全相同的像素。只在内容版本变化时更新区间。必须处理重复格、增长边缘、边界裁切、透明度与绘制顺序；最终以原路径→原路径→候选→恢复的实际 Camera 像素对照验证。预计减少 Canvas 绘制命令，但没有实测前不能承诺整场帧率提升。
2. **随后评估静态地面分块合并。** 若实测表明大量血迹载体/视口仍是瓶颈，可将已落定的地面血合并到局部纹理块，只更新脏块。保留原模拟、地面可达性、真实深度遮挡和换层回滚。墙血和随门转动的血迹保持独立载体。这比单纯换粒子系统复杂，需要验证内存、房间遮挡、像素边界和生命周期。
3. **相似观感需单独确认表现变更。** 采用自有的不规则血泊轮廓、方向性涂抹、密集命中核心和外围细滴；保持当前橙色与最近邻颗粒。当前喷溅/血泊/渗血链路可继续使用，无须替换为完整流体库。轮廓、血量、尺寸、增长时长改变均属于表现调整，尚未授权实现。
4. **完整流体求解器列为独立选项。** 当前证据既不能证明普通血液必须使用它，也没有运行期分辨率/迭代次数。若未来明确要血绕障碍流动，应单独评估 GPU 多次 pass、空间范围和中档设备预算，不能作为本轮 60 FPS 优化的默认路线。

优化验收应分别记录命中爆发、多人同时死亡、血泊增长、落定堆积和跨层恢复的 CPU、捕获更新数、绘制调用、内存及最坏帧；再用正式交火检验全局帧耗时。局部生成变快不等于正式游戏达到 60 FPS。

调查后用户已授权调整喷溅、涂抹与血泊观感，并允许血泊大小和增长节奏变化。现已基于原系统实施自有形态与尸体拖痕，未导入参考精灵；见 [实施与验证记录](reports/otxo-blood-implementation-20261013.md)。
