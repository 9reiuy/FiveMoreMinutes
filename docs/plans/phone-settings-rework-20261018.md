## 已确认的制作与验收方式

先制作一套可操作小样，展示实际游戏视口中的机身造型、提起与开合、页面返回、六项设置、聊天与购物中文排版。交付正常速度动图和清晰截图；用户认可外观后，接入全部正式入口并完成回归。

小样及最终实现检查：

- 主菜单、卧室、正式大厅、正式楼层的真实入口；独立楼层预览沿用同一个暂停界面。
- 鼠标与键盘操作、实体方向键与软键、选中反馈、滑杆步进和拖拽、返回焦点恢复；输入不穿透到射击、移动或卧室物体。
- 小屏中文不溢出、不被铰链或外壳遮挡；聊天和商品可滚到底，末项可读、可选。
- 六项设置修改、实时预览、保存、重开及重启后读取；旧配置迁移保持正常。
- 单手机实例与 Esc 优先级，连续开合及页面切换不叠加；暂停时 UI 动画可运行，关闭只释放自身暂停原因。
- 卧室时间、未读消息、购物扣款、外卖到达自动收起及交互恢复维持原规则。
- 继续游戏、返回主菜单、转场与销毁保持现有状态恢复链路；全部正式入口不遗留旧设置面板。
- 游戏窗口保持后台最小化，使用实际 GPU Camera 截图与正常速度动图交付，记录录制条件及相关回归结果。
