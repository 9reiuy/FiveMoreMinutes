## 先定位，再修改

1. **区分原生画面与显示缩放。** 对照 640×360 原始主 Camera、320×180 镜像、游戏实际输出及 1:1／整数倍查看。若干涉只发生在报告缩放或窗口非整数缩放，说明证据，不修改材质掩盖显示问题。先复现静止、慢走、横向和斜向移动、停下及换向时的纹理。
2. **拆分摩尔纹来源。** 分别检查重复纹理缩小采样、世界空间规则抖动、细密法线／高光、反射采样与输出缩放、重叠面深度冲突。单因素临时诊断可以关闭一个分量，但最终画面需恢复完整内容。旧战斗彩色条带尚未稳定定位，不能直接等同于摩尔纹，或因修复一种就关闭另一缺陷。
3. **已发现的源码线索，仅是待验证假设。** R1 `sample_floor_texture_review.gd` 在第 57／67 行附近将 `filter_nearest_mipmap` 替换为 `filter_nearest`，地板 PNG 的 ImageTexture 路径明确不生成 mipmaps。当前 `office_dither_lighting.gdshaderinc` 的实际 `office_dither_response()` 仅返回连续的 clamp；文件中的 Bayer 函数定义和 `office_dither_enabled=true` 不证明规则抖动仍参与渲染。检查真实绑定、未带 mip 的纹理、反射着色器 `floor(world.xz*32)` 微表面／高次幂 glint 及量化 UV 导数。若试 mip，核对层级数据、图集边缘及法线正规化，不能仅据代码命名宣布根因。
4. **对齐 A 的局部明暗。** 保留原灯位与照射／遮挡关系，先查 B 的颜色转换和光照响应。每组固定至少一对同材质亮面／阴面区域，报告 A、B0、B1 的中位亮度与亮暗差，并实看光斑位置、边界、人物和家具可读性。数值只辅助判断，不用全图平均数或压黑暗部制造对比；不恢复 R1 已修复的重复亮度压缩和零贡献灯改变亮度问题。
5. **采用局部、低成本修正。** 有证据时优先试验环境纹理的合适 mip 层级／局部采样，或程序纹理随像素覆盖率的平滑过滤。保留近景像素结构、人物轮廓、红线及文字的清晰度。Nearest 是原风格原则；用户消除摩尔纹的明确要求允许对确认为问题来源的环境采样做最小适配，但不等于全局改模糊。不要默认开启全屏 TAA／FXAA、提高整体渲染分辨率或增加镜像成本来掩盖问题；若认为必须，需要先提供实际局部对照和代价。
