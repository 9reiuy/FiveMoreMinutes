# 第一章流程修订（2026-10-30）

本页依据用户最新明确选择，覆盖早期任务书中的卧室及红海顺序。

**正式流程：新游戏 → 连廊教程 → 卧室立绘 → 睡觉 → 前台占卜 → 两层战斗 → 休息构筑 → Boss → 返程电梯 → 俯视卧室 → 床边 F → 红海摩斯密码 → 结束一天 → 卧室立绘。**

- `scenes/bedroom/bedroom.tscn` 为日常立绘卧室，保留电脑、药瓶、手机与睡觉交互。它不是已退役的旧 2D Dream 关卡。
- `scenes/story/chapter_bedroom.tscn` 是 Boss 后可行走的俯视卧室；床上保留另一个自己，靠近床边 F 才进入红海。
- 床边 F 只提交 `WAKE → COAST`，不推进日历；观察信号后 E 离开红海，才提交章节完成与一天结算。同一事件不能重复提交。
- 红海退出后无需再回俯视卧室按第二次 F。
- 新档 `flow_revision=2`。旧教程、战斗、Boss 返房检查点迁入新版；旧档若已看完红海、正在等待最后一次 F，则就地完成，避免重播或丢失待结算天数。
- 教程采用共同连廊连接登记、冲刺、实弹三个房间。房间门及连廊检查门按课程完成状态逐段解锁；校准结束后通道终点离开设施，接入立绘卧室。
- 舱门是原创钢质分层结构，具有内嵌面板、加强肋、锁柄、门槛和状态灯；视觉动画与权威 2D 门碰撞同步。

验收以正式 Main 入口的运行画面与自动化路线为准；导航测试明确区分真实走动和用于战斗测试的导航定位，不把自动化驱动称为人工通关。
