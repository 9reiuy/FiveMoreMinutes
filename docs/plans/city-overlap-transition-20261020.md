# 外围高楼遮挡过渡

用户明确纠正：外围楼正常显示，仅在遮挡本楼层视野的重叠部分过渡裁开。不能向外溶解并在楼层外围留一圈碎洞，不能整栋淡出。

在现有城市材质中替换邻楼的二值重叠裁切：预计算从非外部格到外部的内部距离，外部始终完整，内部约 1.5 格宽过渡到完全隐藏。使用稳定像素覆盖而非每帧随机噪声，沿用既有深度缓冲。自身建筑立面保留原遮罩。移除前次加入的角色周围挖洞保护。

保持城市模型、窗光、夜景、房间墙体、柜体及游戏碰撞不变。以同一帧旧硬切／新过渡的实际 GPU 对照、正式入口走动及手机镜头检查为依据；预计算字段做外部完全为零、内部单调、转角与封闭孔验证。修复前次向外渐隐属于本轮纠偏，不待新一轮访谈。
