# 玩家近战宽扇形与像素挥击 — 已确认方案

用户逐项确认 Q1–Q9，并明确“开始执行”。按用户此前要求单智能体实施。

- 仅玩家手持近战：球棍 56px/160°、书本 44px/150°；原地格 32px。
- 连续扫过多个目标，每次挥击每个目标最多命中一次。前摇可修正朝向，主挥击锁定。
- 保留正常移动，不增加强制前冲；翻滚、换武器、踢击、翻越、失去攻击权限、死亡或跨层中止旧攻击。
- 实墙、门扇和高柜挡攻击；低家具允许越过，仍可受到原有伤害。
- 角色姿态、世界像素弧和命中读同一物理时钟。球棍厚风压，书本纸页状残影。
- 命中停顿 20–40ms，每挥击合并一次，轻微震屏。伤害、攻击间隔、击退、血色、拳头、踢击、敌人武器数值不变。
- 真实 Main 摄像机检查八方向、移动攻击、像素化/Palette四组合；静音测试；分别报告逻辑、画面和未验证项。

实现：`melee_sweep.gd`提供公共角度计算，`lucille_weapon.gd`掌握唯一攻击时钟；`melee_sweep_visual_3d.gd`只显示，所属节点为可清理的 `floor_root`。不增加角色捕获视口，也不扩大其每帧纹理。3D弧面固定1游戏像素栅格、深度测试、无阴影，以真实2D碰撞射线裁去墙后的部分。
