# 材质反光与模糊倒影正式接入

用户已认可加强亮斑和细碎光泽的第二版小样，并明确授权“继续推广并验证性能”。本轮将同一套已确认的材质响应应用于所有正式楼层和塔罗入口大厅。

保持各房间原始地板纹理、局部配色、灯光能量、夜景环境、角色与玩法。瓷砖／大理石较强，水磨石更弱更碎，木地板很淡，地毯不加高光或可辨认倒影。大厅使用原有接待区大理石材质。不开新渲染器，不复制角色、碰撞或 AI。

复用单个共享 World3D 的 256×144 反射视口、最高 15Hz；按真实材质身份绑定，每种同源材质只更新一次反射矩阵。动态角色、家具和灯光通过新增节点队列接入，不在战斗中反复遍历全楼层。反射按实际经过时间限频，避免游戏慢速时间拖慢倒影更新。

保留墙、门及家具的实际材质引用，反射通道着色器保持其原有实时裁切与遮挡参数。正式清理、换层暂存和失败回滚均显式恢复旧资源，再接入当前楼层。游戏的像素显示视口重挂接不属于场景销毁。

验收包括四种骨架的真实纹理和生命周期检查、正式 Main 大厅／楼层截图和正常速度动图、原遮挡／血迹／暂停回归，以及现有四类 60 秒交火与十分钟／三次换层测试。性能预算失败如实保留，中档实机继续待验收。不会把短样本关闭／开启对照外推为持续交火性能，也不会把功能断言通过称为稳定 60 FPS 通过。
