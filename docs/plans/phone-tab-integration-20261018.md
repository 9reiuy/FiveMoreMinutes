# 游戏内 Tab 手机：已对齐实施方案

日期：2026-10-18。Q1–Q13 已确认，用户已明确启动实现。此文件替代旧计划中“主菜单及 Esc 暂停界面统一换手机”的范围，保留已有银白实体机身及环境桥作为基础。实现与验收见 `docs/reports/phone-tab-integration-20261018.md`。

## 用户确认的行为

1. 塔罗大厅、所有正式楼层、卧室按 Tab 打开同一部左侧手机；卧室原手机入口保留并调用同一界面。开始界面继续使用原设置，不接入手机。
2. 正式 3D 场景打开手机时暂停战斗和游戏计时；手机与镜头动画仍更新。卧室沿用日常手机不暂停卧室时间及配送的现有规则。
3. 再按 Tab 直接收起。手机内右键／Esc 逐级返回，主页返回关闭。手机关闭时 Esc 仍打开原暂停菜单，保留其继续、设置及返回主菜单功能。
4. Tab 不再打开角色属性卡。本轮不给属性卡新增 C 键或手机入口，保留原组件，避免删除无关功能实现。
5. 手机首页为固定 2×2：上排“讯息／电话”、下排“音乐／购物”；下方左软键“设置”，右软键“返回”。方向导航到边缘停止，不循环。
6. 鼠标实际移动并悬停时更新区域高亮，左键确认／拖动；键盘和鼠标共用选中状态。悬停不反复按实体键，也不因静止鼠标被手机轻摆带动而抢走键盘焦点。
7. WASD／方向键操作；E／Enter／左键确认；Q 对应当前左软键，首页为设置，内页按当前提示执行；右键／Esc 对应返回。屏内软键和实体按键均可点击。
8. WASD／方向键让圆盘向对应方向倾斜并下压，按住保持、松开回弹；确认对应中心钮，返回对应返回键，左软键对应左实体键；滑杆左右调节对应圆盘方向。所有输入走统一动作与反馈入口，避免执行两次或同时误触其他按钮。
9. 手机随鼠标位置轻微转动，最大约 2°，带缓动。拖滑杆、滚动聊天、按住实体键时冻结角度，松开后恢复。姿态轻摆与开合使用独立变换，动态投影继续匹配点击位置。
10. 正式大厅／楼层打开时约 0.4 秒拉近角色约 1.4 倍，把角色安排在画面偏右，留出左侧手机。关闭后平滑恢复原镜头。暂时沿用现有角色美术，只接入镜头与机身动画。卧室保持原固定画布构图，仅播放手机开合。
11. UI 改为浅蓝灰简单几何壁纸，顶部左侧为当前页面名，右侧为时间／电量；内页浅底深字、冷蓝高亮。使用工程已有 12px 中文像素字体，调整行高与边距，适当扩大 LCD 可见面积并减弱固定透视。顶部摄像头与数字区允许出画，LCD 和七个操作键保持可读可点。
12. 讯息复用真实消息、未读及已读状态；电话为明确的暂无通话页面；音乐控制当前 BGM 播放／暂停和音量，不增加独立播放器、曲库或通话剧情。3D 购物可浏览，购买提示回卧室；卧室继续使用原余额、库存、购买与配送权威。

## 复用与边界

- 设置保留现有总音量／音乐／音效、像素化、配色滤镜、阴影质量，修改立即生效和自动保存。
- 时间／电量复用现有游戏及手机状态，不引入新的耗电或现实时间玩法。现有电量图形由压力值映射，并非真实电池模拟。
- 音乐页通过现有 SFXManager 当前 BGM 通道工作，保留场景切歌与音频所有权；不重复创建背景音乐播放器。
- 提取适合共享的消息／商品展示接口，让 3D 场景读取真实存档；只允许卧室调用现有购买方法，不把隐藏整套卧室场景当新后端，不复制扣款／配送规则。
- 保留银白真实 3D 外壳、实际环境采样与 2D 背景回退，换 UI 不改变其物理来源说明。环境反射仍是低清近似，不承诺世界几何投到手机上的遮挡阴影。
- 手机输入优先于扔武器、射击、移动和旧 Tab 角色卡。完整吞掉按下／松开与相关鼠标事件；关闭后恢复游戏输入，不出现松开瞬间误扔武器或残留移动。
- 对话、转场、换层、死亡等已有模态状态遵守统一入口优先级；不抢占 NPC 对话／电梯焦点。关闭、异常中断和场景退出清除手机自己的暂停原因、镜头修饰与捕获资源，保留其他系统的暂停原因。

## 实现约束与事实

当前 `game_input_actions.gd` 把 Tab 分给 `skill_menu`，右键分给扔武器，均需由统一输入入口处理，不仅修改 UI 的按键判断。

楼层和大厅各自每帧重设 Camera 焦点与 FOV。手机镜头应作为独立修饰纳入既有镜头权威，并在暂停期间只推进必要的镜头／投影展示；不借用 NPC 对话焦点接口，不推进战斗物理，不让手机鼠标触发世界 lookahead。关闭时恢复修饰前镜头与原有对话／换层规则。

旧手机 148×230 源字体为 9px，实际 LCD 投影还缩小约 8–10%。只增大 3D 视口不能修复文字信息；本轮需同时调整字体、页面布局、屏幕投影占比与默认角度，并在 ±2° 轻摆范围检查文字笔画。

## 交付与验收

直接验证实际 Main 的 Tab 正式入口，覆盖大厅、正式楼层和卧室；检查开始界面和原 Esc 暂停入口保持其已确认行为。自动窗口始终后台最小化，无焦点，不占用户主屏。

交付实际游戏 Camera 截图及正常速度动图：四宫格、三种输入混用、圆盘按住／松开、确认与右键返回、Q 与软键、鼠标轻摆和拖动冻结、打开拉近角色与收起恢复、12px 中文内容及长消息滚动、3D 购物只读和卧室实际购买、电话说明页、当前音乐播放／暂停／音量。

回归检查按需覆盖：

- 单手机实例、Tab／Esc 优先级、完整输入吞吐、边缘导航及鼠标／键盘高亮切换。
- 鼠标与动态透视坐标一致，拖动无抖动，松开及移出屏幕后无残留按压／调节状态。
- 暂停与计时、镜头动画、原镜头恢复、对话／换层／场景退出中断、资源与暂停原因清理。
- 消息真实状态、六项设置保存、3D 不能扣款、卧室扣款与配送不变、BGM 音频所有权及操作效果。
- 实际显示的文字完整、菜单区域与七键不被裁切，手机轻摆及镜头变换后仍清晰可点；反射不盖住主要文字。
- 记录渲染与环境采集的开销／初次缓存条件。Headless 不代替实际 GPU 清晰度或反射验收，功能断言通过不等于所有引擎日志干净；分别报告。

按已确认方案及项目要求，分工完成应用／UI、机身输入反馈、正式入口与镜头，由主智能体集成回归与可视化交付。
