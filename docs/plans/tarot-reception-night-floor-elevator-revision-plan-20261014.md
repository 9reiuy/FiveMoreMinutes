# 塔罗大厅夜景、地板与共享电梯门面修正方案

状态：用户已确认并授权实现；2026-10-15 已完成修正与相关回归。实际游戏画面和检查记录见 `docs/reports/tarot-reception-revision-20261015.md`。

## 大厅修正

1. 使用正式楼层接待区最终显示的大理石地板：复用正式美术覆盖层的纹理、材质、接缝尺度及 UV 铺贴规则。上一轮只复用了基础主题材质，没有接入最终覆盖层，需要纠正。
2. 后方办公桌转为朝向其南侧员工座位，按实际模型边界重新安排桌、椅和收纳柜的间距，消除重叠；碰撞尺寸与模型占地核对。
3. 大厅保持完全不受全局配色滤镜影响，切换滤镜不得改变大厅画面；正式楼层仍遵从原有显示设置。
4. 大厅采用正式楼层接待区的夜景亮度基准，撤回上轮过强的整体照明。保留柜台、电梯和壁灯的小范围灯光，以及较暗的空地。

保留已确认的大厅布局、家具组合、常开闸机、左工位唯一 NPC 和现有塔罗流程。

## 电梯门面重做

覆盖大厅三部电梯和正式楼层入口／出口电梯，共用统一外观。采用更深色的门板和更明显的工业结构，包含嵌入门套、编号、状态灯、侧边呼叫面板和门槛。保持项目像素纹理与真实 3D 几何标准。

保留现有门洞尺寸、碰撞、开关动画和进入楼层流程；大厅仍只有 1 号电梯可用，2、3 号关闭。轿厢内部沿用现有模型。
