# 前台被动 NPC 与逐字生长气泡方案

状态：用户确认完整方案并追加气泡缓入缓出后授权实现；2026-10-15 已接入，完成实际 Main 摄像机录制和相关回归。交付见 `docs/reports/passive-npc-dialogue-delivery-20261015.md`。

## 范围

本轮覆盖正式游戏塔罗大厅唯一前台 NPC。复用公共气泡和对话控制器，以可配置方式启用新表现，保留教程向导原有交互流程。区分主动／被动入口：主动靠近后自动开口，被动靠近只显示头顶“…”、按 E 开口。当前前台为被动。

## 交互与阶段

- 沿用现有靠近范围；范围内仅显示 NPC 头顶紧凑的“…”提示，走远后隐藏。开始完整对话时隐藏该提示。
- 按 E 开始连续气泡对话，移除前台的“闭嘴、进行占卜、直接前往电梯、知道了”等选项按钮。
- 保留逐字文字、现有文字音效及进度条。进度条结束自动进入下一段，最后一段结束关闭气泡。
- 对话中的 E 或左键直接跳到下一阶段，不先补完当前段文字；不受旧红色打断窗口限制。开始对话的同一次按键不得同时跳段，一个按键只推进一段。
- Esc 或走远可结束当前对话。对话结束、取消或跳段不记作已抽牌，玩家可以正常前往电梯。
- 本轮仅展示对话，不进入三张塔罗牌界面；不删除原有卡牌系统或重写已保存的卡牌结果。

## 气泡与角标

- 保持当前字号、深灰像素外观和最近邻采样，缩小内边距。
- 从约 48×26 紧凑尺寸开始，按已经出现的文字向两侧扩宽；达到约 220 像素宽后换行，随新增行增高。尺寸按 640×360 游戏界面计，以实际 Camera 微调。
- 使用短动画平滑扩展，不能在首字出现前按整句撑开；阶段切换采用短过渡，再按该段已出现内容增长。
- 气泡显示、退出和尺寸扩展使用缓入缓出过渡。
- 角标尖端持续指向当前说话人的头顶附近，留少量间距而不遮脸；框体增长、镜头移动、边缘限制导致框体偏移时，角标方向和长度同步调整。
- NPC 说话跟随 NPC，玩家说话跟随玩家。角标不得错误跟随鼠标或固定在框底中央。

## 已确认台词

1. 电、电梯在左边……通往办公楼……今晚也请小心。
2. 只要撑到发奖金就好了……他们都这么说。可上去的人……怎么越来越少了……
3. 我、我没在数！只是名字要记好……万一奖金算漏了，我就真的……真的……
4. 啊？！我刚刚说出声了吗？！对不起！您没听见，对吧？对、对吧……？
5. 祝您今晚工作顺利！您一定会回来的……我、我在这里等……不！不是催您回来！

语气：神经质、社交恐惧、随时崩溃但努力维持礼貌；由畏缩引导转入碎念，泄露心里话后慌张补救。五段均为 NPC 发言。

## 验收与交付

实际 Main 入口检查：靠近不自动开口、离开提示隐藏、E 开始且不跳过首段；自动推进、E／左键跳段、Esc／离开结束；无选项按钮、无抽牌自动入口，电梯通行及进入楼层正常。

检查短文本、换行、阶段切换与连续按键；验证增长尺寸单调、文字不被裁切、进度条跟随尺寸、教程原模式兼容。检查镜头移动及屏幕边缘时角标尖端与说话人头部的关系。

交付实际游戏 Camera 的“…”提示、首字、扩宽、换行与完整文本截图，以及逐字增长／跳段／角标跟随动图和相关回归结果。GPU 窗口继续屏幕外启动并立即最小化；主智能体独立执行，不使用子智能体。
