# 全屏场景与电梯转场优化

用户已确认范围和完整方案并授权实施。覆盖菜单、卧室、塔罗大厅、进入正式游戏及电梯换层；房间之间过门保持原状。

采用约 4×4 游戏像素的小块深色溶解，640×360 为逻辑像素基准，轻微错落推进，无高亮闪边。普通切换先按遮黑 .25 秒、揭幕 .30 秒；保留加载进度，真实准备就绪后揭幕。电梯保留真实加载及至少 3 秒可移动轿厢，到站保留门动画。动画与黑屏加载分别计时，不以动画掩饰加载时长。窗口屏幕外运行并最小化，不使用子智能体。

实现复用一个小块 Shader 和一个无节点、可取消的动画时钟。公共导演器负责遮盖、就绪和揭幕状态；Main 保留混合场景请求的顺序与加载类型，新场景必须实际提交绘制后出场。加载界面去除固定完成空等，避免旧淡出覆盖新加载。电梯加载采用相同像素遮罩，到站短揭幕与原提示音停顿互换，避免额外增加整段等待。

验收包括：像素块尺寸与完全遮盖的实际 GPU 读回、进度连续和输入恢复、快速连续切换／取消、加载与销毁处理、真实入口、真实换层与强制生成失败回滚，以及前后视觉对照。保持玩法、关卡生成、美术、房间纹理和过门规则。
