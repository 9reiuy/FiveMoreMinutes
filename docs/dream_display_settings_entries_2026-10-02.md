# 3D Dream 显示设置：统一入口

设置中的游戏像素化与滤镜方案 1，现在对正式 Main 流程、直接运行随机楼层、教学层、接待区，以及使用这些世界的独立预览生效。主菜单、卧室不在显式场景白名单中。

新增 DreamDisplayBootstrap：监听显式 3D Dream 场景创建，已有 dream_display 协调器则跳过；否则安装现有单世界视口协调器。所有协调器读取 SettingsManager 保存值并直接监听设置变化，不再依赖 Main 才生效。不会为阴影预览把默认颜色或新阴影效果接入正式楼层。

像素化开启时世界使用现有 640×360 nearest 显示；关闭时恢复输出尺寸渲染。滤镜独立作用于世界视口的 layer 18，地图外黑幕在 layer 19，清晰 UI/交互文字绘于输出画布。不另建全屏 UI 配色滤镜。方案 1 使用现有调色 shader，不新增配色方案。

直接入口已完成生成时，安装过程会迁移世界到视口。迁移期间仅暂停项目的退出清理回调，结束后原样恢复（包括 one-shot）；原生关节退出/进入仍正常执行。门扇和前台碰撞、楼层根节点的退出清理也区分显示迁移与真正离场。真正删除楼层时正常清理显示协调器。修复过程中发现家具错误销毁，已在实际画面与回归中复核恢复。

验证：独立入口与设置四组合共 102 项通过；像素化设置存储回归 PASS。测试不写用户设置，结束恢复内存值。Compatibility 静音运行截图确认像素化/方案 1 与点阵阴影一起显示，家具保留、文字在输出画布。相关差异检查通过。

输出示例：`.runtime/pixel_shadow/mode_2.png`。仍有运行环境证书/缓存权限与资源残留警告；未完成三层完整玩法路线、所有窗口尺寸与长期性能验收。
