# 3D 武器开火节奏调整

按用户确认的参考方案，将 3D Run 的基础开火间隔设为射速倒数，替换此前基础间隔乘 0.8 的方式。

| 武器 | 基础射速 | 基础间隔 | 上一版间隔 |
|---|---:|---:|---:|
| 手枪 | 4.2 发/秒 | 0.238095 秒 | 0.240 秒 |
| 步枪 | 9 发/秒 | 0.111111 秒 | 0.120 秒 |
| 霰弹枪 | 2.4 次齐射/秒 | 0.416667 秒 | 0.640 秒 |

参考来源是用户提供的本地 `OTXO_武器与敌人移速_精确数值.html` 和 `OTXO_武器与敌人移速_逆向补完.html`。报告没有确认武器名称到槽位的对应关系；这组数值是经过用户确认的设计选择，不宣称是 OTXO 三种对应枪械的精确复刻。报告中 0.008 等含义未确认的字段不接入。

玩家与敌人读取相同基础间隔。玩家升级及已有全局射速乘数继续叠加；敌人的攻击前摇、节奏抖动、装填和 AI 规则不改。霰弹枪仍点击释放/蓄力后齐射，不改为长按自动连射。上表是配置基础节奏，不是包含帧量化、输入、蓄力、装填和 AI 前摇后的实机持续每秒发数。

玩家移速 290、敌人基础移速 150、双方弹速 1500、伤害、射程、弹匣、散布、后坐力及 Dash 不改。独立本局配置只初始化一次，换枪和跨层仍使用同一配置。共享源资源不改，旧 2D Dream 不恢复。

静音测试：

- 配置、玩家升级与全局乘数、敌人实际冷却赋值、跨层幂等：103 项通过。
- 换枪、分类切换、拾取、跨层后的武器间隔与实际弹速：180 项通过。
- 门/玻璃与角色扫掠弹道：98 项通过。
- 四骨架正式目标场景运行：264 项通过。
- 相关差异检查通过，测试运行未发现脚本解析错误。环境仍有根证书读取告警。

本轮未进行手动交火手感验收、持续射击动态录制或性能采样；不以参数断言代替这些结果。
