# PicoCAD 2.0 游戏资产建模与导入规范指南

本文档为《5 Minute More》3D 梦境系统提供 **PicoCAD 2.0（或类似低多边形像素建模工具）** 制作家具、墙体及装饰物件的官方建模与导出规范。

---

## 1. 基础单位与坐标换算规范

游戏采用 **2D 物理判定权威 + 3D 视觉投影渲染** 的混合架构。建模时必须严格遵守以下单位与坐标换算关系：

| 维度 | 2D 物理/网格单位 | 3D 场景世界单位 (Godot 3D) | PicoCAD 2.0 对应尺寸 |
| :--- | :--- | :--- | :--- |
| **标准网格单元 (1 Cell)** | **32.0 像素** (`CELL_PIXELS`) | **1.0 米 / 1.0 Unit** | **1.0 网格单位** |
| **坐标映射公式** | $X_{2D} = X_{3D} \times 32.0$ | $X_{3D} = X_{2D} / 32.0$ | $X$ 对应水平左右 |
| **水平深度映射** | $Y_{2D} = Z_{3D} \times 32.0$ | $Z_{3D} = Y_{2D} / 32.0$ | $Z$ 对应水平前后（$+Z$ 朝南朝镜头） |
| **垂直高度** | 无物理概念（由高度分层处理） | $Y_{3D}$（地面为 $0.0\text{ m}$） | $Y$ 对应垂直向上 |

> [!IMPORTANT]
> **坐标轴向与镜头关系**：
> - 游戏俯视摄像机朝向**北方（$-Z$ 方向倾斜俯视）**。
> - 因此，**$+Z$ 轴方向即为朝向玩家镜头的“近景/南侧”**，$-Z$ 为“远景/北侧”，$-X$ 为“西侧/左”，$+X$ 为“东侧/右”。
> - 物体制作时请确认正反面朝向（例如办公桌正面面向椅子的方向）。

## 2. 轴心点（Pivot / Origin）与基准面设定

在 PicoCAD 2.0 中导出模型前，**轴心点（Origin/Pivot）的位置是决定游戏内对其对齐、碰撞与阴影正确的关键**：

1. **地面家具道具（Floor Props）**：
   - **轴心必须位于模型的底面几何中心（Bottom-Center, $Y = 0.0$）**。
   - $X = 0.0, Z = 0.0$ 处于物体水平投影的正中心。
   - $Y = 0.0$ 严禁处于物体内部或悬空，必须贴齐最低顶点（接触地面的脚垫底面）。
2. **模块化墙体（Modular Wall Blocks）**：
   - **轴心位于墙块底面的几何中心**。
   - $Y = 0.0$ 贴齐地面。
   - 沿厚度方向（$Z$ 轴），轴心位于厚度中间（$Z \in [-0.05, 0.05]$）。
3. **墙面挂饰（Wall Attachments，如开关、电箱、挂钟）**：
   - 轴心位于挂饰背面贴墙面的水平中心。

## 3. 模块化墙体规格（Modular Wall Specifications）

游戏迷宫由 $1\text{ cell} \times 1\text{ cell}$ 的网格构成，制作模块化墙体时需符合以下尺寸：

```
+-------------------------------------------------------+ Y = 3.0m (天花板)
|                     顶部横梁区段                       |
+-------------------------------------------------------+ Y = 2.88m
|                                                       |
|                                                       |
|                     墙体主体区段                       |
|         (近景 Cutaway 模式下由 Shader 自动裁剪透明)       |
|                                                       |
+-------------------------------------------------------+ Y = 0.22m
|                     底部踢脚线区段                     |
+-------------------------------------------------------+ Y = 0.0m (地面)
  <- - - - - - - - - -  1.0m (1 Cell) - - - - - - - - ->
```

### 3.1 规格参数表
- **单格直墙（Straight Wall）**：
  - 宽（Width）：$1.0\text{ m}$（$X \in [-0.5, 0.5]$）
  - 高（Height）：$3.0\text{ m}$（$Y \in [0.0, 3.0]$）
  - 进深/厚度（Thickness）：$0.1\text{ m}$（$Z \in [-0.05, 0.05]$）
  - **踢脚线高度**：$0.0 \sim 0.22\text{ m}$。请在贴图或模型倒角上在此高度预留分界线。
  - **顶部横梁高度**：$2.88 \sim 3.0\text{ m}$。
- **窗户墙（Window Wall）**：
  - 整体外框尺寸与直墙相同（$1.0\text{ m} \times 3.0\text{ m} \times 0.1\text{ m}$）。
  - 窗台高度：$0.9\text{ m}$。窗台下方（$0.0 \sim 0.9\text{ m}$）为实墙结构（底部同样带 $0.22\text{ m}$ 踢脚线）。
  - 窗顶高度：$2.5\text{ m}$。窗顶到天花板（$2.5 \sim 3.0\text{ m}$）为实墙上横梁。
  - 左右立柱：各保留 $0.08 \sim 0.1\text{ m}$ 边框。
  - 窗框与玻璃：玻璃位于厚度正中央，建议作为独立单面片，材质指定半透明/不透明单独 UV。
- **单开门门洞墙（Doorway Wall）**：
  - 门洞净空尺寸：宽 $0.8 \sim 1.0\text{ m}$，高 $2.2 \sim 2.4\text{ m}$。
  - 门框上部（$2.4 \sim 3.0\text{ m}$）为门楣实墙。

> [!TIP]
> **关于前景墙剖面（Cutaway）**：
> 本系统已统一采用**着色器高度裁剪机制**。你在 PicoCAD 2 中制作墙体时**只需要做一套正常的完整模型**，无需拆分两套网格。当墙体位于当前房间南侧前景时，引擎材质会自动剔除 $Y \in [0.22, 2.88]$ 之间的像素，完美保留踢脚线和顶梁。

## 4. 家具与互动道具规格（Furniture Dimensions & Rules）

家具道具按大小分类，直接影响玩家翻越（Vaulting）、阻挡碰撞及破坏掉落：

| 道具类别 | 常见物体 | 推荐尺寸 (宽×深×高 米) | 2D 碰撞体推荐尺寸 (像素) | 翻越属性 (`vaultable`) |
| :--- | :--- | :--- | :--- | :--- |
| **小道具 (Small)** | 办公转椅、垃圾桶、边几、落地灯 | $0.4 \sim 0.6 \times 0.4 \sim 0.6 \times 0.5 \sim 1.4$ | 约 $14 \times 14 \sim 18 \times 18$ | `false`（矮小物体无需跳跃，平移绕行） |
| **中型桌几 (Medium/Table)** | 办公桌、会议桌、矮茶几 | $1.0 \sim 1.6 \times 0.6 \sim 0.8 \times 0.7 \sim 0.85$ | 约 $46 \times 24 \sim 50 \times 28$ | **`true`（玩家按空格键可滑铲翻越）** |
| **大型储物柜 (Large/Blocker)**| 双门文件柜、保险柜、大冰箱、立式衣柜 | $0.8 \sim 1.4 \times 0.5 \sim 0.7 \times 1.6 \times 2.2$ | 约 $32 \times 18 \sim 48 \times 24$ | `false`（高大实心，完全阻挡视线与移动） |

### 4.1 碰撞与视觉微调提示
- **防止视觉与碰撞穿插**：家具的 3D 模型边缘可以略微大于（约 $2\sim 4\text{ cm}$）2D 碰撞体积，能呈现出更自然的靠墙贴合感。
- **桌椅套组**：制作桌子时，椅子若为独立物件，应单独建模。若为一体化废弃场景，可将散落椅子连同桌子合并为一个模型。

## 5. PicoCAD 2 贴图与 UV 规范

为了与游戏整体的复古低模像素光影（OTXO 风格）完美融合，请遵循以下贴图约定：

1. **图集分辨率与尺寸**：
   - 推荐使用 $128 \times 128$ 或 $256 \times 256$ 像素的贴图画布。
   - 避免使用非 2 的幂次方分辨率（如 $300 \times 200$），以保障 GPU 采样效率。
2. **像素密度（Texel Density）**：
   - 建议基准：$1\text{ 米} \approx 32 \sim 64\text{ 像素}$。
   - 保持同类物件表面像素大小均匀，避免某面像素极大、某面像素极细的不协调感。
3. **UV 边缘留白（Padding）**：
   - 相邻的 UV 岛（Face）之间至少留出 **1 像素的间隙**，避免斜向俯视时由于双线性滤波或近邻采样边缘溢出产生黑边杂色。
4. **手绘明暗处理**：
   - 材质将在 Godot 中接收**实时像素光照（Pixel-Lit）**。
   - 可以在贴图上绘制细微的环境光遮蔽（AO）和材质细节（如划痕、污渍、木纹、边缘高光），但**不要在贴图上手绘强烈的固定方向直射阴影**，否则会与游戏内动态灯光发生冲突。

## 6. 导出与 Godot 4 导入设置

### 6.1 从 PicoCAD 2 导出
1. 点击 PicoCAD 2 菜单中的 **Export**。
2. 格式选择：首选 **glTF 2.0 (`.glb` 或 `.gltf`)**。
   - `.glb` 会将网格与贴图打包为单个二进制文件，最不易丢贴图。
   - 如使用 `.obj`，请确保将导出的 `.obj`、`.mtl` 以及对应 `.png` 贴图存放在同级目录。
3. 检查轴向：确保导出时以 $Y$ 轴向上（Y-Up）。

### 6.2 导入 Godot 4 配置
1. 将 `.glb` 文件放置在项目的资源目录下（例如 `res://art/Dream/PicoModels/`）。
2. 在 Godot 编辑器 FileSystem 面板中选中该模型，在右侧 Import 面板中：
   - **Root Type**: `Node3D` 或 `MeshInstance3D`
   - **Extract Materials / Textures**: 如需使用游戏自定义 Shader，可选择提取材质。
3. **材质属性设置（至关重要）**：
   - 打开材质（`StandardMaterial3D` 或项目内的 `interiors_a_wall_pixel_light_material.tres`）：
   - **Texture Filter**：设置为 `Nearest`（近邻采样，保持硬朗像素边缘）。
   - **Shading Mode**：`Per-Pixel`（像素光照）。
   - **Roughness**：建议 $0.8 \sim 0.9$（消除廉价镜面高光，保留低模质感）。
   - **Specular**：设为 $0.0 \sim 0.2$。

## 7. 将 3D 模型接入游戏场景（以家具为例）

游戏内的家具场景结构清晰，通过组合 2D 碰撞体与 3D 视觉即可完成接入：

### 结构树范例 (`desk_picocad.tscn`)
```text
RigidBody2D (挂载 chair_01.gd，负责生命值、碰撞、受击、翻越逻辑)
 ├── CollisionShape2D (矩形碰撞体，尺寸对应家具底面)
 ├── Hurtbox (Area2D，负责判定子弹与近战伤害)
 │    └── CollisionShape2D
 ├── MeshInstance3D (挂载 PicoCAD 2 导出的 3D Mesh，负责立体展示与实时光影)
 └── Shadow (Sprite2D 或 Decal，负责地面基础阴影)
```

### 关键属性配置清单
1. **Root (RigidBody2D)**：
   - `Collision Layer`: 第 4 层（`Props` / 层数值 8）
   - `Collision Mask`: 第 1, 2, 3, 4 层（层数值 15）
   - `Gravity Scale`: `0.0`
   - `Linear Damp`: `8.0`（被击退后快速停下）
   - `Lock Rotation`: `true`（俯视角保持方向固定）
2. **`chair_01.gd` 导出参数**：
   - `max_hp`: 耐久度（如椅子 20，办公桌 60，大储物柜 120）。
   - `vaultable`: 桌台设为 `true`，大柜子设为 `false`。
   - `books_drop_category`: 破坏后可能掉落的书籍类型（`table` / `cabinet` / `none`）。
3. **视觉节点同步**：
   - 将导出的 `.glb` 拖入场景作为视觉子节点。
   - 位置微调：确保底部正贴合 $Y = 0.0$。
   - 运行游戏，模型即可无缝融入豪宅房间，享受顶灯投射与动态阴影！
