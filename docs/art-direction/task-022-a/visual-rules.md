采用冷靛蓝、印刷块面与局部半调。最先解决家具的大片亮白和面向关系，让人物从安静的深蓝地面中显现。这些是从本张样板提炼的试行规则，样板确认后再固化为资产规范。

## 本张图的规则

| 对象 | 视觉规则 | 本张样板中的表现 |
| --- | --- | --- |
| 办公桌、椅子 | 顶面用中等明度冷灰蓝；正面更深；侧面和底部形成墨色暗块。亮边、纸张承担少量高亮 | 压低整片白桌面，增加深色面板分区、抽屉缝和局部磨损；椅背与座面仍可辨认 |
| 地面 | 先保留走道和拼接方向，再放少量大形斑驳；大部分区域保持低信息量 | 连续深蓝静区承托人物，磨损沿局部板缝出现 |
| 墙面 | 顶盖、正面、侧面有稳定色差，接缝服从大块面 | 冷灰蓝顶盖、深靛蓝面板、局部掉漆；边界仍清楚 |
| 阴影 | 用桌下、墙脚及画面边缘形成有效黑块 | 暗块帮助分离桌腿和通路；保留地面受光层次 |
| 半调 | 附着于选定的环境表面、阴影过渡或磨损区，点阵尺度跟随贴图 | 点阵集中在少量桌下和局部地面，角色周边的安静地面仍占主体 |
| 人物与玩法提示 | 原有角色精灵、武器、准星、文字保持优先级；环境最高亮度留出空间 | 三名角色及小型提示与压白后的家具形成区分 |

家具细节按“块面 → 接缝 → 少量标签／磨损”的顺序设计。每件家具只留少量有意义的亮边和结构线；文件柜、冰箱及前台的具体图案留待对应资产试点，本张图没有展示这些物件。

设计锚色用于环境表面：墨黑 `#060B19`、午夜蓝 `#10162C`、深靛蓝 `#202A4A`、石板靛蓝 `#3A496C`、磨损蓝 `#62789B`、少量冷亮色 `#A4B3CC`。它们是设计参考值；生成图含中间色，不能据此认定已完成引擎内的 16～24 色规范。

半调在实际落地时使用稳定的表面坐标和受控遮罩。相机移动、角色高速经过或灯光变化时，点阵应跟随表面；光照保持连续，避免重新出现地面同心环纹。角色脸部、轮廓、UI、血液与关键提示保持原有清晰呈现。

## 血色与演出边界

任务书同时写了“独立亮红体系”和“不改血液颜色逻辑”。当前正式代码保留橙血 `#D96B18`、空中血 `#FF9A2E`。本阶段按“不改血色逻辑”执行，血液继续是独立强调色；不会因为这张环境样板而改为红血。

底图没有血迹，也没有完整 HUD。本张样板只展示角色与环境的视觉关系；血液、UI、交互提示和高速交战的可读性需在房间试点中验证。

塔罗、梦境异常、章节事件等保留独立演出语言。普通办公室基线使用家具块面、局部印刷纹理与深蓝静区。
