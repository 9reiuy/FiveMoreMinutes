`.runtime/legacy_2d_cleanup_20261001/retired_files.zip` 保存删除前的实际文件（包括未提交修改），以及本轮改动前的 main 脚本和房间说明。每个删除文件已验证备份 SHA-256。`manifest.json` 记录原相对路径与哈希，`dependency_audit.json` 保存依赖清点。备份位于忽略的运行目录，不属于游戏资源或发布包。无需从不完整的 Git 状态恢复。

不可整包覆盖还原 main 脚本，以免覆盖之后的工作；按 manifest 中的相对路径提取所需文件即可。
