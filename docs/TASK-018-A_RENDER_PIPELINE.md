## 正式接入后的单视口像素化（2026-09-28）

旧三通道选择性预览已退出正式显示链。教学层和随机 3D 办公楼现在各保留一个玩法世界、一个世界渲染视口和正式 Camera3D。设置中的“像素化”默认开启：世界（含人物、武器、光影、弹丸、血迹）以 640×360 渲染并 nearest 放大；关闭后世界视口使用输出尺寸。独立预览可切换 960×540 作画面比较。原有 Depth Bridge 的精灵捕获视口仍在，不能将总视口数误读为世界重复渲染次数。

HUD、准星、提示和菜单仍使用项目的 640×360 逻辑 UI 画布及原窗口缩放。窗口输入先转成世界摄像机视口坐标，投影提示再转回 UI 坐标；地图外黑幕留在世界视口，Palette 在世界内处理，正式 Main 的全屏 Palette 在 3D 场景中关闭。像素化切换不重建楼层或人物，不修改窗口的 `content_scale_size`。

同机位证据位于 `.runtime/unified_pixel_640_office.png`、`unified_pixel_native_office.png`、`unified_pixel_960_office.png`，方案 1 位于相应 `*_palette1.png`；静音动态帧位于 `.runtime/unified_pixel_clip/`，960×540 预览为 `.runtime/unified_pixel_movement_shooting.gif`。画面复查确认办公区桌椅、人物、光影同网格，UI 清晰；抽查移动、射击、Space 规划和 Dash 片段未见旧方案的矩形角色裁切。完整玩家路线与中档显卡表现仍需实机复核。

静音检查：预览 63/0、正式包装 29/0、Main 教学层／随机层 24/0、环境 22/0、瞄准投影 41/0；单视口 GPU 遮挡 6/0（实体前后、透明体、移除），Godot 解析和目标启动通过。全工作区 `git diff --check` 仍仅报告既有 `scenes/ui/dream_hud.tscn:86` 尾部空行；本轮相关已跟踪文件的差异检查通过。

## 2026-09-27 调查时的链路

正式 3D 办公楼由一个玩法世界驱动。`Dream3D_RandomDungeon` 每帧先更新正式摄像机和角色投影，再更新弹丸灯、家具透视孔、投掷/Dash 规划、伤害数字、拾取提示等。地图的 45° 旋转与二维玩法坐标转换仍由原世界负责。

角色 Depth Bridge 使用被动二维捕获贴图，分别输出身体、手持武器和附件平面。Bridge 同样服务于血迹、弹丸、掉落物和其他表现，所以不能把所有 Bridge 都归类为高分辨率人物。身体和武器的深度面、颜色面及枪口快照必须继续使用正式映射。当前人物可见层为位掩码 2；玩家仅投影体积使用 4；普通环境主要使用 1。层位不能根据已过时的测试注释推断。

家具和墙体使用真实几何及独立阴影阻挡体；人物采用仅投影体积。墙体裁切、家具透视孔使用着色器中的丢弃逻辑，遮挡代理必须保留该逻辑。玻璃应允许背景人物进入可见性遮罩，最终着色取自完整参考图，实体窗框仍挡住人物。

地图外黑幕是 CanvasLayer 19；正式 HUD、交互提示等使用 CanvasLayer 20。黑幕的射线参数和电梯开口来自正式摄像机，其原着色器使用 SCREEN_UV。预览若将它重定向到根视口，须使用预览专用材质，将屏幕取样改成内容矩形的局部 UV，并将矩形尺寸固定为内容尺寸。只平移 CanvasLayer 会导致留黑边时黑幕偏移。

正式 Main 的 Palette 是 CanvasLayer 1000 的最终全屏处理。独立预览不实例化这个 Main；它只对环境结果处理 Palette，再按人物遮罩合成，最后叠加黑幕和 UI。地面血色 #D96B18、飞溅 #FF9A2E，以及现有血泊扩散节奏不属于本轮修改。

## 已退役方案的证据

`tests/pixel_environment_test.gd`、`tests/MANUAL_TEST.md` 和灯光脚本注释明确记载 Selective Scene Pixelation 已退役。原生基线要求正式场景没有 PixelWorldViewport、NativeActorViewport、ActorVisibilityViewport，也没有 VisibilityMask 代理和注册系统。手册记录后续采用只对照明采样进行像素化的方案。

本仓库可见提交历史未找到说明退役原因的记录。无法据此声称旧方案因为性能、闪烁或遮挡缺陷退役；具体原因未知。本轮独立预览不移除正式入口的退役结构断言。

## 预览契约与风险

预览使用固定种子 42001 的开放办公区，一个真实玩法世界和一个正式摄像机控制源。480×270 环境、原分辨率完整参考、原分辨率可见性遮罩的摄像机在渲染前读取同一快照。环境与参考共享 World3D；遮罩只复制显示代理，不复制物理、AI、伤害、计时或灯光。

1920×1080 下整数放大 4 倍；其他尺寸居中整数放大。输入由正式世界所属的高分辨率视口接收；窗口到内容坐标转换须排除黑边。模式切换不生成第二个玩法世界。额外参考图和阴影绘制会增加成本，不能将预览视为性能优化。

遮罩的正确性必须用实际画面验证，尤其是自定义 DEPTH、alpha 丢弃、透明玻璃、人物与家具透视孔、武器独立平面及相机抖动。Headless 只能验证节点、参数、生命周期和数学映射，不能验收渲染像素或 GPU 帧耗时。

## 独立预览交付（2026-09-28）

入口：`scenes/dream/preview/SelectivePixelPreview.tscn`。在编辑器打开该场景并单独运行，或使用 Godot 指定该场景启动。F6 切换原显示／选择性像素化，F7 单独切换环境 Palette。启动默认静音、关闭手电，不更改正式入口与项目拉伸设置。退出恢复原窗口内容尺寸和静音状态。

显示层保留一个真实玩法世界；环境与完整参考共享同一个实际 World3D，遮罩另有无玩法的代理 World3D。只有玩家、敌人的身体及手持武器进入原精度分类；仅投影人体不被移出环境灯光计算。原显示且 Palette 关闭时停用额外两通道绘制。代理缓存材质参数，只提交变化值，并清理已销毁来源。

输入由预览缓存窗口鼠标事件，统一减去整数显示区域起点。角色握持姿态、枪口瞄准、地面规划和准星调用同一可选输入适配器；无适配器的正式入口继续读取原视口鼠标位置。黑边禁用射击和 Space 启动，并保留最后合法方向，避免无穷坐标进入射线投影。

### 当前结果

- **画面：待视觉批准。** 已产生 1920×1080 同机位四张对照图；环境 480×270 最近邻 4 倍放大，人物取原精度参考。未调整资产、血色、血泊曲线或光照预算。HUD 仍沿用既有布局，其部分固定位置与字号尚未针对 1080p 重新排版。
- **对齐：部分完成。** 49 项结构／输入／模式切换／三次重建检查通过；黑边映射增加实际适配器检查。静音输入驱动片段确认实际开火。尚不能据此宣称八方向首帧枪口误差、Dash 终点、所有窗口尺寸及镜头抖动均已逐帧视觉验收。
- **遮挡：基础 GPU 检查通过，完整玩法矩阵未完成。** 实体位于人物前／后、透明材质和删除遮挡物 5 项检查通过，人物白色遮罩像素依次为 5900／0／5900／5900／5900。实际毁门、破窗、旋转家具透视孔、倒地、血滴落地仍需逐项动态验收，不能用此箱体测试代替。
- **技术回归：无新增失败，但非全绿。** 血迹 17/0、瞄准预览 41/0、阴影 47/0；原显示仍 16/2、角色武器仍 107/5，均与修改前一致。正式入口无选择性节点断言保留。三次重建代理数 917／918／915，没有逐层递增；这不是正常工牌跨层流程的替代验收。

### 性能实测

RTX 5070 Ti，Godot 4.7.1 Compatibility/OpenGL，1920×1080，每模式预热 10 秒并采样 60 秒。同种子、同输入路线，包含玩家开火；不是人工完成的多人交火验收，也不是纯 GPU 计时。

| 模式 | 帧耗时中位数 | P95 | 平均绘制调用 | 玩家开火 |
|---|---:|---:|---:|---:|
| 原显示参考 | 16.906 ms | 38.672 ms | 1607 | 100 |
| 选择性预览 | 33.433 ms | 107.209 ms | 6231 | 90 |

采样结束两模式投影灯均为 7；视口总数分别 240 与 174，包含既有角色、掉落物及特效捕获视口，不是新增 240 个选择性通道。选择性通道固定为三个。两轮死亡、血迹和弹丸结果不同，不能将该结果解读成精确隔离渲染开销的等负载 A/B；但足以确认当前原精度参考＋代理方案开销明显，**性能未达正式接入要求**。中档显卡未经验证。shader cache 写入警告也应在后续正常权限测试环境中消除后复测。

结论：**PARTIAL，独立预览可运行，不替换正式显示链。** 需要继续完成完整动态遮挡／对齐矩阵、可比负载性能复测及主观画面批准，才讨论正式接入。
