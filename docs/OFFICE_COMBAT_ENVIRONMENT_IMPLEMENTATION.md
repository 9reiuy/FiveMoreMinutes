# 办公楼战斗环境改造 — 2026-09-21

状态：**第一版实现已落地，整体验收 PARTIAL**。

## 已实现

- 扩大五种轮廓的房间，开放办公区 14×16，会议室 14×14，其余常规空间 14×10；最远合法路径上限 32 个设计格。相机、FOV、Dash 数值未修改。
- 房间家具使用两种镜像功能模板及有限整组偏移；保留门口预留区、连通性检查、至少 60% 未占用面积和 6×3 格直线战斗空地检查。新模板失败时不再回退到旧随机家具散布。
- 接入 18 个 Kenney CC0 模型，补充机柜、复印机、隔断、白板和接待台的程序化低多边形模型。授权与来源见 `art/Dream/office_lowpoly/SOURCES.md`。
- 家具模型、碰撞占地和遮挡高度共用 OfficeFurnitureCatalog；保留原 2D 家具物理与破坏逻辑。修复额外 encounter drop 链在模板外混入旧家具的问题。
- 子弹发射时缓存枪口高度；家具平面相交后按实际高度与局部显示器区域筛选，低家具越弹不造成伤害。敌人射击可行性使用同一高度规则。旧 2D 弹道保持原规则。
- 墙高 2.6、门高 2.2，内外墙厚度 0.18/0.28，门叶厚度 0.06；真实门楣、顶部横梁裁切、细玻璃框。机房/档案室门使用金属色，其余门使用木色输入。
- 地毯、瓷砖、防静电板等低频程序化地面，统一房间配色与光色；顶灯数量预算未增加。家具接触阴影不创建灯。
- 新设置默认关闭 Palette，已有玩家选择保留；方案 1 仍可用。
