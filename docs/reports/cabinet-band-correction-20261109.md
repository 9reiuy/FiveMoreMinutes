# 保留装饰块的柜顶明暗修正

2026-11-09，正式工程`E:/GameProjects/FiveMinuteMore`。用户明确指出：要处理装饰块下沿和柜顶的黑色条纹，不能移除顶部装饰块。上一轮删除`DeskDetails_cabinet`是误解，本轮已撤销。

两个顶部装饰块恢复为原来的folder／paper盒体。尺寸分别为0.40×0.18×0.30与0.30×0.14×0.30，位置及原色均不改。生成器与删除前的原文件逐字节一致。柜体、原颜色图、碰撞、正常地面投影和四项已批准材质效果继续保留。

## 来源与修正

实际Camera隔离显示：清除纹理细线、停用法线凹凸、分别停用卡通／拉丝／边光，均不能解决整片压黑。关闭月光阴影或仅隐藏屋顶遮挡体时，柜顶及装饰块下沿恢复层次；隐藏柜体自身的投影替身不能解决。说明这里主要是屋顶遮住外部月光，而不是柜体自阴影偏移造成的条纹。

原有`office_furniture_bounce.gd`每房四盏补光位于0.65米，低于柜顶1.85米，无法照到朝上的面。现仍使用同一组灯，放到`min(2.35, wall_height - 0.25)`米，源强度增益由0.75改为2.25。它们继续跟随真实室内灯的颜色、开关和楼层电路，保留结构遮挡；没有增加灯数、材质自发光或额外渲染通道。

屋顶和外部月光的投影保持，原顶灯／窗光位置与强度不变。之前停止生成喷漆水平面周期法线的改动保留，本轮没有再改材质或着色数学。
