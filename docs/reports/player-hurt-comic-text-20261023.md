# 受伤文字：粗体像素与漫画半调阴影

## 范围

只修改玩家有效受伤后的中文感叹词。保留受伤地点世界锚点、星星、屏幕冲击与调色板隔离、战斗数值、无敌时间和一般交互/对话字体。单智能体执行。

## 表现

- 每字相差 28ms 入场，75ms 达到放大峰值，再收缩回弹；约 250ms 稳定。
- 基础显示约为原生字形的 1.65 倍，峰值超过 2 倍。交错倾斜、短促跳动，后段从原受伤位置漂移并淡出，850ms 完全清理。
- 原生 12px 中文像素字形以相邻笔画印章加粗，最近邻采样，独立像素轮廓。未改全局字体。
- 第一轮实机发现 FontFile 自带 outline 在变换后断裂，已改为字形邻域扩张描边；第二轮游戏摄像机确认中文可读。
- 独立后置 HUD 点阵阴影，错位 5px，棋盘半调；不对世界、星星或其他 UI 应用该材质。

## 验证

- `player_hurt_presentation_test.gd`：57 项通过，包括弹出峰值、回弹、逐字延迟、交错倾斜、淡出、半调层级，以及原有跨层/暂停/战斗不变回归。
- `player_hurt_camera_test.gd`：15 项通过。真实 GPU、正式入口、Palette 开/关、像素化开/关、有效伤害、实际移动输入及世界锚点；录制为确定性效果步进，不是性能录像或 60fps 证明。
- 查看实际摄像机截图确认字形、深色轮廓与点阵阴影；静音片段位于 `.runtime/player_hurt_20261023/hurt_comic_text.mp4` 与 `hurt_comic_text_detail.mp4`。
- 测试退出仍有先前已存在的两张纹理资源释放警告和 UI anchors 警告；不是“全部日志无错误”的结论，本次未改无关 UI/资源生命周期。
- 差异空白检查通过；大量既有未提交改动保留，未提交或上传。
