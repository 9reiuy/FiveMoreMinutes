# 原墙体竖向切面贴图小样

**本版未获观感认可，不作为最终交付。** 用户指出墙体显粗、裁切轮廓未完整展示，并补充局部图要求墙脚短斜面接低墙根。本报告的 64／21 项检查仅证明此版材质及既有网格行为，不能证明满足最新参考造型。

## 方向与范围

按用户对参考图 x95.8%、y43.6% 位置的进一步标注，本轮重点是被切开的竖向墙端面。上一版新增 JoinedCap 顶盖小样作废，不推广。本版直接使用原有 WallMesh 的端面及顶面，新增 Mesh 和顶点均为 0；尚未推广至所有正式楼层。

实现位于 `scripts/dream/preview/wall_cut_face_texture_sample.gd` 与 `shaders/dream3d/preview_wall_section.gdshader`。原 surface0 包含墙正面与左右端面，材质按局部法线仅在端面采样实际像素截面贴图；原正、背墙面继续使用已有纹理与光照。原 surface2 使用同套截面纹理衔接，未叠加额外面片，也未改变顶点或原 UV 数组。材质支持恢复到原覆盖资源。

贴图有浅色窄边、略暗实心内芯和少量接缝。按当前原网格实际厚度生成 32 px／世界单位的纹理：普通墙为 16 px 宽，全高外窗框为 8 px 宽，剖切窗恢复对应实际厚度。保留原夜景和配色滤镜，因此本次运行呈蓝灰色。仅给端面材质少量明度补偿以维持暗处可读性，未添加灯光。

## 验证

- 新贴图检查 64 项通过：原网格资源、三组表面、节点数量、变换、阻光体不变；原墙正面贴图／办公楼像素 atlas 不变；截面真实像素数据及边芯明度差、窗墙实际厚度和纹理密度正确；全高／剖切及旋转情况下可恢复原材质。
- 原物理门剖切 19 项和玻璃剖切回归通过。基线原墙表面／法线／UV 诊断通过。
- 实际 Main → 正式 V3 seed 120 → 档案室 room5，21 项 GPU 检查通过。目标是原有 H:x1:y28 的墙端，位于全高墙与矮墙交界；不是被门叶或同向全高墙遮住的门洞细缝。
- GPU 诊断临时仅替换实际端面绑定的纹理，排除顶部后仍有 1,299 个端面下半部像素变化，证实贴图确实作用于竖向表面。诊断色已恢复，不用于最终交付画面。
- 前后截图保持相同 Camera 变换、35° FOV、640×360 世界视口及 1920×1080 输出；普通输入完成后续走动。碰撞形状、层、掩码与阻光网格保持不变，恢复时再次核对。
- 为隔离建筑观感，定位玩家到原生房间后停用敌人处理，不使用造成频闪的长时间无敌。RTX 5070 Ti / Compatibility，窗口屏幕外启动并最小化。
