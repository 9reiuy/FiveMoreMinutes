# 风格化浓烟接回交互白盒

后续修订：用户指出持续发生感后，交互烟雾已改为同一批雾团保持聚拢。最新状态、41 项检查与实机证据见[持久雾团记录](interactive-gas-persistent-cloud-20261117.md)。下文保留本日首次加浓版本的实现记录。

2026-11-17 用户要求“接回交互关卡”，随后指出烟雾过于稀少，要求达到薄雾般的浓度。本轮已经在独立交互白盒完成接回和加浓；授权范围为独立交互关卡，未修改主线关卡入口。

## 最终行为

- `Run_Interactive_Gas.cmd` 默认进入可射击、移动与翻滚的房间，F2 打开／返回保留的独立参考烟柱。不再默认打开没有交互的视觉页。
- 新房间使用同一原创 Voronoi 云瓣网格、教程 `light()`、常量两色色阶与原噪声硬边溶解。独立参考烟柱的发射参数和外观保持。
- 新增 `interactive_gas_stylized.gd` 和 `interactive_gas_particles.gdshader`：原生 GPU 网格粒子直接读取既有 GPU 气体模拟的密度、速度和障碍纹理。粒子在速度场中积累位移，遇到实体边界停止或滑动；不以贴图滚动代替气流运动。
- 补足浓度：96 个烟团改为上限 256 个，基础尺寸从 0.65–0.78 调为 0.90–1.08，出生高度从 0.62 米单薄一层改为约 0.57–1.37 米的分布，降低边缘密度区域的整团缩小幅度。烟团互相遮挡形成连续烟层，仍是完整三维云团，没有重新叠加写实薄雾或透明渐变。
- 子弹、真实角色移动和既有飞扑翻滚继续给原模拟注入扰动；密度变化控制整团尺寸，硬边溶解继续使用既有生命周期。保留原射击、移动、翻滚的玩法数值与气流输入参数。
- 空格翻滚、鼠标射击、WASD 移动；G 同时重置气体与粒子，P 同时暂停／恢复二者。进入参考页会暂停隐藏的世界及其粒子，返回时保留原本的暂停状态。
- 烟雾使用独立渲染层 12，避免与已有的城市层、屋顶层和光学效果层冲突。单独的校准方向光维持原两色表面，房间灯保留烟团对地面的真实阴影；退出时恢复自己修改的灯光与 Camera 层位。
- 释放粒子对模拟纹理的引用后，再释放模拟的 GPU 资源。未切换渲染后端，未修改正常试玩入口的声音设置。

## 验证与实机证据

Godot 4.7.1、Forward+／Vulkan、RTX 5070 Ti；测试使用私有静音 WASAPI 配置。默认世界 Camera 为 640×360，窗口 1280×720。后台绘制显式提供时间步，实际 GPU 粒子有运动。

`tests/interactive_gas_whitebox_test.gd` 本轮改为测试原生粒子分支，最终 **31 项通过、0 项失败、进程退出 0**。旧版 44 项外扩描边测试不作为本轮验收证据。

- 受控原生 GPU 粒子从 X=5 被速度纹理推进，在 X≈6.99996 的固体边界停止；无速度对照保持 X=5。测试粒子独立于房间旋转，避免误用 `capture_aabb()` 坐标。
- 气体密度、速度保持有限值，固体网格内密度为零。弹道测试区域的密度总量从 303.70 降至 4.68；随后 24 个模拟步回填到 42.97。
- 使用正式武器／子弹、角色移动和翻滚路径完成三段实际交互录制，检查真实的射击及运动事件。
- P 的暂停／恢复、暂停中 G 补烟、F2 打开／关闭／释放／恢复状态通过。
- 新增可选气体支持后，冻结的独立参考 Camera 与改动前 Shader 输出逐字节一致。
- 同一测试场切到正式美术模式重建，新的原生粒子适配器加载；旧节点已释放，旧密度／速度／障碍纹理经拥有它们的 RenderingDevice 查询均已不存在，资源列表清空。未用 `RID.is_valid()` 的非零句柄检查冒充存活性检查。

全部证据位于 `.runtime/interactive_gas_link_20261117/`：

- `interactive_dense.webp`：70 帧实际 Camera 交互演示，按录制时间戳播放；仅缩放和加标题，未画补烟雾或调色。
- `density_comparison.png`：相同视角下的稀疏版／加浓版实机对照。
- `shoot/`、`walk/`、`walk_recovery/`、`roll/`：原始 1280×720 图像及采样时间戳。
- `reference_baseline.png`、`reference_updated.png`：独立参考页的逐像素对照。
- `production_art_fixture.png`：同测试布局的正式美术模式加载证据，不代表主线推广。
- `dense_interaction.log`、`result.json`、`summary.json`、`frame_times.csv`、`integration_manifest.json`：最终检查、原始帧时间及源文件哈希。前期失败日志保留，最终状态以 `dense_interaction.log` 为准。

## 有界帧时间采样

固定 Camera／角色姿势、相同灯光与声音条件、256 个原生 GPU 烟团；按暂停→运行、运行→暂停两轮，每窗口 180 帧，共 720 帧。以下为进程墙钟帧间隔，**不是纯 GPU 耗时，也不是全游戏帧率认证**。

| 窗口 | P50 ms | P95 ms | P99 ms | Max ms |
| --- | ---: | ---: | ---: | ---: |
| 第一轮暂停 | 6.883 | 7.405 | 7.574 | 7.661 |
| 第一轮运行 | 6.898 | 7.716 | 8.574 | 13.422 |
| 第二轮运行 | 6.939 | 7.605 | 8.192 | 8.675 |
| 第二轮暂停 | 6.894 | 8.309 | 16.767 | 17.572 |

运行窗口出现一次 13.422 ms 长帧，暂停窗口最大 17.572 ms；该对照未定位系统或 GPU 根因。采样中没有截图读回，正式美术模式的重建不计入这些窗口。
