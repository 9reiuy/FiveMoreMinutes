# 叉车局部加速气流与前后渐隐

2026-11-17，已接入共享叉车控制器和当前1-2关卡，使用用户选定的Vefects风纹，按俯视角制作围绕车身的气流。按最新红框收短保留范围，主要保留车身周围一段，前后两端均平滑渐隐。

## 实现与素材

- `scripts/dream/props/forklift_boost_wind.gd`：两个车身局部网格，共用一份720三角形曲面，总计1440三角形。跟随叉车旋转和楼层高度，由实际车速与加速状态控制强度和拖尾长度。没有独立每帧循环、灯光、碰撞或额外视口。
- `shaders/dream3d/forklift_boost_wind.gdshader`：透明流动风纹。前端UV 0.27之前完全透明，0.27至0.40平滑显现；后端0.53至0.73平滑消退，0.73之后完全透明。无需截屏采样或全屏模糊。
- `scripts/dream/props/drivable_forklift.gd`：创建并同步气流；停车重置、下车、死亡与停用立即清理；手刹或撞墙取消加速后快速消退；随原模型跨区转移和卸载。
- 气流网格标记为视效并排除血迹接收，沿用原有上车材质处理的排除逻辑，保持透明材质及动态参数写入。未改车体外观、伤害、速度、碰撞、驾驶音效或近战卡肉。
- `art/Dream/VFX/VefectsWind/`：三份原始TGA及逐像素一致的PNG转换、原始LICENSE、SOURCES。许可允许用于商业成品，不是CC0，禁止作为独立素材或在公开仓库中再分发。参考图片只用于观察形状，未复制进游戏。

## 验证

独立白盒及同布局正式美术先行验证65项，通过；组合负载配对检查7项，通过，随后接入共享叉车。

前后范围收短后的最终集成验证：PID30300，退出0，63项检查通过。覆盖正常行驶不出现、Shift加速、四个朝向、取消加速、手刹、真实墙体碰撞、下车、跨区转移、重置、重建和实际1-2关卡卸载。已查看实际Camera截图，气流保留范围接近用户红框，两端均平滑消散。

运行条件：Godot4.7.1、Forward+ / Vulkan、RTX5070Ti、1280×720原生显示、WASAPI。自动进程在启动前配置私有主音量0并检查重载；未改用户保存音量。最终运行日志无ERROR/WARNING。
