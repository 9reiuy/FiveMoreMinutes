# 按标注摆放卧室与重做紧凑大厅

2026-11-03，依据本轮红蓝标注和“右侧进入、经过前台、最左端上电梯”的要求。此记录替代此前两份报告中的大厅与卧室布局结论。

[打开标注与实机对照页](../../.runtime/layout_redraw_20261103/review.html)。

## 当前布局

- 卧室床移到左后角并旋转 90°，对应红框的横向摆放；窗户移至北墙左段，对应蓝框。地毯随床平移和旋转，继续完整覆盖床的占地。同步床边药瓶、床与药物交互点、睡眠人物位置和朝向，移开与新窗位冲突的墙柱。
- 大厅主体改为 14×8 格，右侧增加 3×3 格短入口，总共 121 格。原大厅主体为 26×16 格、416 格。大厅现在只有一张中央前台、一个小候坐区和最左端的一部可用电梯。
- 横向地毯连接右侧入口与前台，左端转向电梯。减少镜头跟随幅度，使进入时就能看清整条路线。入口近侧墙使用剖面显示。地毯按边界拼接，薄布料不再投射错误的黑色接缝。

运行时几何检查确认：床位于 `(-3.8, 0, -3.3)`、朝向 90°；窗户位于 `(-2.55, 1.96, -4.36)`。床最高点 1.269 m，窗户最低点 1.3906 m；窗户与床、柜子、墙柱和通风百叶不相交，地毯完整覆盖床。

首次 Camera 尝试因场景数字写法缺少前导零而加载失败，已修正并重新运行；对应旧日志保留在 `camera/`。`camera_v2/` 是成功加载后的第一版图片，其中大厅地毯接缝随后又做了修正。最终图片归档在 `camera_final/`。

测试退出时仍会出现此前的两项贴图 RID / ImageTexture 释放日志，部分场景还有 ObjectDB、资源退出与 UI 锚点警告。此次验证不涉及全游戏性能验收。
