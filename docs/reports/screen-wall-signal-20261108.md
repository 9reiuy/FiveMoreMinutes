# 电视墙统一蓝色与随机信号切换 · 2026-11-08

已接入正式主菜单，试玩入口仍为 `tools/preview_screen_wall.cmd`。常态画面和对应屏幕光源统一使用中间右侧横屏 **TV_04** 的蓝色，并在此基础上提高纯度。保留原眼睛颜色、鼠标跟踪、立体角色姿势及屏幕背光关系。

每台电视独立随机切换：首次等待约 1.2–4.8 秒，之后每轮间隔约 2.4–7.8 秒。短暂频闪进出，中间保持约 0.72–1.32 秒。带选项的屏幕完全隐去人物画面、显示原选项文字；装饰屏幕随机显示雪花或经典彩条测试图。彩条保留参考图的彩色条纹，常态人物画面采用统一蓝色。

悬停继续使用原有显像管过渡与停留判断，并接管当前屏幕；随机展示本身不会触发菜单操作。逐台关机时取消随机信号，重载后重新计时。新增随机切换不触发音效；现有悬停和关机音效沿用。暂停、设置页禁用随机切换和主菜单蓝色增强，保持原滑条的 `#82ABBA` 磷光色。

实现只复用原有选项纹理和屏幕材质，彩条由 shader 绘制，没有新增动态图片读取或显示视口。电视几何、角色资产及姿势、光源数量、Direct3D11 启动方式、低优先级保护和前台 60 / 后台 30 限帧未修改。
