# 无人机与送餐机器人调整 · 2026-10-23

## 已接入正式游戏

- 两种机器模型缩小至原来的 2/3：机器人 2.4 → 1.6，无人机 1.3 → 0.8667。机器人移动半径 15 → 10，受击胶囊同步缩小；导航查询同步使用新半径。无人机受击半径 18 → 12。真实枪口随模型移动，描边捕获范围同步缩小。
- 无人机使用 20° 的 SpotLight3D 定向射灯，灯从机头前方照向目标身体高度，不使用全向灯模拟探照灯。枪口瞬时闪光仍保留自己的短暂补光。
- 锁定时，机头和射灯朝向目标，而不是被巡逻立面朝向覆盖；继续保留前摇最后 0.12 秒的瞄准点锁定。巡逻路线、飞行高度、弹速、射速不变。
- 两者死亡烟雾与玩家跑步直接复用 `nyangeon_vfx_shapes.smoke_texture()`，保留同样的分块轮廓、像素颜色及收缩消散方式；死亡烟雾更大、持续更久并上升。无人机枪口也复用此纹理，不再单独生成另一套烟雾轮廓。坠落、爆炸火花保留且不产生额外伤害。
- 受到有效伤害后，原模型材质短暂替换为白色，再恢复原材质，时长沿用普通敌人的配置（当前 0.06 秒）。不穿透墙体，不改变外轮廓，不让枪口特效跟着闪白。机器人表情更新避开闪白期间，死亡前恢复材质。
- 不再创建两者的血条节点；仍为 100 HP，伤害与弹反秒杀规则不变。保留返回空值的旧血条查询接口，仅用于兼容，不产生显示节点。
