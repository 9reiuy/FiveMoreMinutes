# 火焰、燃烧与机器敌人正式接入

## 已接入

- 送餐机器人、外围无人机在生命低于或等于最大值 30% 时自动着火。
- 保留原始模型翻倒/坠落：机器人约 0.42 秒、无人机约 0.65 秒后，使用新系统爆炸。旧死亡闪光、独立烟雾和火星实现已移除，避免叠放两套。
- 玩家/员工枪口及机器敌人枪口采用同一套短促粒子喷焰。保留现有子弹、伤害、射速、弹匣、瞄准前摇、后坐力与枪口照明；原有枪口烟雾保留。枪口不构成点燃源，避免额外改变武器伤害。
- 火焰与火星使用专用语义色编码，由最终调色 pass 在选色前恢复黄白、黄、橙、红；烟雾及描边继续参与场景配色，不使用穿墙屏幕覆盖。
- 已验收的整体外沿描边保留：所有轮廓先绘制，所有填色后绘制，重叠内部不留逐粒子黑线。

## 燃烧规则

`scripts/dream/burning_effects.gd` 为唯一楼层控制器，视觉仍使用可复用 `elemental_particles_3d.gd`。

- 每游戏时间 1 秒，按目标当时的最大生命/最大耐久扣 10%。不是剩余生命的 10%，不是固定 10 点。
- 普通接触燃烧默认持续 5 秒，再接触仅刷新时间，不叠加每秒伤害或重复建立火源。低血量机器敌人会保持点燃直到其原死亡逻辑触发。
- 玩家走正常 `receive_damage`，保留既有护盾、翻滚/受伤等保护；敌人、机器和家具走各自正常 `take_damage`，不直接越过死亡与破坏流程修改血量。
- 当前 Boss 的 `boss_variant`、world.boss_enemy 以及未来 Boss 的 `is_boss` 属性/metadata、bosses/dream_bosses 组、`is_burning_immune()` 都支持免疫。后续新增 Boss 应使用其中明确身份，不依靠名称猜测。
- 火源可引燃玩家、敌人、实际可破坏家具。家具只选有 `max_hp` 的实际家具，不把玻璃和门错误当作可燃家具；按其最终运行时耐久计算伤害。
- 每 0.25 秒检查接触。默认接触半径 26 玩法像素；家具使用实际 footprint 的最近边缘，不只比较中心。附加高度限制与墙/门射线阻隔，不透实墙传火。
- 爆炸火团在约 0.65 秒内可引燃附近目标（接触范围 40 玩法像素），不附加直接爆炸伤害。
- 暂停、换层挂起不继续计时/扣血。控制器归属 floor_root，旧楼层销毁一并释放；目标用 WeakRef，死亡/销毁会注销火源。

## 边界与预算

燃烧对象上限 32、总粒子上限仍为 384、局部无阴影火光上限 4、短暂爆炸点燃区上限 16。持续发射公平轮转，并保留 96 粒子槽供爆炸。多火源下会降低视觉密度，不能承诺无限火源保持全部粒子数量。未新增全局天气/风系统，现有 set_wind 接口可继续用于后续风场。

## 验证证据

- `burning_damage_test.gd`：21 项通过，含百分比最大生命、刷新不叠加、5 秒熄灭、Boss 免疫、真实玩家/家具/机器人入口、家具破坏、近邻点燃、换层停损、释放目标、枪口不点燃与爆炸可点燃。
- `elemental_particles_test.gd`：24 项通过，生命周期、风向、预算、清理及爆炸预留。
- `unit_presentation_rules_test.gd`：52 项通过，双枪后坐力、死亡模型转移、坠落、共享爆炸、正常弹道等。
- `special_units_hotel_robot_drone_test.gd`：47 项通过，实际受击代理、100 HP、模型及弹道链路等。
- `special_units_formal_camera_test.gd`：最新 51 项通过，实际 Main 正式随机楼层 / Camera / Compatibility GPU。火焰、枪口、爆炸、巡逻与原色豁免截图位于 `.runtime/special_units_20261023/`。捕获脚本手动暂停了燃烧扣血以逐阶段验收，不用其截图证明伤害计时。
- `elemental_palette_test.gd`：实际 GPU 对照原始火焰与 palette on/off，两次共 2622 个暖色像素采样，最大通道误差 2/255。
- 整体外描边既有独立 GPU 对照 4 项通过；当前未将所有玻璃/半透明墙组合宣称为全覆盖验收。

捕获脚本中修正一次冻结无人机后坐力的测试前置条件：关闭物理瞄准时先归零后坐力，避免渲染帧再移动射灯使测量失配。没有借此修改实际射灯逻辑。

仍有既有退出资源警告：Main GPU 测试两张 GL texture 与 RenderingServer 析构顺序，部分 Headless 测试 ObjectDB/resources。未宣称全工程无警告，也没有做本轮正式战斗峰值性能验收。未提交或上传。
