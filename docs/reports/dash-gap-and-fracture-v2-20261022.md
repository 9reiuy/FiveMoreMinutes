# 跨空隙冲刺与受击定向碎裂 V2

日期：2026-10-22。接入正式随机办公楼和独立样板间；不改伤害、冲刺距离、外围玻璃 100 耐久、主动走出破口坠落死亡及员工卡保护。

## 本轮规则调整

- 移除“冲刺路径遇到首个非地板格就截停”的限制。沿朝向、在原冲刺距离内从远到近搜索合法落点，检查完整玩家占地及实际碰撞。室内隔墙、楼外空隙均可越过；另一侧不可达或放不下玩家时，退回当前一侧的安全位置，不落在虚空。
- 门、室内玻璃和外围玻璃复用原模型表面及材质切分。门板分成大块，玻璃使用三角切片；保留原 UV、纹理和初始变换，不再以通用小方块代替整个物体。断面玻璃加细亮边，原有透明纹理保留。
- 大块初速度沿受击方向，平面速度 4–6 世界单位/秒，散射约 ±10°，取消反向玻璃飞片。旋转后依据当前模型边界与地面接触，转为一批小碎屑；小屑约 0.4 秒内消失。不再长期保留地面碎片。飞入楼外的片块不在虚空生成地面碎屑，最迟 2.5 秒清理。
- 保留最多 32 批效果的预算和楼层归属，小碎屑使用批量绘制；无新增刚体、伤害、拾取物或捕获视口。
