# 屏幕墙模型与交互样板

本次交付为独立样板。原冷色终端 UI 方案按用户要求暂停，正式主菜单及 ESC
入口未接入这套屏幕墙。

## 最终布局

- 16:9 游戏构图，12 台不同比例、不同转角和深度的电视围在中央；6 组服务器与
  多组实体线缆分布两侧、背面、顶部和地面。
- 按用户后续反馈收窄、堆高、打散排列，周围压暗；机壳使用黑、炭灰及少量旧灰白。
- 不设置环境光或顶灯。12 个短程灯随电视屏幕布置，模拟屏幕对附近机壳与线缆的照明。
- `TV_07` 独立放大至 2.05 × 2.05，移到上方中央空位；下面两块电视略向上收拢。
  全体屏幕共用同一图像裁切基准，并对齐眼睛电视；眼眶、完整眼睛不跨屏或被遮挡。
- 原始眼睛颜色保留，瞳孔跟随鼠标；使用原游戏的移动限幅、平滑响应与停留回正行为。

## 交互与可编辑文件

- `tools/preview_screen_wall.cmd`：独立试玩，1280×720，使用独立用户数据目录。
- `scenes/preview/screen_wall_review.tscn`：可运行预览入口。
- `art/preview/screen_wall/screen_wall_model.tscn`：可编辑场景；普通试玩读取这个场景。
- `art/preview/screen_wall/screen_wall_model.glb`：可导入其他软件的几何与静态材质模型。
- `art/preview/screen_wall/ASSET_SOURCES.md`：CC0 来源、下载记录、转换说明及编辑方法。

四块屏幕已配置新游戏、继续、设置、退出的独立选项。鼠标接近时，只让相应屏幕
经历短暂花屏并显示选项；离开恢复拼图。只有实际可见玻璃上的点击才触发，前景实体
遮挡会阻止穿透点击。其余屏幕保留独立配置位置。键盘亦可切换和确认四个选项。

预览里的设置会打开现有设置面板，退出会关闭预览。新游戏、继续仅发送独立选择信号
并反馈选中状态，尚未接入正式存档或游戏流程。GLB 不包含 Godot 的运行时着色器或交互。

Godot 4.7.1 Compatibility，RTX 5070 Ti，真实 GPU 后台渲染；启动前准备独立静音配置，
使用 Dummy 音频驱动。以下是功能与视觉验证，不是帧率或性能验收。

|---|---|---|
| 屏幕显示、花屏、四个选项、键盘、前景遮挡与导出 | 56 项通过，0 失败 | `raised_full_out.log` |
| 完整眼睛、全部遮罩像素可见、上下左右跟踪、实际红色瞳孔像素位移、停留回正 | 36 项通过，0 失败 | `final_eye_out.log` |
| 保存场景重载、16:10 窗口保留 16:9 画面、设置与返回、静音保持、GLB 回读及 12 个独立电视分组 | 30 项通过，0 失败 | `raised_roundtrip_out.log` |

三次最终测试均退出 0，配套错误日志为空。文件均位于
`.runtime/screen_wall_review_20261106/`。最新动效为 `screen_wall_eye_raised.gif`，
由实际引擎帧按记录的时间间隔合成。

制作过程中修正了服务器模型的压缩扩展兼容问题、非交互遮挡物的元数据查询错误，以及
保存场景的重复导入实例关系。早期失败或旧布局截图不作为最终证据。
