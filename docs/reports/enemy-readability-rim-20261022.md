# 存活敌人像素发光描边 · 2026-10-22

## 范围与实现

- 仅正式角色显示桥中的存活敌人身体启用；玩家、尸体、分离的手持武器和环境默认关闭。
- 在现有 `lit_pixel_carrier` 的透明像素中检查一圈相邻纹素，形成一源纹素宽的暖白色硬边。保持角色自身像素网格，不做模糊光圈。
- 描边使用材质自发光，不创建 Light3D、不照亮场景、不新增视口或额外绘制代理；角色内部原画、受光和伤害数值不变。
- 沿用正式角色参考深度与 alpha scissor；正常接受前景深度遮挡，不透墙。
- 配色沿用世界最终 Palette。原色暖白；方案 1 映射为配色中的浅色，不绕过滤镜。
- 桥仅在生死状态变化时更新材质开关。材质保留运行时所有权，地面反射适配后死亡开关仍作用于实际绘制材质。
