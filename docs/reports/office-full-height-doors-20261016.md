# 正式办公楼层保留完整门体

用户要求墙体使用当前 U 形裁切后不再裁切门。本次仅在正式原生办公楼层关闭门体裁切提交：门扇、附属观察玻璃、门框保留完整高度，旧截面盖面隐藏。墙体 U 形、每房间专属墙面纹理、门开关／推踢／物理碰撞／破坏和电梯流程保持现有规则。

`office_skeleton_world_base.gd` 提供正式墙体方案的范围判断；`dream_3d_room_visibility.gd` 在房间提交时据此对门和门框传入不裁切。物理门本身的通用裁切接口仍保留给原独立样板及其他未纳入的场景。

验证产物：`.runtime/office_full_doors_20261016/`。

- `regression/`：生产墙材质生命周期、物理门铰链与裁切、玻璃三组针对性回归通过。明确报告 73 项断言，玻璃套件未报告断言数。门回归包括普通推动、叶片沿铰链运动、碰撞跟随、踢门与破坏。
- `camera/report.json` 和 `gpu.log`：实际 Main 正式入口，A1/B2/C3/V3 seed120 的 61 个房间、真实电梯分阶段换层及回滚，278 项检查通过，无脚本错误。每次纹理验证时同时检查全部物理门、附属 ShaderMaterial 玻璃、门框和旧截面盖面没有启用裁切。
- 房间原有墙面正反材质及贴图像素校验继续通过，52 组贴图绑定；墙体几何刷新仍无逐帧重建。
- GPU 窗口屏幕外启动并最小化，RTX 5070 Ti / Compatibility。房间截图初始定位为测试夹具、敌人暂停；单独走动片段使用普通输入，不作为交火 FPS 测量。

`camera/doors_before_after.png` 为同一 A1 seed120 会议室实际 Camera 裁切对照：左侧来自上一轮正式接入截图，右侧为本轮完整门体。两次运行重新生成，不声称其他动态像素完全相同。原始完整 PNG 保留。
