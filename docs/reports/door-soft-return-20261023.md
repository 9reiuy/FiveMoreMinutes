# 门的柔和回正（2026-10-23）

## 范围

参考 Woo Woo 的铰链、回正及近闭合减速思路；沿用本工程真实 3D 门、材质、双扇/单扇结构和 2D 权威碰撞，不移植竖条精灵。保留开门冲量、最大角度、血量、伤害、破碎和既有跨层铰链注册修复。已有未提交变更未回退。

## 本轮修改

`physical_door_3d.gd` 增加每扇门的回正等待计时。受击/主动推门后等待 1.2 秒；主动开门驱动与战斗挥动期间不接管。之后以角度弹簧和角速度阻尼朝关闭方向转动，限制到安全的被动摆动速度；接近关闭 ±3° 时进一步减速。沿用原有 2°、低角速度落闩逻辑。

只调整角速度，不移动刚体中心、不重设门板变换、不额外建立铰链或复制碰撞。回正使用被动摆动状态，不产生战斗伤害，复用已有朝玩家夹入的刹停判断。玩家离开后继续回正。关闭落闩后沿用已有休眠处理。

## 验证

- `door_return_motion_test.gd`：20 项通过，双方向、30/60/120 Hz 数值收敛、安全速度及已有血量/角度。
- `physical_door_hinge_cutaway_test.gd`：22 项通过，含回正防夹、离开后继续关闭、回正不转化为攻击、普通推门与踢门强度差异。
- `door_hinge_edge_regression_test.gd`：96 项通过，单/双扇、不同朝向、挂起恢复和正式跨层。
- `door_hinge_live_test.gd`：实际 Main 正式楼层、真实 GPU 相机，跨层挂起恢复后推门与回正通过。打开铰链偏移 0.00041144 世界单位，回正最大偏移 0.00040409，最终角约 1.967°并落闩，2D 碰撞误差 0。
- Camera 图：`.runtime/door_hinge_20261022/after/return_060.png`、`returned.png`（已查看）。这些证明动作与外观，不是峰值性能验收。
