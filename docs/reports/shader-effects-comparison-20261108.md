## 八种状态及比较约束

| 键 | 内容 | 该状态唯一变化 |
| --- | --- | --- |
| 0 | 已认可材质基准 | 铁／塑料／木材强化保留；六项待比较效果均关闭 |
| 1 | 卡通分层 | 三段逐灯受光与块状高光 |
| 2 | 结构描边 | 模型锐边／开放边的细暗线 |
| 3 | 受光边缘光 | 随真实灯光及阴影变化的窄亮边 |
| 4 | 交叉排线阴影 | 较暗受光区加入表面固定的斜线／交叉线 |
| 5 | 拉丝金属高光 | 金属改用方向性高光，其他材质保留已认可函数 |
| 6 | 明暗交界像素抖动 | 只启用已推广的真实光／影过渡函数 |
| 7 | 原正式材质参考 | 关闭已认可材质强化，保持同机位／灯光／纹理 |

所有状态均使用Forward+／Vulkan，640×360世界分辨率、Nearest显示。此处“渲染效果”指着色方式，不是后端选型实验。正式游戏原有明暗交界网点保持原状；仅比较样板的0号基准将这项可选效果关闭，6号单独开启。角色描边／专用特效与现有层次增强仍属共同底层，不混入待比较的六项。

三种机位都来自同一个GameTestLab正式随机布局／生产美术世界；逐项照片在同一冻结Camera和同一世界状态采集。每项之后都返回0号基准验证逐像素相同，不能把前一项残留当成下一项效果。

## 实现

候选 `.runtime/shader_comparison_20261108/candidate/` 继承已认可材质样板，复用原卡通控制器及原几何边界算法，新增独立状态编排、表面排线与金属高光函数。2049个架构／家具材质用于卡通、描边与表面样式；2276个材质的既有网点开关进入单项状态管理。每次只开启一项，原色贴图、原灯色、碰撞和武器数值保留。

排线按世界位置和表面法向选择投影平面，以32px/m网格定位线条。密度随逐灯受光变化，不读取最终屏幕颜色，也不叠加随机噪声。金属使用切线／副切线方向不同的粗糙度分布，将原各向同性高光改为拉长的分布；只作用于现有finish数据标识的金属面。木、塑料、纸张直接返回已认可的原高光函数。机制参考 [Godot空间Shader](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html) 与 [各向异性说明](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html#anisotropy)，新代码为本地编写。

比较发现旧几何描边控制器缓存了进入样板时的墙体Mesh；后续激活不同房间时，正式U形剖切会更新49个墙体Mesh。新入口的 `adaptive_edges.gd` 在样式选择时以当前剖切重新适配，并保留所有者最新Mesh与实例参数，不把旧房间的墙体恢复回来。此修正在新比较入口内，未擅改旧入口或正式源。

首次更换绘制资源另有少量持续的边缘像素差异：诊断中Mesh／材质／参数身份相同，但首次往返约397像素不同，下一次同样往返0差异；未把它归因为已确认的GPU内部原因。新观察位置现在显式先完成剖切与绘制准备，再呈现基准，随后所有单项均可逐像素还原。准备时保留灯光、阴影与反射，没有以删效果制造对比或性能结果。

原正式材质参考切换前后保存当前活参数，避免材质控制器的初始参数覆盖当前房间的实时剖切／反射状态。
