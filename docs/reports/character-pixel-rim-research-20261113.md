# 像素角色边缘受光：现有链路与实现建议

2026-11-13。范围：代码与官方资料调查，未修改正式角色材质、贴图、灯光或玩法，未制作实机效果样板。

后续状态：同日已完成独立实景小样，见[小样总结果、试玩入口与开销](character-pixel-rim-sample-20261113.md)。下文保留调查阶段结论；正式流程尚未推广。

## 参考图的视觉特征

从截图可见：角色与武器朝向亮处的部分边缘接近白色，背光处保持暗色，亮边并不沿整个人物等宽闭合；头部、手臂和武器存在局部亮面，最亮处略有溢光。这可用光源驱动的轮廓光、局部高光及克制的 Bloom 组合近似。

截图不足以确定参考游戏使用了“3D 角色低分辨率渲染”还是“2D 精灵配合法线和高光”。本报告只判断本工程可采用的实现方式。

## 当前工程核查

| 部分 | 当前状态 | 对实现的影响 |
|---|---|---|
| 角色显示桥 | `dream_3d_actor_depth_bridge.gd` 捕获分件角色，显示在受光 `Sprite3D` 上 | 可复用既有显示与真实灯光，不必替换角色原画 |
| 角色材质 | `lit_pixel_carrier.gdshader` 具有自定义 `light()` | 已有逐灯方向、颜色、衰减和阴影入口 |
| 法线 | 当前角色材质没有设置 `NORMAL_MAP` 或逐像素形体法线 | 现有角色作为一块平面受光，难以出现随身体轮廓变化的局部亮边 |
| 漫反射 | `max(abs(dot(NORMAL,LIGHT)),0.45)`，角色受光倍率默认 0.50 | 当前策略偏向稳定可读性，不会自动构建身体曲面 |
| 可读性底光 | 配置默认 `character_self_emission_strength=0.01` | 与新轮廓光分开；关灯只要求新增边缘光归零 |
| 现有目标亮边 | `_sync_character_readability()` 仅对近战范围内可击中的敌人开启，使用独立高亮颜色和自发光 | 保留其目标提示职责，新的受光效果使用独立参数 |
| 已推广的家具边光 | `office_style_rim.gd` 明确排除含 `capture_texture` 的角色材质，处理模型几何边 | 家具上的边缘光不会自动作用于角色的透明轮廓 |
| 真实空间参考 | 材质已设置参考 `DEPTH`，并将修正位置写入 `LIGHT_VERTEX` | 扩展时保留这些坐标及真实遮挡，避免亮边错位 |
| 投影 | 可见角色不进投影 pass；独立代理负责影子 | 保留此分工，避免重新引入像素自阴影条纹 |

Godot 4.7 的逐灯处理能提供光方向、光色及含距离/阴影影响的衰减值；其标准 Rim 也受真实光影响。当前工程已有自定义光照，因此需要结合角色轮廓扩展，不能仅给平面材质打开一个 Rim 参数就期待出现人物形状的亮边。[官方逐灯接口](https://docs.godotengine.org/en/4.7/tutorials/shaders/shader_reference/spatial_shader.html#light-built-ins)、[官方 Rim 说明](https://docs.godotengine.org/en/4.7/tutorials/3d/standard_material_3d.html#rim)

## 推荐路线：透明轮廓方向＋真实逐灯响应

1. 从角色合成捕获的 Alpha 邻域提取轮廓，生成窄的内侧边缘带和朝外方向。以现有像素格为基准，在实际 640×360 Camera 中校正为约 1 个游戏像素，强受光处再适量变宽。
2. 将边缘方向转换到与当前灯光一致的坐标空间，构造供轮廓光使用的近似法线。角色普通漫反射可以先保持，不必一次重做整个身体的着色。
3. 在现有 `light()` 内添加独立受光项，组合边缘带、朝光方向、背光/侧光权重、灯光颜色和实际衰减。新增效果不写恒定自发光，不创建角色专属追随灯。
4. 身体、环形手臂、手持武器及附件沿用相同投影关系。分件接合处需要抑制内部亮缝，武器随握持旋转后受光方向也应保持正确。
5. 沿用当前 Nearest、实际深度与阴影。先核对纯轮廓光，再使用场景已有的克制溢光，不提高全局 Bloom 来掩盖形体问题。

示意关系：

`新增边缘亮度 = 边缘带 × 朝光/逆光权重 × 实际灯光颜色 × 实际衰减和阴影 × 强度`

深色原画的黑边可能把纯漫反射高光压掉，这是小样必须单独处理的情况。需测试独立受光高光的输出通道与现有 `specular_disabled`、自定义光照的组合，避免用除以暗色的方式制造失控增亮。

这条路线主要解决外轮廓受光，设计上可复用已有角色捕获。邻域纹理采样仍会增加 GPU 工作；实际开销需在样板中测量，不能在实现前承诺零开销。

## 更接近参考图的第二步：像素法线与高光控制图

头发分束、脸颊、手臂、衣褶等内部形体需要额外的法线或局部高光控制。它们必须与原图集逐帧、逐朝向、分件旋转/翻转同步。原画的颜色明暗不应直接当作高度：深色头发不代表凹陷。

可先为头发、衣服和武器设置不同的高光响应，再对关键朝向补原分辨率的辅助贴图。Godot 的法线贴图改变受光角度而不改变几何，适合保留原角色轮廓。[官方法线贴图说明](https://docs.godotengine.org/en/4.7/tutorials/3d/standard_material_3d.html#normal-map)

| 路线 | 能得到的效果 | 边界 |
|---|---|---|
| 透明轮廓方向＋逐灯亮边 | 头发、身体、四肢和武器外边缘随光换侧 | 内部衣褶与脸部立体感有限 |
| 另加像素法线／高光控制图 | 进一步塑造头发、皮肤、布料与金属亮面 | 需要维护八朝向、动作分件和额外贴图链路 |

## 建议的小样范围与验收

先用玩家和一名人形敌人，包含空手与持枪，在同镜头下比较原版／轮廓光版。正式材质保持，样板独立。

- 左、右、后方灯光切换时，亮边对应换侧；关闭灯光后新增效果归零。
- 墙、实体门、高柜与灯光阴影能够遮掉新增亮边，保留当前遮挡关系。
- 八方向、站立、行走、翻滚、挥击和手臂归位不产生亮边错位或关节亮缝。
- 近战目标提示、受击白闪、烟雾剪影、看手机和死亡流程保持原职责。
- 使用相同灯光和 Camera 的正常速度对照，核查移动时的像素稳定性，并单独记录角色数量增加后的开销。

当前结论：可实现同类效果，优先验证轮廓方向与真实灯光，再按视觉差距决定补多少内部法线细节。尚无本轮实机样板或性能验收结果。
