# 独立角色椭圆双手样板

后续状态：球棍握柄修正及正式玩家接入已完成，见 `player-hand-formal-integration-20261023.md`。以下记录的是最初独立样板阶段的范围。

## 范围

仅新增独立预览、显示控制器及测试；没有修改正式玩家、攻击判定、伤害、移速、弹速、Main 或随机楼层入口。未导入 Woo Woo 的素材或脚本。

入口：`res://scenes/dream/preview/CharacterHandOrbitSample.tscn`。Godot 打开该场景后按 F6，而不是 F5。

左侧是固定双手的结构对照，不是正式游戏的完整战斗回放；右侧是新显示方式。鼠标转向，WASD 移动，左键播放动作，空格演示冲刺，1/2/3/4 切换拳头/手枪/步枪/球棍，T 自动转向。样板不产生子弹或伤害。

## 实现

- 复用自己的玩家头、身体、脚、双手、武器和刘海素材。
- 双手地面轨迹为横向半径 12px、纵向半径 6px 的椭圆；地面深度负责身前/身后排序，独立高度负责手的显示位置。
- 独立保存平滑跟随状态，避免现有步行动画重置手的位置；指数插值不依赖刷新率。
- 枪械使用主手及支撑手握点；球棍有蓄力、扫击、回收姿态。后续已纠正握持方向：原图左端是木柄、右端是缠铁丝的击打端，不水平翻转原图。
- 复用现有前后/左右头部与身体图和刘海弹簧，不凭空补出缺失的八方向原画。
- 玩家及武器的处理完全禁用，样板驱动的是显示节点。整个像素角色通过透明 SubViewport 放到独立 3D 场景中，由 Camera3D 实际渲染；不是正式角色深度桥的集成验证。
- 样板冲刺仅用于观察移动时双手及刘海的跟随，不代表正式冲刺的参数和判定。

## 验证

- 新样板无界面检查：116 项通过，退出码 0。Dummy 渲染器退出时仍报告 10 个资源未释放及 ObjectDB 提示；不宣称此路径无警告。
- RTX 5070 Ti / Compatibility 实际 Camera3D 检查：116 项通过，退出码 0，无上述退出提示；窗口最小化且不抢焦点。
- 原有 `melee_presentation_test.gd`：229 项通过。
- 原有 `player_side_bangs_test.gd`：24 项通过。
- 合计 485 项断言通过。检查范围不包含正式楼层联动或峰值性能，不能据此声称正式游戏已完成改造。

GPU 产物位于 `.runtime/character_hand_orbit_20261023/`：16 张方向/装备截图、120 帧球棍转向动作和 `hand_orbit_camera.mp4`。视频是固定 30Hz 步进的动态验收记录，不是实机 FPS 测量。
