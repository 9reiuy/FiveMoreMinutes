# 岸线交错、山体融合与防波带 — 2026-10-28

独立夜岸本轮修正；使用同一个 `tools/run_night_coast.cmd` 启动。Codex 在当前工作树独立完成，没有提交、无并行代理。

## 改动

- 上坡与横向坡脚放缓，台地中心线和宽度加入非对称变化；山体轮廓增加低幅起伏，降低直立墙面感。角色与地形使用同一高度函数，保留从较低处登高望海的路线。
- 沙滩从大块平面改为有低幅高程变化的缓坡。岸线加入左右凹湾、浅水入口、伸入海面的沙嘴；退潮与泡沫跟随实际弯曲岸线。
- 新增 `coast_shape.gdshaderinc` 和 256×256 浮点岸形数据图。CPU 高度函数生成几何和流动地形，同时向水面、沙滩材质提供相同岸线/障碍距离数据，避免材质仍画直线、模型已经弯曲的错位。
- 按用户确认的含义制作不规则礁石防波带和少量消波块：10 个低多边形礁石、2 个四脚混凝土消波块；不排成密闭直墙，留有水道。
- 礁石和消波块映射到近岸流动网格的固体区域；视觉上沿石块边缘补充断续撞击泡沫。消波块采用简化圆形水力占地，而非精细计算四条支腿间的水流；不宣称已求解三维波浪衍射、翻卷或真实消波效率。

保留深红海面、连续波纹、少量暗星、云遮月和海天交界 SOS 灯点。没有改动正式办公楼或接入正式血迹。
