# 游戏辅助功能：自动跳跃与屏幕抖动

## 最终行为

- 设置新增“游戏辅助功能”，提供“自动跳跃”“屏幕抖动”两个开关，默认开启。
- 主菜单、暂停设置、手机设置读取同一 SettingsManager；保存到用户配置的 accessibility 分区。旧配置缺少这两项时使用开启的默认值。测试使用隔离用户目录，不覆盖真实玩家设置。
- 自动跳跃沿用现有翻越动作、碰撞例外、路径与落点检查。仅玩家有移动意图、朝向低矮家具且接近其碰撞边缘时触发；沿边、远处、背向或站立不触发。自动检测使用附近家具的原生物理宽相查询，不逐帧遍历整层家具。
- 高柜、禁翻家具、悬空家具、被挡落点、缺失地板及坑洞不触发。落点检查包含角色身体周边地板；暂停、剧情移动和控制锁定不触发。关闭设置只阻止新的自动动作，不中断正在安全完成的翻越。
- 空格仍是现有鼠标方向冲刺；自动跳跃不消耗冲刺，也不修改攻击和移动数值。
- 关闭屏幕抖动后清除当前镜头冲击，拒绝后续镜头冲击，并关闭电梯镜头震动；电梯声音不关闭。镜头正常跟随、瞄准偏移、剧情／手机镜头、武器动作与游戏后坐力数值不变。暂停期间切换也会同步清理，重新开启不重播旧冲击。

## 验证

全程使用静音音频驱动。GPU 测试仅最小化其自身窗口，通过正式 Main 进入游戏并使用正式摄像机。

| 项目 | 结果 |
| --- | --- |

| 正式入口与鼠标菜单操作、正常移动自动翻越、关闭后阻挡 | 12 项通过（原分辨率／关闭滤镜） |
| 同上，像素化与方案 1 | 12 项通过 |
| 设置尺寸与阴影设置回归 | 通过，设置面板最小尺寸仍为 280×230 |
| 冲刺纯逻辑／正式世界 | 92／22 项通过 |
| 跨层生命周期 | 729 项通过 |
| 低矮家具弹道 | 187 项通过 |
| 玩家目标描边 | 16 项通过 |
| 弹反、前摇、电闸 | 71 项通过 |
| 相关差异检查 | 通过 |

覆盖站立、沿边、背向、接近、关闭设置、手动旧翻越入口、合法落地、碰撞例外清理、高家具、悬空家具、受阻落点、楼外无地板、暂停和控制锁定。GPU 实测仅按移动键触发翻越，没有按空格或直接调用动作启动函数。

部分测试退出时仍出现已有 ObjectDB／资源、GPU 纹理释放日志；不将功能断言通过等同于退出零警告。未执行全量历史测试或全局性能基准。
