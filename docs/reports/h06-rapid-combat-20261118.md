# H06 快速扫射、炮击后坐与导弹齐射

2026-11-18 已接入第一章电梯大厅和原 `Run_H06_Boss_Test.cmd`。按 **1** 测炮击、**2** 测锁定导弹、**4** 测单束激光、**7** 测半血六束、**8** 测全场齐射。按 **0** 回到正常循环，**F5** 重开。

| 招式 | 实机结果 |
|---|---|
| 单束激光 | 上盖打开后加速扫完一圈。物理帧实测约 1.13 秒，扫射期间机身没有位移或转向，墙与立柱截断光束。 |
| 半血六束 | 原上盖抬起，六束以 60° 间距同步扫过 90°，约 0.62 秒。每场触发一次。 |
| 锁定导弹 | 每枚锁定后约 0.17 秒出管，沿连续短弧飞向锁定点。出管到落点约 0.53 至 0.78 秒，落点预警保留到该枚命中。 |
| 炮击后坐 | 炮管回缩时机身也通过物理碰撞后挫。空地实测约 0.73 米，贴墙时后挫量受限。 |
| 招式衔接 | 收招 0.24 秒，准备下一次起手间隔 0.16 秒。末枚导弹出管后即可进入收招，两种导弹都能在上一轮的末枚落地前接下一招。 |
| 三排齐射 | 三条预警各横贯大厅，每排六枚，从远至近连续落地。排间留有安全空档，每排命中只结算一次。 |

正式代码通过 47 项攻击、32 项测试入口、21 项普通关卡进场与退场、17 项六足动作、9 项实际 Camera 检查。普通关卡实测半血旋转与三排齐射，并在尚有导弹飞行时击败 H06，确认剩余导弹、预警和伤害被清除，电梯解锁。固定全览 Camera 共采集 79 张原始帧。
