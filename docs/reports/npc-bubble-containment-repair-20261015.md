# NPC 气泡文字与被动提示修正

文字原本由 MarginContainer/VBoxContainer 布局，容器最小尺寸会超过正在动画中的气泡；原高度估算也没有使用 Label 的实际换行结果。现改为独立文字视口，在内部范围裁切，文字按目标宽度排版；最终高度依据 Label 自身的换行与最小高度计算。进度条留独立空间，长句完整显示，扩展期间文字不会越过框体。

被动 NPC 的“...”现在是 GrowingDialogueBubble 同一场景的独立实例，复用背景、字体、动态角标和缓入缓出。提示文字居中，不显示倒计时，靠近提示仍不阻止 E 开始对话；进入对话、离开或转向电梯时提示消退。通用交互提示继续用于电梯等交互。

五组相关无窗口回归通过，新增 NPC 检查 97 项通过，包含逐字扩展阶段的文字视口边界、与进度条的分离、最终完整长句的多行显示及无隐藏行。原气泡、控制器、教程和接待交互范围检查均通过。

实际 Main GPU Camera 流程 19 项通过，包含同款提示、E/左键跳段、五段台词、角标跟随、Esc 退出及普通行走后进入正式楼层。RTX 5070 Ti / Compatibility，1920×1080 输出，窗口屏幕外启动并最小化。已检查首字、换行和长句截图。退出仍有原有 GUI 锚点警告、两项纹理资源退出清理诊断；未将这些诊断声明为已解决。
