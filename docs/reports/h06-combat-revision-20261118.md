# H06 六足踏转、半血攻击和后方弱点

2026-11-18 已接入第一章和 `Run_H06_Boss_Test.cmd`。测试入口中 1–5 重复原五招，6 把玩家放到脚边并演示踩踏，7 把 Boss 血量降到一半以下并演示六向激光。6、7 的单次演示结束后回到正常循环，F5 重开。

| 行为 | 实现与验证 |
|---|---|
| 旋转激光 | 原先约 6.61 秒。现在六足踏步带动整机转向，前慢后快，一圈实测 3.02 秒、23 次踏步。短预警结束时移除地面范围，只保留实际光束。墙体截断光束，末段快速扫过时也检查相邻物理帧之间的角度。 |
| 六枚导弹 | 发射架提前抬起，每枚锁定后约 0.17 秒出管。前一枚离开后才显示下一点。各自目标锁定后保存，落弹仍按最后一次锁定时的屏幕纵向顺序从上到下。 |
| 跳砸与冲刺 | 跳砸预警 0.525 秒并加快下压和蹬地，冲刺预警 0.50 秒。跳砸实际半径由 2.45 增至 4.6 米，地面圆形同步。有空地时会保留朝向横跳，攻击间隙也能横向踏步。落地尘烟从机腹和足端向外扩散，普通出场落地同样使用扩大后的尘烟。 |
| 近身脚踩 | 就绪时按玩家位置选可达的实际足端，抬起、落脚，只在接地时结算。落点周围有 1.45 米圆形提示和短暂尘烟。 |
| 半血攻击 | 血量低于 80 时排到当前攻击之后，每场只触发一次。抬起原上盖，露出发射器并同时射出间隔 60° 的六束激光，结束后合盖。 |
| 前侧防护 | 淡金色护盾随车身转向。前、侧和腿部拦截实际子弹，包括带穿透的子弹。后方青色格栅为弱点，从正后方射击实际扣血。 |

独立白盒在正式美术大厅通过 38 项攻击规则、29 项操作入口和 11 项实际 Camera 检查。接入后通过普通第一章入口 19 项、原六足运动 17 项、实机落地与侧腿阻挡 10 项及 Main 入口 6 项。最终时序调整后复验了攻击规则。Main 退出仍打印此前已有的纹理 RID 清理告警，6 项入口断言通过。
