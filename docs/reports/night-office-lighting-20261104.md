# NIGHT-OFFICE-002 有屋顶的夜间办公室

2026-11-04。READY_FOR_REVIEW。交付范围为独立小样。

N 将夜间场景分成灯下的工作区、窗边的冷光和暗下来的城市。建议先用 N 试玩确认这些明暗关系。N 在本轮仍有超过 16.667 ms 的帧，性能数据留作独立小样的配对结果。正式精简灯光已解决战斗尖峰的用户反馈仍有效。

## 实施

以 LIGHT-REFLECT-001 冻结副本为来源。复制 8,331 个输入并按当前正式工作树同步发生变化的角色深度桥。先前 A/B/C、副本和记录仍可单独访问。新副本位于 `.runtime/night_office_lighting_20261104/project/`，存档和设置由专用启动器隔离。冻结共 8336 个文件。复核时冻结输入变化为零。 [来源清单](../../.runtime/night_office_lighting_20261104/source_manifest.json) · [冻结散列](../../.runtime/night_office_lighting_20261104/frozen_manifest.json) · [正式树边界审计](../../.runtime/night_office_lighting_20261104/boundary.json)

原室内主光和补光均为方向光，叠加 0.52 的全层底光。旧 B 增加窗光后仍以 0.36 的底光配合两束室内方向光。N 把弱环境底光设为 0.18，城市材质单独按原强度的 34% 显示。保留 640×360 游戏摄像机、调色、角色原画、橙血、碰撞与战斗内容。

N 在有灯具计划的当前房间使用一盏投影聚光灯，位置、方向与照射角来自原办公灯具。灯位固定在屋顶下方。窗光采用一束整层共用的固定冷光，沿用美术参考的几何遮挡思路，复用原墙体、窗洞、窗框和家具。原屋顶平面在 Compatibility 的诊断中只带来很小的遮挡差异，N 将相同楼层轮廓做成厚 0.18 单位的闭合遮光顶，进入阴影通道。候选最多同时两盏建筑投影光，原生战斗与单位功能光继续工作。 [候选实现](../../.runtime/night_office_lighting_20261104/project/night_office/lights.gd)

平面反射沿用 C 的 320×180 镜像缓冲和 512 局部阴影图，每次绘制更新。主场景与镜像使用同一组灯和同样的弱环境参数。地毯的镜像强度为零。关闭两组光后，镜像非透明像素的平均 RGB 亮度指标由 29.8 降至 23.4。这是反射光响应的辅助读数。 [镜像实拍](../../.runtime/night_office_lighting_20261104/evidence/mirror_both_sources.png)

## 画面和功能

实际 Camera 的 34 项检查通过。四态对照暂停在同一姿势，仅在诊断中隔离电梯和无人机等功能光。移除屋顶后，选区有 27,771 个像素变化超过 2/255，恢复屋顶后该选区与原室外光画面匹配。封窗使该区域的室外光差异量下降 96.4%，办公灯依然有效。窗边光斑及遮挡可以从实际开口追到地面。

正常速度片段含原角色移动和镜头跟随、家具及人物反射、原生门受力和从房间 7 走入房间 4。收录实际时钟时间戳并编码为 30fps 播放文件。原始采集帧率随截图读回变化。重建和退出时上一套镜像视口均被释放。 [移动片段](../../.runtime/night_office_lighting_20261104/evidence/N_walk_door.mp4) · [真实过门](../../.runtime/night_office_lighting_20261104/evidence/N_room_transition.mp4)

## 限制与下一步

当前每个房间最多选一盏原灯具。大开间边缘较暗，缺少灯具计划的房间以弱底光和可达窗光为主。背光立面采用单一方向的遮挡结果，没有额外漫射窗灯。镜像继承平面方案的取景边缘淡出及部分场景特效排除，验收覆盖这一层与换房流程。

先请用户比较 N 的灯下通路、暗角和窗边层次。若画面方向合适，下一步在同一 N 布光下做镜像开关配对，测量它对战斗慢帧的独立影响，再决定是否继续优化。 [交付文件与散列](../../.runtime/night_office_lighting_20261104/delivery_manifest.json)
