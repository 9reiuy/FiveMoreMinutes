# H06 直达测试入口与渐变预警

2026-11-17。当前 Codex 独立完成，已接入；未导出。

## 使用

双击工程根目录 `Run_H06_Boss_Test.cmd`。直接加载实际电梯大厅、玩家和H06，不经过前面的关卡、追逐或跳落出场。背景音乐关闭，常规音效保留；独立用户目录为 `.runtime/h06_boss_test/user_data`，不修改主游戏存档或音量。

| 操作 | 行为 |
|---|---|
| 1—5，或点击面板 | 分别重复直线炮击、六枚导弹、蓄力跳砸、旋转激光、蓄力冲刺 |
| 0 | 从炮击开始依次循环五种攻击 |
| P | 暂停／继续Boss，玩家仍可移动 |
| F2 | 开关测试无敌，默认开启；关闭后使用原玩家伤害逻辑 |
| F1 | 显隐操作面板 |
| F5 | 重开并直接回到Boss战 |

常规移动、翻滚、射击和换弹保留。配备实际突击步枪，Boss血量仍为160，可正常击败。切换攻击会清除旧预警和弹体，将机甲放回初始位置；跳跃中切换也会恢复地面支撑。面板125×229逻辑像素，点击面板不向场内射击。

## 预警样式

H06圆形与长条攻击预警改为贴地Shader：完整发亮红边、向内渐变、边缘柔和光晕和半透明红色填充。圆形带一圈较淡的外环。蓄力期间填充逐渐覆盖范围，完整边界始终保留；导弹飞行时继续推进各自圆形标记的填充。伤害、范围、锁定点和攻击时序没有因此扩大或改变。

`h06_attack_warning.gdshader`使用实际米制尺寸计算轮廓宽度，长条不会随长宽比例把光边拉粗；额外0.28m仅容纳视觉光晕。预警不投影，不新增灯或屏幕效果。每个Boss复用一块长条与六块圆形平面，结束、切招、死亡和退出都隐藏／释放完整效果。

该样式在独立检查与连续战斗对照通过后，已默认用于普通第一章H06。旧预警只保留内部对照开关，无新玩家设置。
