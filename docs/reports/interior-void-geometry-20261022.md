# 内部空区域改用三维黑暗封底 · 2026-10-22

## 修改范围

- 正式随机楼层及共享显示系统的样板间不再创建 `OutsideFootprintMaskLayer` / `OutsideBlackGradient`，不再运行整屏涂黑着色器。
- 复用现有外部洪泛分类：仅为不属于可走地板、且不与外部连通的空格生成黑色封底。建筑外部、与外部连通的缺口继续显示城市。
- 封底低于地板 0.08 世界单位，边壁闭合到地板高度以防斜视露缝。使用不受光照影响的不透明黑色材质、正常深度测试，不投影；每层一个合并网格。
- 不增加碰撞、导航、地板格子，不修改布局、摄像机参数、伤害、冲刺跨空隙或掉落判定。
- 城市直接读取摄像机快照，不再通过复制和字符串改写黑色蒙版着色器获取数据；城市几何不投到内部封闭空洞内。
- 旧 `_update_outside_mask()` 名称作为现有调用方的兼容入口保留，功能仅为摄像机快照及轿厢阶段封底可见性。旧遮罩属性为空，旧着色器文件未删除、但本路径不再加载或绘制它。
