# 爆炸、集装箱落地与六足移动音效接入

用户已确认选用四条试听并授权接入。现已接入现有游戏事件及 H06 六足机器人的真实步态，音量按用户要求压低。

## 已接入的行为

- 爆炸使用第 1 条。覆盖共享燃烧/爆炸控制器、机器人与无人机共用死亡演出、叉车销毁、H06 爆炸攻击与货运区爆破、列车车钩爆炸。
  叉车移除了原破墙声叠加；其他普通破墙事件仍使用原录音。
- 集装箱落地使用第 2 条。货运区封路落箱和竞技场吊箱在实际触地时触发；吊箱砸到六足机身也触发该金属撞击。
  落地后因下方车辆立即破碎的情况只播一次落地声，避免再叠更响的旧破墙声。
- 六足移动使用第 3、4 条。每次真实交替三足落地触发一声重落脚，关节层按实际摆腿运动播放并淡入淡出。
  固定两条交替脚步声部与一条关节声部，跟随原机体跨区；静止后没有持续关节循环。
  暂停、跳跃阶段、隐藏、停用/战败与卸载均已处理。

四种声音都走现有 Environment → WorldSFX → SFX 音量路径，并遵循原慢动作音高。
空间定位使用线性范围衰减，避免驾驶员或相机靠近声源后出现额外增益。
共享声音池每次复用都会恢复对应衰减模式，其他旧事件保持原设置。
