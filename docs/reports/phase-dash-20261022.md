# Space 穿墙冲刺（2026-10-22）

## 已接入正式玩家输入

- Space 按下立即朝当时鼠标方向冲刺，168 游戏像素／0.14 秒；长按不再进入旧预演，也不自动连续冲刺。
- 到达后沿实际起点—终点执行一次胶囊查询，半径 16；每个敌人只结算一次。读取近战携带槽的原伤害，未携带近战武器时读取拳头伤害；不切换当前枪械、不修改普通近战范围。
- 沿途忽略墙、门、玻璃、家具和敌人身体，不推撞或破坏障碍；终点以原身体碰撞形状和整层地板、坑洞判定验证。终点失效时退回合法位置；整条路线被动态障碍覆盖时执行无攻击的安全恢复。
- 仅冲刺位移期间无敌。此次胶囊直接击杀至少一名敌人就归还一格充能；多杀不叠加，延迟死亡不刷新。非击杀冷却 0.8 秒；多充能升级的额外充能仍按冷却恢复。
- 单个可复用像素拖尾和三个只显示的残影，无额外角色逻辑、AI 或捕获视口。投影材质保留动态实例身份，避免反射注册后冻结透明度。效果归属当前楼层，跨层销毁。
- 旧飞扑／预演方法保留兼容，但正式 Space 输入不再调用；未改鼠标攻击、地图旋转、摄像机、血色和敌人战斗数值。
