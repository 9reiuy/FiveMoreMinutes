# 近战与叉车撞击卡肉核查

2026-11-17，当前正式共享战斗路径已接入卡肉，运行中有效，本轮无需新增或重复接入游戏逻辑。

## 当前行为

- 玩家棒击和书本挥击由整次挥击的 `melee_impact` 事件，经 `DreamPlayer._on_melee_impact` 请求一次卡肉。单个敌人的受伤回调在挥击结算范围内抑制重复全局反馈。
- 普通拳击、脚踢命中，以及叉车撞敌人的普通和致命受伤，经 `EmployeeEnemy.take_damage` → `request_combat_impact` → `request_hit_stop` 接入共享时间控制器。
- 配置为轻20毫秒、中40毫秒、重70毫秒，卡肉期间时间倍率为0.05。时间控制器用真实时间结束停顿，保留最短触发间隔和正在停顿时的去重。
- 实测普通拳脚和书本20毫秒，棒击40毫秒。此次叉车正撞在接触前加速至10.5米/秒，触发70毫秒；倒车4.8米/秒触发40毫秒。车辆其余档位仍按真实撞击力度分级。

## 验证

新增 `tests/combat_hitstop_integration_test.gd`，复用真实扫掠碰撞、白盒、正式美术测试场及当前1-2叉车入口。保持时间控制器运行，读取命中后的实际 `Engine.time_scale`、停顿令牌、剩余时间和恢复状态。

144项检查通过，失败0；PID60728，退出码0。Forward+ / Vulkan、1280×720原生显示、WASAPI，启动前使用私有静音配置并检查设置重载，最终引擎日志无ERROR/WARNING。

覆盖正撞、倒车、致命撞击、棒击和书本普通命中／一次挥击击杀3名敌人、拳击、脚踢、空挥与场景清理。确认有效命中实际降至0.05，停顿只触发一次，到期恢复1.0；空挥不触发。
