# 近战武器左右离身距离修正

## 根因与修改

用户截图所示的“左边贴身、右边外飘”不只是挥击角度问题。球棍在显示层下移了 18px，但正式 3D 捕获还会根据地图/相机朝向旋转 WeaponRoot 的像素基底。这使固定向下的偏移也被旋转，产生两边共用的侧向漂移。前一轮仅检查逻辑命中扇区和源节点握柄，没有覆盖这一正式捕获坐标差异。

新增 bridge 的 `compensate_weapon_pixel_offset`，将身体/画面空间的下移偏移逆旋转到武器捕获坐标，再经过现有挥击父节点的逆基底。如此待机、转向、挥击时的肩部下移保持竖直，左右握点不再整体向同一侧漂移。

保留正确的木柄握点与双手间距，不改攻击半径、伤害、扇区、冷却、枪口或物理形状；未修改左右挥击的权威角时钟。本次针对用户明确指出的离身偏移，而不是更改战斗数值。

补充生命周期保护：独立玩家尚无 bridge 时不读取缺失元数据；场景销毁时相机不在树中则不做投影查询。
