# 独立样板浮尘 V2：顺向漂移与短促闪亮

本次纠正 V1 “固定小范围晃动、颜色几乎不变”的问题。仍仅在 FurnitureTextureReview 独立样板中生效，未接入正式随机楼层，未修改家具、灯光、摄像机、战斗或 UI。

## 调整

- 常规漂移速度为 0.18–0.28 世界单位/秒；V1 主要方向约 0.023–0.043，因此大多数颗粒约快 5–8 倍，具体取决于种子。
- 从单格内的 0.3 单位小晃动，改为通常约 1.3–2.4 单位的顺向路径；受房间边界限制时缩短路径或换方向。每条路径以 0.1 格间隔检查，并检查 0.13 格边缘净空，整条路径仍在同一个实际室内房间。
- 出生/消失淡隐后重置位置，不在可见时突然回跳；轻微横摆只是附加项，不再是主要运动。
- 每颗独立 3.2–7.5 秒闪亮周期，单次约 0.2 秒明暗脉冲。平时低亮环境色，闪亮时短暂过渡到带轻微冷暖差异的浅灰/亮白；不是常亮、同步闪烁或彩色纸屑。
- 闪亮以材质实现，不增加 Light3D，不改变场景照明。仍接受遮挡和世界调色板。
- 数量/批次仍为种子 120 的 90 颗、13 批，最多 192 颗。路径只在构建时检查，运行时仍只更新一个 GPU 时钟；私有 RNG、暂停、F8 对照及跨层清理保持不变。

## 真实摄像机验证

- `sample_indoor_dust_test.gd`：312 项通过，包括完整路径净空、正向移动、稀疏非同步闪亮、数量/所属房间、RNG、暂停和再生成。
- `sample_indoor_dust_camera_test.gd`：13 项通过。检查原生/像素化及 Palette 组合、单颗显示、物体遮挡、闪亮和实际位移。
- 单颗在最终图片中，0.7 秒移动约 **10.76 个物理输出像素**。这个数来自两张真实图片的颗粒像素中心，而不仅是公式投影。
- 同一颗粒字面区域的 RGB 平均亮度峰值：不启用 Palette 时从约 **0.646 → 1.000**；启用方案 1 时约 **0.620 → 0.959**。证明明暗闪亮没有被调色板抹平。
- 单颗普通可见状态在自己的投影区域有 18 个截图像素变化；被不透明几何体挡住后该区域开/关差异为零。
- 全场景 A/B 仍受既有桌面屏幕材质的时间变化影响，因此整图差异不当作纯浮尘贡献。关键结论均由单颗区域隔离验证。
- 6 秒静音预览使用正式样板 Camera3D、25fps、每帧 40ms 的确定性效果时间，不是帧率性能录像。
