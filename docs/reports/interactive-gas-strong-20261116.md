# 交互雾增强版

该体积版本保留用于 V 键对照。当前白盒默认使用灭火器烟团外观，见 [灭火器外观试用记录](interactive-gas-extinguisher-20261116.md)。

用户反馈上一版太弱。本轮仍限于独立白盒，入口 `Run_Interactive_Gas.cmd`，未接入正式关卡；不改武器伤害、射速、人物速度与翻滚位移。

## 当前效果

- 改为沿实际 Camera 视线积分三维密度纹理，40 个视线采样，保留团块起伏和较窄通道；不再叠加上一版原生 FogVolume 的密度。
- 初始密度倍率 1.35 → 2.25；自然卷动驱动力 0.13 → 0.38，速度衰减 0.72 → 0.50，雾体运动更明显。
- 子弹扰动半径 0.38 → 0.55 米，清除增益 3.4 → 4.6，推力 1.8 → 2.8。
- 行走／翻滚半径分别改为 0.80／1.15 米，推力增益改为 0.28／0.65。翻滚清除增益由 0.16 调至 0.42，走动加入轻量排雾。
- 身体扰动从脚边球形范围扩展到躯干高度，避免上方未扰动的雾盖住尾流。所有作用仍输入同一流体网格，保留墙体／障碍物掩码与回填。

## 渲染范围与边界

白盒两盏真实 OmniLight 的位置、颜色、范围、能量逐帧传入，另预留两个槽位给实际枪口闪光。雾内向光源方向进行 6 次密度／实体掩码采样，近似内部遮光；沿视线累积透射率。深度纹理限制积分终点，前景不透明物体不会被雾覆盖。

这是有界的单次散射与环境回光近似，不是完整多重散射或引擎任意光源自动接入。白盒最多四个光源；其他关卡、聚光灯、玻璃等透明表面排序及多烟团须另行验证。原生体积雾关闭，因此不再改动全局 froxel 分辨率，也没有两个密度渲染器重叠。

流体网格仍为 64×24×64，30 Hz 更新，24 次压力迭代。显示直接读取主渲染设备的密度与障碍物纹理，无正常运行时 CPU 密度读回。

[Godot 原生 Fog Shader 文档](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/fog_shader.html)说明其细节受相机 froxel 网格约束；本轮独立积分是针对该白盒的显示选择。

## 实机验证

`tests/interactive_gas_whitebox_test.gd` 在默认 640×360 世界视口下通过 30 项检查；关闭像素化的 1280×720 世界视口也通过相同 30 项检查。输出均为 1280×720，使用 Godot 4.7.1、Forward+/Vulkan、RTX 5070 Ti，私有静音 WASAPI 配置与真实后台 GPU 绘制。

覆盖 GPU 有限性、实体内零密度、真实子弹输入、走动、飞扑翻滚、回填、完整重建与纹理释放；新增逐灯画面差异和前景遮挡画面检查。前景绿色遮挡板中心在开／关雾时 RGB 最大误差为 0；两个侧灯单独关闭时均引起可测的雾体画面变化。

前景测试初次因混用世界视口坐标和窗口图像坐标失败，已改为经过正式显示层转换取样；随后两种分辨率均通过。原始失败日志保留，没有把失败记录当作通过证据。

固定弹道区域密度总量 303.703 → 4.684，24 步回填后 42.973。实际 Camera 已检查静态雾团、射击通道、行走与翻滚录制；数据只验证模拟，视觉由实机画面单独评价。

证据目录 `.runtime/interactive_gas_strong_20261116/`，关闭像素化对照在其 `native/` 子目录。各含静帧、90 帧三段动作录制、`interactive_gas.webp`、原画幅视频、`frame_times.csv`、`result.json`、`summary.json`。上一版源码局部备份在 `previous_source/`。

默认模式有效日志：`.runtime/interactive_gas_20261116/strong_verified.log`，引擎 PID 71684，退出 0。关闭像素化有效日志：`strong_native.log`，引擎 PID 60440，退出 0。

- `tests/interactive_gas_whitebox_test.gd`：30 项实际验证和显示层坐标转换。
