# NIGHT-OFFICE-003｜顾问首轮验收

2026-11-04。结论：**功能与照明覆盖部分通过，等成本要求未通过，任务整体不予通过；N3 保留为独立候选。正式游戏不接入。** 退回同一灯光负责人做范围明确的成本返修，不收回已拆给其他聊天的 VISUAL-004。

顾问读取执行报告、40 项结果、原始计时汇总的结构与样本、供电审计、冻结报告；实际查看 N2/N3 远端工位 Camera 对照与真实电闸通电/断电截图，抽查六个关键源文件散列零不一致。没有重跑游戏，也没有把读取视频时间戳等同于完整观看视频。

## 可以接受的阶段结果

- 远端工位和相邻通路照明有改善，整体仍保留夜间明暗层次。测试路线 7→4→6→4→7 的固定灯位/开启/能量检查通过，断电后 7→4→7 仍关闭；原先进房渐亮逻辑不再作为验收目标。
- 40 项检查零失败；真实电闸输入在原交互距离内触发，带有后台输入时序适配，不能据此称为无人值守的完整玩家实玩。真实弹丸碰撞分发损坏电闸及第二种子重建/释放均有记录。
- 供电审计登记 153 个灯节点、129 个显示/灯具候选，当前样本断电后的有效人造光源和可见 StandardMaterial 发光为空；截图中办公照明显著消失，自然窗光仍在。覆盖范围以本次节点/材质及事件清单为限。电闸语义指示、交互标记和血色保留，不把它们视作实际照明贡献。
- 执行者冻结报告记录 8343 项无漂移。VISUAL-004 撤回前只有调查，五项未实施、未纳入 N3 冻结；用户最新无调色默认、纯白冲刺、角色/无人机修复仍由另外三位负责。

## 未通过的硬约束

本轮走动配对方向一致，不再能只以背景波动解释成本差异：N2 的 P50 为 7.985 / 8.460 ms，N3 为 12.050 / 11.344 ms，分别多 4.065 / 2.884 ms。主视口与镜像 GPU 中位诊断均增加，战斗仍有大量超 16.667 ms 帧。它表明本独立候选未达到“不增加当前消耗”，不推翻用户对正式精简灯光版的实测修复。

本种子 N3 常亮 23 盏办公聚光灯，其中 15 盏带阴影，而 N2 通常只有当前房间一盏室内投影。全楼照明常驻不要求所有阴影每帧都重复计算。当前还没有逐项隔离证据，不能直接宣布全部增长就是阴影图造成。

断电调用 CPU 为 15.39–18.99 ms，需单独返修，避免把持续开销转成操作尖峰。顾问读到 `n3_power.gd::_gate_render_sources()` 断电时复制发光材质、送电时清空暗材质引用，且黑暗时逐帧扫描登记源；这是应分析的实现线索，不是已完成计时归因。

一组 N2 跨门断电区间只有一帧，一轮 N2 战斗断电只有三帧，不能据它们判定断电比较通过。视口 CPU/GPU 是辅助诊断，不等同于完整帧耗时。显存变化含重建/缓存顺序，应单列，不能忽略。

## R1 最终内部复核与统一移交

顾问通过状态快照主动取得 R1 完成结果，读取 `cost_r1/REPORT.md`、`HANDOFF.md` 和 `runtime_delta.json`；核验 N2→N3 的 11 个目标源文件及 N3→R1 的 7 个目标源文件，18 项散列全部匹配。直接读取最终受控 Camera 结果为 50 项零失败，并查看走廊启用筛选／仅撤去筛选两张原图，确认存在明显照明差异。顾问没有重跑计时，性能数字采用执行者的本轮实测记录。

供电切换的首次调用从 N3 约 15.300–15.364 ms 降到 R1 1.878–1.987 ms；预建暗材质及单一供电所有者可作为独立改动移交。但视锥筛选未降低主要成本，两轮 R1 走动 P50 11.573 / 11.516 ms；战斗 P95 33.434 / 31.561 ms，高于配对 N3 的 29.475 / 29.381 ms。最慢 117.102 ms，因此常驻照明的等成本与稳定 60 帧均未通过。这只约束本实验，仍不推翻用户正式精简灯光版本已解决尖峰的反馈。

执行者明确记录大开间及走廊筛选前后差异为 17,527 / 60,187 像素，撤去筛选但保留 R1 供电实现后两处与 N3 为零像素差。顾问据此排除 `cost_light_views.gd` / `VIEW_FILTER`，不将该筛选合入正常候选。关闭办公投影的诊断仍改变画面，不能将其低耗时当成方案通过。最终 50 项功能验证为无人机巡逻受控夹具；实际战斗计时未冻结无人机，二者范围须分别保留。

已将冻结移交定向交给主工作流：在既有 `main/project/` 按语义整合 N3 必需运行增量与 R1 单独供电路径，保留五项视觉修复、后坐力和配置身份。角色派生灯须在源灯电源层更新后同步 `layers`，断电同帧生效；无人机白红动画不能越过电源关闭条件。主小样保留 N2 回退档与性能未通过的常驻照明实验档，不自动把后者视为已批准默认值。

渲染已释放 GPU，顾问进程快照无 Godot；最终统一 Camera 窗口已交主工作流。最终入口与全体结果仍等待其合样验收后一次交付，暂不启动新的引擎投影架构任务。
