# 爆炸空气冲击波推广与随机重播修正 · 2026-11-17

用户在确认可以随机变化后授权推广，并明确不需要再录制演示。空气波现接入主游戏共享爆炸池与WorldCameraFinish；原主入口及启动器重启生效。本轮未重导EXE、提交或部署。

## 随机重复的原因与修正

小样为此前的空气波开关对照，每次replay都将元素特效随机数重置到3871，导致碎片、烟柱和烟团细节完全重复。正式游戏的Elemental入口本来就在每次爆炸传入其独立RNG的新值；此次没有改动正式伤害／随机数宿主。

小样现在启动时初始化独立的演示随机序列，自动循环、R和T选取新变化；1／2切换复用当前一次爆炸，保留有意义的开关对照。三连模式自动循环也保持三连。固定3871只保留给可复现的诊断和计时。

连续四次正式爆炸数据检查确认碎片速度、烟柱轨迹与烟团参数变化；同一明确种子仍能准确重现。用户授权不录演示之前的一次24项检查记录保留，之后的推广检查没有追加截图或视频。

## 正式接入

- 新增 `scripts/dream/explosion_airwave.gd`：实际Camera下的共享采样宿主，用弱引用登记所有爆炸池，优先保留较新的压力波，总上限8道。爆心按实际Camera重新投影，随原爆炸时钟冻结／消退；隐藏楼层不泄漏空气波，恢复显示时继续已有时序。
- `explosion_stylized_pool_3d.gd` 在原相机效果注册／释放位置登记空气波。燃烧引爆、单位自爆和列车车钩等现有共享调用自动接入；clear、离场与Camera更换同步释放。
- `world_camera_finish.gd` 将上述参数交给原有材质，`world_camera_finish.gdshader` 引用新的 `explosion_airwave.gdshaderinc`。复用原一次屏幕拷贝与处理，不增加视口、灯光、渲染世界次数或新贴图。
- 已看过小样的空气位移函数去掉注释、空白并统一函数名后，与正式include逐字一致。保持0.65秒寿命、7游戏像素叠加上限、Nearest、原RGB强度0.16／暗角0.24与受击表现。根画布HUD／手机不在此采样目标内；原56项小样检查已含根HUD逐像素隔离，本次按用户要求不重录画面。
- 相机切换时记录最后写入者，避免退役相机清掉新相机的参数；最后一次清理立即归零。小样开关已改成直接控制正式宿主，不再替换私有着色器或生成第二套效果。

这是屏幕中的压力波表现，不是逐像素3D空气射线或流体模拟。没有修改碎片数量、灯数、伤害、危险区、爆炸本体材质或既有游戏玩法。
