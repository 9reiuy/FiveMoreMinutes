# 空中泼洒与尸体擦痕修正

> 后续反馈发现逐滴落地数据未及时唤醒已冻结的地面捕获，旧录像仍呈现集中显示，且测试玩家设置的3600秒无敌造成频闪。当前修复与新录像见[落地显示、节奏与测试频闪修正](blood-touchdown-display-correction-20261014.md)。本文520重力及单组飞行范围已被四组高低弹道替代；本文旧GPU检查不足以证明落地过程及时显示。

用户给出的两张参考明确要求：尸体拖动留下宽而破碎、带纵向擦拭空隙的血带；击杀的血液先可见于空中，再落地形成不规则泼洒。这次修正已接入现有正式血液、尸体运动及捕获链路。未使用子智能体，真实 GPU 录制和回归窗口均最小化。

## 修正原因与行为

旧拖痕每8px采样一次，却只画当前一帧的移动长度，慢速尸体因此留下规律小点；旧版还主动截短笔画留下间隙。现在累计每一帧经过的完整路径，满8px画一段连续擦痕，转弯先提交未满8px的直段，保留真实折角。默认名义宽度24px，沿路径有不对称宽窄、边缘撕裂及间歇纵向空隙。图案以全局路径距离为相位，相邻段不重置成重复图章。

旧正式命中喷血在120ms统一落地，未判断各滴高度。死亡喷洒现在采用独立高度、垂直速度和重力，触地时在该滴实际落点生成不规则、完整不透明的1px血斑。墙面碰撞仍结束飞行并沿原墙血路径处理；实际地板和墙门查询裁剪地面血斑。已落地像素不移动、不扩大、不渐入。仍使用既有单个效果和3D MultiMesh载体，没有新增第二套粒子系统或重复死亡爆发。

死亡地面池取消预置的110组远处散点、12个中等外溅块及外围指状块，只负责尸体附近伤口沉积；远处泼洒来自飞行血滴触地。局部池由四个完整碎边小块和三个稀疏晚期小块组成，主要局部沉积在约83ms内，最后少量沉积到550ms。死亡位置、落地触发、尸体寿命、伤害及非致死命中规则继续沿用。橙色、最近邻、8192格预算、原遮挡、落定合并冻结及换层回滚保留。

上一轮 `blood_deposition_camera_capture.gd` 使用了 `rifle`，该标签未被敌人的枪击来源判定接受。它能证明死亡地面池，却不能证明正式枪击喷血；此前对此链路的描述不充分。本轮夹具改为玩家发射实际 BasicProjectile，经过扫掠碰撞和正式伤害结算，核对死亡来源为 `player_projectile_assault_rifle`。夹具仅把单发伤害设为目标当前生命+1，以稳定触发死亡，不修改正式武器数据。

18个相关Headless脚本通过，记录1735项检查，未输出计数的脚本未补算；覆盖墙门查询、合并、回滚、尸体接触/跟随/寿命等。新增 `death_blood_ballistics_test.gd` 557项检查通过，涵盖旧120ms时刻仍飞行、陆续触地、已知落点、大时间步、真实墙碰撞、上限和调用方随机流不变。加宽后拖痕专项26项重新通过。三项GPU回归共83项检查通过：重绘35、查询Camera30、合并Camera18。GPU Camera退出仍有既有两份纹理资源清理告警，未将这些告警描述为已修复。

离树池形态生成16次：当前局部池中位1.675ms、P95 1.927ms；原始旧径向形态中位7.918ms、P95 8.514ms。它只衡量形态生成，不含真实碰撞、空中飞行落地的分帧成本或渲染，不能推出整场FPS改善。

没有重跑600秒整场性能验收或全工程清单。整场稳定60FPS、换层等待及中档实机验收仍未通过；视觉匹配需用户观看当前动图确认，自动化通过不等于达到OTXO观感。

手动复查：正式游戏击杀敌人观察先飞行后触地；尸体静止后用玩家/家具连续推踢，检查宽擦痕、慢速移动和转弯；再检查墙边、关闭与打开的门，以及换层失败回滚不留下跨层血迹。
