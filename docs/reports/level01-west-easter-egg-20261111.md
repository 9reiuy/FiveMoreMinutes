# 0-1 左侧 DMC-12 风格彩蛋

用户要求：左侧仍是黑色渐变但允许走入，约四个原关卡长度后出现参考图风格汽车，用聚光灯照射，车后有燃烧的轮胎印。本次只修改与验证工程，没有导出新程序。

初版车辆随后按用户反馈重建了连续车身、轮拱和灯组，修正轮胎遮挡，并补充做旧材质。当前车辆与最新实机验证见[汽车细化记录](dmc12-refinement-20261111.md)；本文下方的`easter_native_02`为初版证据。

## 实现

- 原主路线仍为 38×12 米，原三段房间、出生点、敌人/武器/开场慢动作规则和右侧连接不变。移除渐变后的旧 `LeftBoundary` 空气墙。
- 车辆中心在 `(-152.5,5.5)`；从左侧开口 x=-0.5 到车辆为 152 米，等于 38×4。西侧总边界 x=-168.5，额外空间容纳车辆后方的火痕和绕行。
- 黑色路段和实际逻辑地板连续；额外逻辑地板归入口区域所有，房间锚点及原房间地板网格矩形保持原位置。常规相机能跟随玩家进入黑暗，不增添 UI 提示。
- 新车为实际低模几何，银色楔形车身、低车顶、深色车窗、鸥翼门接缝、尾部百叶、四个矩形前灯、黑色防擦条与涡轮式轮毂；沿用工程已有拉丝铁原贴图和 Forward+ 动态受光。
- 一个带真实阴影的冷白聚光灯和静态反射探针照明展示区。探针只捕获环境层，避免将移动角色烘进反射。混凝土地面沿用当前 0-1 受光材质，并在展示区四周渐隐到黑色，没有叠加共面地板。
- 两道约 10 米的焦黑/炽热胎印沿车辆后方延伸，复用生产火焰、烟雾与余烬模块。只做视觉，不新增伤害规则。玩家接近前展示灯与粒子停用，离开后清理；粒子和灯保持既有模块上限。
- 彩蛋与 0-1 地板同属一个区域根节点；进入 0-2 时一起停用并卸载。独立 0-1 和连通试玩都使用这套实现。
