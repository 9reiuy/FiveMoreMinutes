# 电梯加载前后段修复与验收

日期：2026-10-12。单智能体执行，全程使用静音音频驱动和独立测试存档。

## 已接入正式游戏

进门、关门 → 全屏黑屏 → 完成下一层布局、家具、美术、捕获池及真实渲染预热 → 显示独立轿厢，玩家可移动至少 3 秒 → 短黑屏切换 → 开门、走出、关门。

- 新楼层完全准备好才显示轿厢。可见停留按实际时间计时，暂停期间不计时。
- 可见轿厢期间，楼层所属对象的更新和物理暂时停止，玩家及轿厢继续运行；出场时恢复原有状态。正常楼层内的全层敌人更新规则不变。
- 重加载不再发生在玩家可以移动的轿厢画面里；出场复用已完成的预热，只提交最终摄像机和遮罩切换。
- 旧楼层保留到新层预热成功后再销毁。失败恢复原布局、敌人、家具及特效，归还控制，并将玩家放到电梯自动进入触发区外，防止反复自动重试。
- 黑幕独立覆盖真实输出窗口，支持缩放；取消和场景销毁时释放黑幕并恢复原暂停状态。
- 黑屏期间拦截输入，防止 Esc 打开被遮住的暂停菜单；可见轿厢期间保留正常暂停功能。
- 修复跨层延迟材质注册和回滚记录中的失效节点引用，使用弱引用读取后再校验。
- 未修改摄像机、地图角度、移速、弹速、伤害、家具美术或退役内容。

本轮不代表交火峰值掉帧已经全部解决，也不保证所有设备没有偶发停顿。
