# 冲刺地面胶囊漏判与尸体全身接触修复

## 已修正

1. 原胶囊形状正确，但查询的是向上偏移28px的站立枪械受击框；对称摆放在路线两侧20px的敌人会一侧命中、一侧漏判。现以敌人正式地面位置及现有 `get_hurt_radius()` 判断圆与扫过线段的距离，不改活敌人的枪械受击框。
2. 起点圆在冲刺开始立即检查；随后逐物理步检查实际走过的段，终点仍包含完整圆端。各段并集形成完整胶囊，统一命中集合保证每敌人每次冲刺只结算一次。敌人中途受击后离开路线，不再因终点查询时已离开而漏掉。
3. 直接击杀记录累计至冲刺完成，仍只归还一格充能；不依赖延迟流血死亡。聚合镜头反馈每次冲刺至多触发一次，未扩大攻击半径16px、距离168px、时长0.14s，也未改携带槽伤害／空手伤害与冷却。
4. 候选敌人从当前楼层敌人根取得，不复用跨帧AI缓存；排除禁用的回滚暂存层、死亡和排队释放对象，仍可打到墙后的有效目标。
5. 尸体原接触范围是半径8px、高32px的小胶囊。现在读取可见头、躯干、双手和双脚的精灵部件边界，额外留2px接触余量，建立随姿态更新的凸包。
6. 正式3D中，经现有显示桥和正式Camera将身体轮廓投到地面，沿用尸体血迹的空间换算口径；不直接把屏幕精灵偏移当作地图偏移。无3D显示桥的物理测试使用原生2D姿态轮廓。
7. 玩家、移动／旋转家具与尸体的接触，以及尸体落地后的平移墙／门／家具扫掠，共用完整身体轮廓。初始已贴墙时阻止向墙内继续运动，并允许向外离开。姿态及投影未改变时复用已有凸包，无逐帧GPU取图。
8. 保留尸体只受玩家走动和家具推动、不挡玩家、不响应子弹、不因推动重置存留时间的规则；未加入新的逐骨刚体模拟，未改变死亡动画、血色或布娃娃冲量数值。
