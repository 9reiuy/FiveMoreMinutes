# 独立样板：室内像素浮尘

## 范围与运行

仅在 `scenes/dream/preview/FurnitureTextureReview.tscn` 增加 `SampleIndoorDust`；正式随机楼层、接待场景、卧室、主菜单、伤害/战斗特效均未接入。可在编辑器打开此场景按 F6；F8 对比浮尘开/关。

按已确认方向制作稀疏室内浮尘，而不是爆炸烟团、屏幕雾层或新的灯光。沿用当前摄像机、场景光照和调色板，单智能体执行。

## 制作

- 颗粒为实际空间中的小型相机朝向四边形，呈一两像素为主的阶梯小斑点；大小有少量变化，不使用柔化大圆盘。
- 随机高度约 0.35–1.7 世界单位，各自 7–13 秒周期，斜向缓移、轻微横摆，以像素稀疏度渐隐渐现。
- 每颗的漂移限制在一个合法室内格内，生成仅使用本房间实际 `usable_cells` 与 `floor_cells` 的交集；不在楼外、内部空洞和电梯轿厢生成。
- 真正深度测试，由墙、家具等已有几何体遮挡；接收场景灯光及世界调色处理，不影响清晰 UI。
- 每房间一个 MultiMesh，逐帧只更新一项动画时钟，粒子轨迹在 GPU 上计算。无单颗节点、碰撞、物理射线、额外视口或全屏遮罩。
- 最多 192 颗、每房间最多 28 颗；种子 120 当前为 90 颗、13 个房间批次。使用私有 RNG，不推进玩法随机数。
- 暂停停止计时，关闭对比时冻结并隐藏；楼层切换时隐藏旧池，新层重建，旧节点随所属样板楼层销毁。

## 验证

- `sample_indoor_dust_test.gd`：131 项通过，覆盖合法房间格、数量上限、无碰撞/视口、RNG 不变、稳定种子、开关、暂停、切换、再生成清理、正式场景未接入。
- `sample_indoor_dust_camera_test.gd`：9 项通过，使用真实 GPU、正式样板摄像机及已有世界显示适配；检查像素化/Palette 开关组合、单颗最终画面及不透明遮挡。
- 同一最大规格样板颗粒在对应投影区域有 22 个物理截图像素发生变化，Palette 关/方案 1 均通过。放置不透明几何体在它前方后，开关颗粒的该区域差异为 0。
- 初版测试把 HiDPI texture.size 与实际 get_image() 输出尺寸混用，导致检查区域偏移。已改为实际图像尺寸计算投影区域；没有靠放大颗粒来绕过失败。
- 整幅场景 A/B 仍包含桌面显示材质自身的时间动画，因此其 1590/1466 像素差异不作为纯浮尘贡献。有效显示与遮挡结论基于单颗投影区域对照，不以材质参数替代画面验证。
- 已检查样板摄像机截图和动态逐帧输出。对照录像为 25fps、每帧 40ms 的确定性效果时间，共 6 秒；不是运行帧率证明。

### 静态开销对照

RTX 5070 Ti、Compatibility、1280×720 输出、640×360 世界像素化、Palette 1。冻结 AI、角色及场景处理，同一镜头串行 off/on/off，每段预热 15 帧后记录 55 帧。

| 状态 | 中位帧耗时 ms | P95 ms | 最高 ms | Draw calls |
| --- | ---: | ---: | ---: | ---: |
| 关 | 6.835 | 8.127 | 9.767 | 1076 |
| 开 | 6.878 | 8.916 | 10.722 | 1119 |
| 关 | 6.869 | 8.817 | 9.456 | 1076 |

本轮中位数增量约 0.026ms（相对两次关闭均值）；13 批粒子在当前光照下增加 43 draw calls。1000 次更新平均约 0.771 微秒。只是静态样板局部测量，不能外推为战斗峰值稳定 60fps。

### 已有回归问题

- `office_sample_test.gd` 有 1 个失败：旧断言“开放办公室内墙数为零”。该测试只加载未修改的 OfficeSample 基础场景，不包含新增节点。
- `furniture_face_texture_test.gd` 共 16579 项，有 3 个失败：城市旧遮罩/相机射线断言与外围玻璃透明度断言，并有旧材质 null 调用。专门删除浮尘节点后再次运行，失败项与数量完全相同；用于该隔离的临时测试分支已恢复，旧测试源码无变更。
- 部分 headless 测试退出仍有现有 ObjectDB/资源释放警告。不能宣称全套美术回归或全部日志无错误，本次没有修理无关问题。
