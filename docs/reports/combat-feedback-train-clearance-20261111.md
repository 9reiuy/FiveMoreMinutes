# 近战掉落、敌人受击体、战斗文字与0-6顶部遮挡

本次按用户的五项反馈修改共享战斗代码和0-6列车实例。没有导出或打包。

## 修改

1. **击落武器越界**：原击落流程向轻质量刚体施加强冲量，同时调用落地策略把墙体碰撞归零，武器可穿墙滑出地板。`place_after_swap`现在将这一类非伤害散落速度限在240px/s，运动期间仅与墙体及通行边界碰撞，启用连续碰撞检测，并由真实地板查询保存最后合法位置。停止后恢复普通拾取状态；敌人武器生成点也先检查墙／地面。玩家主动投掷仍走原来的伤害与飞行流程。
2. **身体缺少判定**：旧受击胶囊中心为Y=-28、长46px，高于当前32px角色的躯干。现在按当前角色头顶、腿脚和视觉缩放重建上半身胶囊，并在同一个Hurtbox内加入身体／腿部圆形体，按相机在地面的方向对齐。脚底行走圆与AI寻路保持原规则，死亡／暂时禁用受击时两部分一起关闭。Boss自定义立绘安装后也刷新胶囊。
3. **击杀语**：保留现有连续击杀时间窗（3秒）；第1至3人不出现，第4人起每次有35%概率从原词库取词，避免重复上一条。使用局部随机数，加入有界的死亡去重记录。
4. **伤害数字**：共享敌人战斗文字不再生成数值字符串。伤害计算、死亡、血液和已有的“暴击”文字继续运行；普通非暴击伤害不创建文字记录。
5. **0-6头顶物件**：自己的六节车厢继续清空座椅／扶手组合，对手六节车厢保留座椅并裁去1.60m以上的顶部扶手。双方的窗墙／端墙也收起2.55m以上的顶部横框，避开高角度镜头中挡在头部上方的强亮横条；这些实例网格按源资源缓存。双方进入车内战斗的剖开状态时隐藏顶部灯管网格，保留实际光源。重新绑定导入列车的灯具源范围，清掉裁剪前的旧光晕位置；共享光晕也逐个尊重发光网格可见性，防止隐藏灯管残留发光条。
