# 厚实货梯全面接入交付

用户认可涂漆钢板、暖白内部照明及门扇蒙版的最终动态小样后，已将它提升为共享门面，应用于塔罗大厅三部电梯及正式楼层电梯。大厅保留 01/02/03 编号，仅 01 可用，另外两部关闭。编号由门体维护，不再叠加旧墙面文字。

## 实现与范围

共享实现位于 `scripts/dream/elevator_freight_facade.gd`，`elevator_floor_door_3d.gd` 工厂统一创建。原预览模块成为兼容包装，正式工厂不依赖预览目录。大块涂漆钢板、宽加强筋、厚侧柱、封闭电机罩、金属门槛、少量黄黑警示及琥珀条灯保留已确认造型。

移动门扇本体和筋条、铆钉使用固定门洞坐标裁切。暖白内部灯和朝外聚光随实际可见开口比例变化，关门后归零，内部发光灯条也隐藏。外部琥珀条灯独立保留。门洞宽度、原动画行程、物理碰撞、员工工牌、抽牌、进入／换层流程及独立换层轿厢沿用现有系统。

全面接入发现两处小样环境未覆盖的问题并修正：工厂在进入场景树前创建模型，灯光改用局部朝向和安全坐标初始化；正式楼层背向高位摄像机，浅内景的盒状顶棚与侧壁会挡住门板，改成只显示内侧的表面，关闭时可看到钢板、开启时可看到门内照明。正反编号均保留。诊断中间画面与日志保留，最终输出以 `final_main` 为准。

## 验证

相关九个逻辑脚本最新结果全部通过，报告断言数合计 148：大厅修正、布局、电梯音频、加载遮盖、门扇屏幕朝向、门墙对齐、独立电梯方向、NPC 交互范围及大厅场景。最后针对内景几何再次运行大厅修正、门扇朝向、门墙对齐，均通过；不重复累计断言。

实际 RTX 5070 Ti GPU 验证：

- 正式 Main 流程 30 项通过：三部货梯和 01/02/03 编号、普通移动经过闸机与家具、唯一左工位 NPC、正常对话／抽牌、普通电梯 E 输入进入实际楼层、共享货梯接入、地板与夜景参数、大厅滤镜隔离和正式楼层原设置恢复。
- 共享正式门体动态检查 16 项通过：原门动画与碰撞开关、关闭时内部灯和溢光归零、完全打开时照明开启、门外实际 GPU 地面像素变亮；门洞外两侧像素在蒙版开启时保持不变，临时去掉蒙版后相同区域出现门扇，验证测试区域确实能捕捉溢出的钢板。
- A1、B2、C3、V3 四种正式楼层运行检查：264 项，0 失败。

上述完成运行退出码均为 0，无脚本、shader 或场景树初始化错误。已有 GUI 锚点、两个纹理 RID 与少量退出资源清理诊断仍在日志中，未将其标记为已解决。

所有 GPU 运行在屏幕外启动并立即最小化，串行执行；主智能体独立完成，无子智能体。

## Camera 交付与测量范围

`.runtime/freight_delivery_20261015/final_main/` 保存实际正式入口、三部电梯、正常抽牌和进入楼层画面，含 `elevators.png`、`lobby_elevator_open.png`、`floor_elevator_closed.png`、`floor_elevator_open.png`。楼层电梯两张为保留游戏角度、投影和 FOV，仅平移至门中心的诊断镜头，原门动画正常运行。

`.runtime/freight_delivery_20261015/animation/freight_open_close.gif` 为共享正式门体开关动画与内部溢光的实际 GPU Camera 录制，裁切只去除周边画面。该审查镜头保留游戏角度和 FOV、焦点平移至门前；原始逐帧 PNG 保留。普通移动和正常乘梯证据来自另一个 Main 流程测试，不以审查镜头替代。

入口渲染统计在 `final_main/report.json`：120 个限帧渲染帧，世界视口 640×360、输出 1920×1080。CPU/GPU 计时仅涵盖该视口，不包括游戏逻辑、最终窗口合成或限帧等待，不据此声称完整 60 FPS 或交火性能达标。

本轮入口测量：绘制调用中位数 211，视口 CPU 中位数 0.923 ms、GPU 中位数 0.445 ms、GPU P99 4.469 ms。该单场景采样不代表所有楼层或战斗负载。
