# 三段侧刘海小样

2026-10-20。仅小样启用，正式玩家仍使用原版，等待外观确认后推广。由主智能体独立完成。

## 修改

使用原 4×11 像素图集，将整体转动改为三段滞后弯曲；发根固定、发中与发梢依次跟随，急停后衰减回弹。沿用原驱动与摆角上限，并校正整体发梢方向，避免曲线削弱实际摆幅。

中心线长度 3+4+4=11px，六个三角形共享四个横截面，UV 固定，最近邻采样，无独立发片接缝。左右镜像、背向隐藏、头部及高度继承、回血层同步保留。复用已有 Polygon2D 3D 被动复制；没有增加碰撞、第二份模拟或捕获通道，也未修改 PNG。
