# 玩家额外投影清理

用户确认：保留脚下向左下延伸的原有人体长阴影，只清除人物左侧的额外人影和头后的条状投影；正常角色与手持武器保持不变。本次独立执行，GPU 窗口全程最小化。

## 定位与实现

真实 Main 入口的接待房间、冻结同一帧逐项隔离：关闭反射颜色不能移除圈中影子；关闭人体投影会同时移除圈中影子和需要保留的长阴影。两处来自同一个人体阴影代理被多盏灯重复投射，不能直接删除整个人体代理。

- 玩家不再创建 `WeaponVolume` 长方体投影节点。实际武器精灵、握持参考平面、枪口与弹道映射未修改。敌人的既有投影配置保留。
- `OfficeShadowManager` 仅允许一盏现有灯投射玩家人体阴影。优先保留落在角色脚前、实际 Camera 中清晰可见的长阴影；按有效灯光范围选择，切换带 1.4 倍优势门槛，减少交界处反复换向。
- 使用 `shadow_caster_mask` 单独控制玩家投影通道，不改变照明接收层、灯光颜色、亮度、家具及敌人的投影通道。室外无可用室内灯时沿用原有太阳光。
- 玩家枪口脉冲仍照明、投射家具与敌人阴影，但不再叠加玩家人影。暂停、轿厢挂起、灯光释放及换层清理同步解除投影归属。
- 保留人体代理的原始几何和姿态计算，以保留用户要求的原有长阴影；没有将整个低模人体删除。
