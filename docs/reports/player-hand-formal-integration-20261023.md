# 玩家双手显示接入与球棍握柄修正

## 当前结果

正式玩家在 `_ready` 创建 `player_hand_presentation.gd`，不是只在独立样板中启用。重新运行 Main / F5 即可使用，主场景和地图入口未更换。

球棍原图 `art/Dream/weapons/Weapons/3.png` 左端为细木柄，右端为缠铁丝的击打端。先前将右端误认为握柄是错误的。现保留原图水平朝向，定位左侧有效像素边缘内 2px 的木柄作为主握点，另一只手沿木柄相距 3px；不握缠铁丝的端部。

待机球棍斜抬，绕握柄而非图片中心转动。显示层单独下移到肩侧，挥击仍复用原有 `weapon_motion` 与 melee snapshot，不改攻击角、攻击范围、伤害、冷却、冲刺或移速。

## 正式接入方式

- 持武器时，双手显示挂在原有 ReloadVisualPivot 下，与武器共享正式 3D 捕获平面，自动跟随挥击、后坐力和换弹。
- 不移动原有手部节点或场景路径，不影响刘海、治疗叠层及身体动画；空手显示原拳头像素并按 12×6px 椭圆分布，保留出拳偏移及前后排序。
- 枪械沿用既有瞄准椭圆、枪口和射击几何，只增加主握手与支撑手的显示；未替换战斗权威。
- 切换到其他武器时复原球棍特有的贴图偏移、旋转及翻转。移除武器或死亡后不遗留持武器的双手。
- 球棍纹理有效区域缓存一次，不逐帧读回纹理像素。
- 样板同步修正木柄方向；没有导入其他游戏的美术。
