# 手机细化独立试玩 · 2026-11-08

用户指出上一版金属受光明显、LCD仍像独立平面。本轮让屏幕与机框响应同一组光源，并降低背光对表面受光的遮盖。当前仍为独立样板，正式手机未推广，美术观感待用户确认。

唯一试玩入口为 `tools/preview_phone_polish.cmd`，默认进入实际Main的立绘卧室并打开手机，使用独立试玩数据。需关闭旧试玩后重开以加载最新材质。Tab收起／打开，Q或实体左软键进入设置，右键／Esc逐级返回。鼠标控制左右最大±12°／上下±8°转角，无平移；拖动和按住操作时冻结姿态。

## 当前屏幕与机框的整体受光

之前LCD在独立第6层，主光／补光和映射场景灯照不到它，独立面光对正常UI的变化又被全强度背光覆盖。现在LCD回到机框相同的第1层：原key、fill、3D映射场景灯及辅助均匀面光同时照射屏幕与金属。辅助面光的数量／位置／尺寸没有增加，只将其作用范围改为完整手机。

LCD保留UI自发光，背光增益降至0.60，给表面受光留下可见余量。漫反射随原UI色素响应以保持文字对比；粗糙度0.48和适度宽高光表现磨砂玻璃，而非针尖状光点。亮区由引擎计算光源方向、距离、表面法线与观察方向，不使用窗面／卧室图像或屏幕UV中的绘制光斑。玻璃与金属反射率不同，但光照方向、颜色及随手机转角的变化来自同一组灯。

立绘卧室仍不抓取整图／角色辉光作为机身反射；卧室原图与原灯光未改动。3D金属保留6个64px真实场景捕获面和真实灯光局部映射、手机自阴影、原投光纹理。未复制场景遮挡几何，局部映射边界不变。
