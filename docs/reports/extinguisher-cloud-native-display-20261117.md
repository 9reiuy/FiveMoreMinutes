# 灭火器聚拢雾团、白盒禁音乐与移除画面像素化

> 后续修正：走动造成空隙后仍按整格判定的缺陷已改为共享雾团状态，最新实现与本轮验证见[烟雾显示与判定同步](extinguisher-cloud-occupancy-fix-20261117.md)。下文保留首次推广时的实现和测量记录。

2026-11-17，按用户要求，将已确认的聚拢雾团用于灭火器打破后的效果；同时彻底禁用独立白盒的背景音乐，移除全游戏的画面像素化处理。未改变像素原画、家具贴图、灯光数量、画质开关或战斗数值。

## 当前实现

正式 `FireExtinguisherSystem.install()` 默认使用 `stylized_extinguisher_system.gd`。原控制器继续负责覆盖范围、墙／门／玻璃阻隔、遮挡视线、灭火、敌人隐藏及 12 秒消散；灭火器耐久、飞行与首次碰撞停止喷射等规则保留。旧呈现仅通过测试专用的显式元数据保留，用作配对基线，普通游戏入口没有旧版切换项。

呈现改为同一批原生 GPU 网格雾团，固定轮廓与溶解形态，无周期性上升、长大、重生。子弹、地面人物走路及翻滚驱动局部位移，扰动衰减后逐渐聚拢。每层共用一个有界数据池：256 个主体槽、24 个短促喷口槽；对应的可见绘制和影子绘制共享数据及运动材质，不为每个灭火器创建一套体积求解器。研究白盒原有的完整 GPU 体积流体求解器继续保留。

可见网格仍是原确认版本的 3,968 个三角形，仅将重复顶点归并为 2,143 个共享顶点；展开索引后逐项验证位置、法线与 UV 未变。真实影子使用同步的 248 三角形 LOD，保留所有灯光及投影功能。不是通过关灯、关反射或关闭烟雾投影获得性能成绩。

共享资源已打包到 `art/Effects/StylizedGas/`，正式代码不依赖 `.runtime`。网格为本项目原创生成；噪声来自用户提供的教程包，许可来源和未确认的再分发权利如实登记于该目录的 `SOURCES.md`，未声称其为 CC0，也未对外发布资源。

原有玩家／NPC 黑色剪影得以保留。新立体雾团会写入深度，原剪影会被其遮住，因此增加云团专用剪影材质：结合场景参考深度与固定云团两色色阶，在雾团覆盖下显露剪影。不是给所有人物加常驻描边；敌人的遮视线隐藏规则保持原样。

雾团专用样式光使用共用引用计数管理，稀疏灯光策略不会误将其关掉。多层暂存／回滚时复用和恢复自己的灯光层位，不改其他灯的能量或可见性。模型、影子、材质和覆盖数据随楼层清理；失败回滚保留同一池状态。剪影绘制变体在正常加载期间以不写入任何颜色的 Sprite3D 准备一次，避免首次进入雾团时才创建绘制流程。

## 全游戏取消画面像素化

- 世界视口按实际显示尺寸原生渲染，1280×720 窗口下实测为 1280×720。640×360 只保留为逻辑 UI 坐标，不再用作世界低分辨率处理。
- 菜单、手机和白盒面板移除对应控制，F6 不再切换。旧 API 调用不能开启，旧配置即便写有 `pixelation_enabled=true` 也忽略并迁出保存文件。
- 原生显示覆盖正式教程、接待区、办公关卡和共用显示入口；红海不再读取旧像素化开关。保留像素原画及原贴图采样。
- `AGENTS.md` 已更新为用户的新要求，后续不再恢复该效果。

## 白盒禁背景音乐

共用测试场在创建世界前取得独立音乐禁用范围并停止当前音乐。改变音乐音量或重新载入设置仍保持禁用；SFX 总线保留。退出测试场解除范围，正常游戏音乐可用。该范围不写音乐音量、Windows 音量或正式进度。

菜单与手机设置回归还发现购物卡片拖拽释放被滚动容器接收时，可能遗留倾斜锁。现于 GUI 派发后结束本控件已经持有的指针交互；真实点击仍只购买一次，拖拽松手不购买。相关 35 项手机检查通过。

## 有界性能检查及限制

固定正式美术测试布局、8 个 AI 关闭的敌人、家具与相同画质、原生 1280×720、相同音频条件；先做旧／新、新／旧配对，再针对异常和剪影路径作有界复查。逐帧 CSV 保留首个事件、重复事件与真实开火，不删慢帧，不在采样窗口截图。这是进程墙钟帧间隔，不是纯 GPU 时间，也不是全游戏流畅性认证。

最初完整网格投影在组合开火时开销过高。一次仅供定位的投影开／关对照显示投影相关开销明显；随后实际交付保留真实投影，使用共享顶点与同步影子 LOD。相关诊断数据为 `ablation.csv`，从未把关闭投影的版本作为最终结果。
