# 参考图大堂：口字形前台与六部内厅电梯

此页记录红线调整前的504格版本。当前电梯区已收回、闸机已前移，见[最新布局](reception-compact-lift-hall-20261108.md)。

当前正式前台已采用用户参考图的空间关系：前景左侧口字形接待台、开敞石材前厅、六级宽台阶、抬高的内厅、左右各三部电梯、后部闸机与两侧等候区。旧121格小厅及后墙单电梯草稿均已被替换。美术观感仍待用户审阅，以下是功能和实际游戏 Camera 的验证结果。

![实际游戏Camera](../../.runtime/reception_reference_layout_20261108/final/lobby_game_camera.png)

## 当前布局

- 平面为24×21格，共504格；前厅入口在画面前方偏右。
- 前台为四面实体石材柜台，中间保留真实员工空间，未叠放旧实心桌子。NPC使用用户指定的`art/Dream/enemy/npc1.png`，站在柜台内部。前侧柜台保留原塔罗和交谈入口。
- 内厅地面高0.6米，六级宽台阶与前厅连接；角色、影子和瞄准投影使用同一楼面高度，碰撞仍由原2D游戏权威处理。
- 西侧A1/A2/A3、东侧B1/B2/B3共六部电梯，均在台阶后的内厅侧墙上。每部有实际门板、碰撞与入口，不是贴图假门。靠近哪一部就选择该入口，轿厢按该侧的朝向对接；六部沿用现有办公层流程。
- 门板仍为两片同向侧滑。后部四个闸机机身形成三条通道，两侧各有一组等候座位。高石柱、后部夹层栏板、深木饰面和三角格栅顶保留参考图的层次；近处屋顶作剖切，避免遮挡闸机。

## 材质、光照与角色

保持Forward+ / Vulkan、640×360游戏画面、1280×720呈现和Nearest采样。大厅使用独立的灰石、深木、红毯及金属材质。完整原图与下载记录见[材质来源](../../art/Dream/ReceptionLobby/SOURCES.md)：

- 红毯使用Keith333的[实拍红地毯](https://opengameart.org/content/carpet-texture-red-seamless-texture-with-normalmap)，保留完整2048×2035照片及作者配套生成法线；CC BY 3.0署名随`data/asset_attributions.txt`分发。
- 石材使用cgbookcase的[Grey Matte Tiles 01](https://www.cgbookcase.com/textures/grey-matte-tiles-01)和[Natural Stone 01](https://www.cgbookcase.com/textures/natural-stone-01)；深木为Poly Haven的[Walnut Veneer](https://polyhaven.com/a/walnut_veneer)；电梯使用cgbookcase的[Brushed Iron 01](https://www.cgbookcase.com/textures/brushed-iron-01)。这些原始PBR图组均记录CC0来源。
- 15张原图的SHA-256均与下载记录一致。DirectX法线在导入时反转Y，OpenGL法线保持原方向；原图文件未改写。
- 门板有实际折边，绑定颜色、金属度、粗糙度及法线图。反光来自大厅现有的屏幕空间反射，固定实际Camera的开关对照在门面24×59像素区域产生359个变化像素。没有绘制假反光，也没有保留未产生贡献的反射探针；屏幕空间反射仍受当前可见画面范围限制。
- 新高石柱的横纹经灯光开关和纯色墙材质对照确认来自顶灯阴影。四盏顶灯收窄光锥并调整阴影偏移后，实机条纹消失，四盏灯的实际投影仍开启。家具旧噪声对照改变224个像素；当前家具材质的同区域变化为0。
- 表情与“交流”使用同一正式对话气泡，每2.4秒交替；接近后只显示“交谈”，真实对话开始时让位。原对话控制器、打字与塔罗流程保持原有权威。

## 诊断与边界

历史草稿和失败诊断保留，未计入最终191项。首次六门循环在等待已关闭门的旧信号时超时，已修复测试的等待条件；新台阶通路避开了扶手端部碰撞后通过。早期退出的Ogg播放清理提示由测试退出前停止本进程音乐解决，未修改正常游戏音乐行为。

最终日志仍有既有Control锚点提示。两次办公层图形检查包含`OpVectorExtractDynamic is not supported yet.`诊断；此前单电梯的相同主流程已有16条，本轮A3同为16条，不能归因为这次布局变化，也未将日志表述为全空。本轮验证功能、原分辨率实际画面与有限的材质对照；没有做整局性能认证。

当前实现入口仍是`scenes/app/main.tscn`中的正式接待区。布局实现集中在`scripts/dream/reception_reference_layout.gd`，楼面高度适配仅用于前台的`reception_actor_depth_bridge.gd`，共享办公层渲染与轿厢资源未改动。
