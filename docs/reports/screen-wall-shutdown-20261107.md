# 主菜单电视逐台关机

已接入正式主菜单的新游戏与继续游戏操作。已有存档时，仍先确认覆盖；取消确认不关闭任何电视。确认后锁住菜单操作，先播放关机动画，完成后才向 Main 发出开始/继续请求，避免提前创建游戏场景或写入新存档。

## 动画与声音

- 按各电视在实际 Camera 中的位置，到电视群投影中心的距离，从远到近依次关闭；中央眼睛 TV_07 单独保留到最后。
- 外围屏幕每隔 0.10 秒启动下一台，每台用 0.22 秒将画面纵向收成亮线，再横向收成光点、衰减至黑。对应补光一同衰减到零，电视电源指示灯与机身编号随后熄灭。
- 所有其他电视完全熄灭后，完整眼睛再保持 **0.55 秒**，然后播放同样的显像管关机效果。完成后进入游戏。底部文字在序列开始时淡出。
- 关机期间屏蔽重复点击、Enter、Escape 和底部链接操作，仍允许眼睛响应鼠标移动。移除菜单会取消尚未完成的请求；返回主菜单生成全新的亮屏状态。
- 使用新制作的 0.180 秒 CRT 断电音，短促降频声叠加继电器与放电杂讯，无外部采样。平均 RMS 与现有悬停音一致，峰值略低；共享 UI 音量链和 -9 dB 播放器衰减。同一时间只保留一个关机音，避免叠音放大。

声音主文件、原始制作配方和运行资源见 `sfx/preview/SCREEN_WALL_AUDIO_SOURCES.md`。原有悬停音没有更改。

## 验证

Godot 4.7.1 / Compatibility / RTX 5070 Ti，实际 Camera 后台 GPU 渲染。引擎启动前准备各自的私有静音设置，使用 Dummy 驱动保证自动运行无输出；不改玩家资料、播放器音量偏好或 Windows 总音量。这里验证 UI、流程、时序及画面，不代表全游戏性能认证。

| 检查 | 结果 | 引擎 PID | 日志 |
|---|---|---:|---|
| 独立 GameTestLab：新游戏、继续、覆盖确认、取消、从外向内、12 台各关一次、眼睛最后、输入隔离、补光关闭、中途移除 | 45 通过 / 0 失败 | 89584 | `lab_out.log` |
| 正式入口：新游戏与继续均延迟到关机完成、私有存档、进入 3D、暂停、两次返回菜单及全局限帧 | 26 通过 / 0 失败 | 98848 | `formal_out.log` |
| 菜单回归：设置、公告、确认、防误点、键鼠、重载和宽高比 | 53 通过 / 0 失败 | 98788 | `menu_regression_out.log` |
| 完整实际 Camera 录像 | 72 帧，2.39 秒，退出 0 | 31668 | `capture_out.log` |

三种进入游戏路径都只在眼睛完全关闭后发出一次请求。实测“其他电视全部熄灭”到“眼睛开始关闭”的间隔分别为 0.5544、0.5487、0.5511 秒，符合用户要求的 0.3–0.8 秒。

独立台、菜单回归和录像错误日志为空。正式入口延续先前 3D 切换中的一条锚点布局警告，流程通过；没有声称其日志完全无警告。

证据位于 `.runtime/screen_wall_shutdown_20261107/`：

- `screen_wall_shutdown.gif`：实际 Camera 连续帧，按记录时间合成，仅缩到 640×360 方便查看；GIF 无声，声音在试玩中播放。
- `only_eye.png`、`collapse_line.png`、`all_off.png`：眼睛独留、收束亮线和全黑。
- `shutdown_result.json`：逐台开始/熄灭时间、每帧状态、发出请求的时间。
- `formal/formal_result.json`：正式流程结果。
- `validation.json`：本轮源码、音效资源和证据哈希。

试玩仍为 `tools/preview_screen_wall.cmd`，关闭旧窗口再重新打开即可。该入口运行正式游戏流程，使用原来的私有试玩资料。

## 修改范围

仅扩展电视显示控制器、共享 CRT 着色器、电视墙序列和正式菜单的进入游戏时机，新增关机音及相应测试/证据。电视模型、布局、颜色、正常悬停时序、眼睛跟随、设置和退出行为保留。前台 60 / 后台 30 FPS 策略保留，没有提交、合并或清理其他工作树改动。
