# 随机办公楼：已验收室内浮尘正式接入

## 范围

正式随机办公楼的房间、走廊以及该楼层的安全接待室使用已验收的独立随机曲线漂移和偶尔闪亮效果。独立接待场景、教学场景、轿厢、主菜单、卧室不接入。仍保留独立样板与 F8 对照；正式游戏不响应样板 F8 快捷键。

没有复制视觉实现：样板和正式楼层复用同一控制器/Shader。没有更改颗粒大小、闪亮、移动参数、伤害、玩法 RNG、摄像机、调色板或现有家具美术。

## 生命周期与边界

- 由已有 CombatVFX 的楼层初始化入口安装，限定随机办公楼世界类型；不会因为其他 3D 场景也调用 CombatVFX 就接入。
- 控制器和粒子几何均归当前 `floor_root` 所有，安装幂等；最多 192 颗，每房间最多 28 颗。为后续房间和走廊预留预算，防止大房间耗尽全部额度。
- 使用真实房间地板与所属房间编号，验证完整弯曲包络和净空；不向楼外、内部空洞或独立轿厢生成。
- 加载期间先建立粒子池但隐藏，进入/乘坐/退出轿厢时隐藏并冻结，恢复 IDLE 后复用已有池。不把路径生成分摊到恢复控制后的第一帧。
- 暂存层保留隐藏池与动画时钟；生成失败回滚恢复同一批对象/时钟。成功换层后旧层控制器和几何随旧层销毁。
- 每帧仍只更新一个 Shader 时钟，无额外物理、灯光、捕获视口或全屏图层。
