# 灭火器烟云：分组黑描边、圆形半调（2026-10-24）

> 历史迭代记录。最新 7–13 圆不规则烟团、12 秒、受光、沿途留烟、双向视线与子弹驱散结果见 `extinguisher-smoke-12s-20261024.md`；下文的旧场景阻塞状态不再适用。

## 当前用户确认口径

- 云堆式二维卡片，三维高低和前后层次；底部可沿地面裁平。
- 按最新反馈改为每组 5–8 个大小不同的圆先合并。组内无接缝，组间保留黑色 2 纹素描边，不再把整层烟云全部合成一个轮廓。
- 阴影共用浅色底，只改变圆形网点大小/覆盖率，没有网点下的实心灰块；不以网点挖透明洞。网点在过渡区域连续缩小，而非用两档半径硬切。
- 覆盖范围、灭火、人物剪影、敌人失去视野等玩法规则不改。未复制参考游戏图片或代码。

## 实现

`extinguisher_smoke_common.gdshaderinc` 每个实例按种子生成 5、6、7 或 8 个融合圆。形状并集外侧两纹素为黑色，内部绘制浅色与半调墨点；轮廓和填色在同一次绘制完成。实例按相机深度后向前上传，因此前组能遮住后组，组间轮廓不会被一轮全局填色抹除。烟雾控制器只用一个材质/一个批次，不为每组增加节点。

半调使用 6×6 纹素的印刷单元，最大圆点半径从 2.8 缩为 2.15 纹素，按阴影强度 smoothstep 连续减至 0；过渡位置可表现为单纹素小点，四角留空。保持硬像素，不使用透明模糊边。黑描边仍经过既有游戏调色流程；开启方案 1 后映射至现有调色板的近黑色，而非添加调色豁免标记。

地面基础烟层维持连续，上层烟团以 1.8–2.8 秒错峰更新，上升、扩张、收缩后消失；总体最后 1.2 秒收缩清除。网点不会在整个灰底上叠一层。

## 本轮验证

- `extinguisher_group_outline_test.gd`：12 项真实 GPU 检查通过。三组叠放时内部组间黑轮廓 2480 像素、外侧黑轮廓 6314 像素；单组内部接缝为 0（排除外缘一纹素内的栅格采样差异）。两纹素描边明显厚于一纹素。
- 同测试检测到 30 个小网点过渡单元、22 个密点单元，72 个圆点单元四角留空；实际采样出 12 种非零覆盖级别，并非仅两档硬切。浅色底和点墨仅两档填色，没有灰色阴影底。底部裁切、上部保留、内部不穿孔与动画检查通过。
- 原 `extinguisher_union_outline_test.gd` 作为兼容入口调用上述分组检查，旧的“所有组重叠处禁止黑线”断言不再适用于新需求。
- `fire_extinguisher_test.gd`：35 项通过，含烟雾范围、墙门限制、灭火、消防器耐久和碰撞伤害。
- `smoke_wall_depth_test.gd`：4 项真实 GPU 检查通过，前烟遮后墙、前墙挡后烟、前方剪影可见、墙后剪影不可见。
- `extinguisher_cloud_preview.gd`：使用正式烟雾控制器和游戏调色板的独立 GPU 预览正常退出；最大 70 组（上限 192），6 秒后覆盖为空、可见实例为 0，没有新增脚本错误。
