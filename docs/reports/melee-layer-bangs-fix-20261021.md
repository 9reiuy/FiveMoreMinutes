# 挥击层级与刘海惯性修复

## 范围

用户确认后单智能体执行。保留攻击范围、伤害、攻速、击退、血液、拳头和踢击；不改摄像机、地图旋转、原刘海像素或135度摆动上限。不提交或推送。

## 修复

- 移除挥击弧面固定 `1.06` 世界单位（约34游戏像素）的头顶高度。每个快照读取正式角色Bridge的武器参考面，弧面位于握持面下方0.012世界单位。沿用真实深度测试：角色竖直深度面区分前后弧，持握精灵保持可读；墙及高柜仍遮挡。不强制置顶、不新增视口或可见碰撞体。
- 刘海以前只读取游戏移动速度和瞄准，站立挥击只改变视觉偏移且锁定方向，因此没有对应驱动。现在在同一个物理时钟中采样挥击身体偏移和前倾带来的头部运动，将其速度差输入现有弹簧。视觉驱动有界并增强短促动作的可读性，三段弯曲、固定发根、后脑隐藏和治疗覆盖沿用原规则。停止、恢复及取消仍由同一个弹簧自然回弹，不增加独立Tween或第二个模拟器。
- 上轮GPU演示暂停世界后没有手动推进刘海，不能用于验证挥击刘海联动。本轮控制序列显式推进正式 `step_actor()`，并保存弯曲量、末段角度、弧面与握持高度。显示模式对比前统一让弹簧回到静止状态。
