# 爆炸第二版正式推广 · 2026-11-16

用户已批准“可以推广”。正式共享入口 `scripts/dream/explosion_particles_3d.gd` 现使用已批准的 Le Lu 第二版重建：热区烟团、弧形喷射烟柱、飞散火星、半球冲击波、初闪和地面裂纹。原伤害、0.65秒危险区、持续燃烧和枪口火焰逻辑保持。燃烧引爆、单位自爆、叉车调用和0-6列车爆炸均经共享入口生效。

原主入口 `scenes/app/main.tscn` 和 [现有启动器](../../tools/preview_screen_wall.cmd) 保持；重新启动工程试玩即可加载。本轮没有重新导出历史 EXE，也没有提交、清理、合并或部署。共享工作树内其他任务的改动保留。

## 接入与实际场景修正

- 新增正式爆炸池、单次爆炸呈现和相机辉光宿主。六份 Shader 沿用已批准小样；六张原贴图保存为原生 ImageTexture 资源，逐像素／格式核对一致。正式运行不依赖 `.runtime`、旧 VDB 或原图片导入缓存；来源说明和散列清单加入 Windows 导出包含项。
- 保留8次爆炸上限、2.8秒呈现寿命、原有四盏共享临时灯。没有新增照明节点、世界渲染视口或物理碰撞。爆炸随原特效时钟暂停、推进和清理。
- 地面高度使用实际楼层上下文；风只推动烟团，裂纹固定于接收平面。离地或无房间支撑的爆炸不生成悬空裂纹。0-6明确将车钩缝隙设为无地面接收，爆炸和退役车厢继续共同随背景行驶，原20秒危险时限保留。
- 多个爆炸池共用一个相机辉光宿主，已有场景辉光保持原值。没有原辉光的场景只在爆炸期间借用环境副本，其他环境参数继续同步。灯具雾效通过同一宿主读取／更新底层环境，避免相互包裹导致爆炸辉光残留；两种结束顺序均验证。
- 实机发现血迹系统会将预分配的临时特效网格登记成接收面，额外产生查询碰撞。现以显式元数据排除这些特效；普通实体及同一宿主下的实体子网格仍正常接血。
