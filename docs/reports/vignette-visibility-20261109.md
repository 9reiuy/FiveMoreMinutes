# 暗角可见度修正

2026-11-09，用户反馈“暗角效果完全没看到”。旧版在技术上有效，但压暗主要落在本来就很黑的四角：边角约8%，两侧中点约2%，实际夜景中难以辨认。

当前仅将暗角最大强度从0.08调整为0.24，径向过渡从`0.55–1.90`改为`0.55–1.35`，让柔和暗边往画面内延伸。RGB only仍为0.16，未修改材质、灯光、准心映射或UI。

![同一实际Camera，左旧右新](../../.runtime/vignette_visibility_20261109/delivery/comparison.png)

正式Main→立绘卧室→前台→真实乘梯→办公首层的35项检查通过，PID61932退出0并释放。使用Forward+／Vulkan、640×360、Nearest，启动前私有Master=0／WASAPI，未改玩家或系统音量。

- 实际Camera外圈85578个像素变化超过2/255，变化均在中央一半之外，没有像素被提亮。
- 中央一半宽高的画面矩形逐像素不变；根UI像素不变。
- 关闭暗角后，新旧RGB only全帧逐像素一致；重复开启后恢复同一Camera画面。
- 灰色校准图实测四角明度比从0.92169降到0.75904（约24%压暗），侧边中点从0.98193降到0.86747（约13%压暗）。校准图仅作数值检查，展示图使用实际游戏Camera。
- 强受击画面与旧版逐像素一致，仍使用取较强者的单次处理，没有把暗角与受击压暗相加。
- 21份保护源中仅预期的暗角常量与Shader过渡两份变化，其余19份不变。

本轮是既有处理的参数修正，没有增加画面通道、纹理取样或渲染目标；未重复全游戏性能认证。完整截图、结果与回执见[本轮证据](../../.runtime/vignette_visibility_20261109/)。旧的8%记录保留为历史，当前暗角以上述参数为准；RGB保持已批准强度。

继续使用[原游戏入口](../../tools/preview_screen_wall.cmd)。正在运行的旧游戏需要重启才能重新加载已显式写入材质的暗角参数。未提交、清理共享工作树或调用Antigravity CLI。
