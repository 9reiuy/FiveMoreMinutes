# 命中特效被敌人身体遮住：修正记录

原因位于显示深度与捕获池复用，伤害判定没有反向。上一版只将特效颜色挂点移到可见躯干前方，预建的反馈池槽却由旧版占位效果初始化。重新绑定时未更新相机平面与材质策略，仍使用普通 Sprite3D 深度；而角色身体使用另一个竖直参考面，部分特效像素因此落到身体之后。普通枪火／弹道使用的水平深度面也不适合直接套到覆盖躯干的命中光晕上。

本次修改：

- 命中特效采用与身体平行的竖直深度面，向相机方向保留 0.04 世界单位间距。上、中、下部像素使用同一套遮挡规则。
- 反馈池重新绑定时显式切换相机朝向和材质；同一个槽在枪击、旧版近战反馈、枪击之间复用时恢复对应策略。
- 光晕使用独立的透明混合材质，保留深度测试，不预写不透明深度，避免透明光晕挖掉身体。墙和家具仍可遮挡效果。
- 原大小、颜色、时长、伤害、血液和身体闪白不变。材质随反馈池预建，已有正式遮黑预热覆盖新材质。

验证在后台最小化执行。正式 Main 入口、实际游戏 Camera、真实敌人枪击伤害入口，分别从三个方向命中：GPU 共 26 项通过。检查了身体上／中／下参考深度、同一捕获槽交替复用、容量不增长、前景实体墙的真实遮挡。墙前后的冻结输出逐像素比较一致，证明确实被墙遮住。最终日志没有脚本错误，仍有已有的 Control 锚点和 GPU 退出纹理清理诊断。

相关无界面回归 4 项、135 项断言通过，覆盖烟雾、实际命中路由、正式推广生命周期、人物／枪械投影。早期测试的禁用物理碰撞夹具已修正，最终 GPU 日志为 `gpu_blended.log`。
