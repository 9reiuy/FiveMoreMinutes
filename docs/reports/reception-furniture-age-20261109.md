# 大厅桌子、沙发与闸机纹理和做旧

2026-11-09。用户要求桌子、沙发也增加纹理并做旧，随后追加四台闸机。沿用正式大厅入口；没有新增试玩入口或改动其他关卡。

## 实现

- 前台与茶几：保留既有石材／胡桃木照片。茶几木纹调整到更适合小桌面的尺度和对比，增加桌沿磨耗、局部漆面擦伤、表面粗糙度差异；涂层金属桌架也有少量露底磨损。
- 两张沙发：保留原始网格、完整图集UV与灰绿色调，叠加已有Caban完整照片的中性绒面变化，以及配套法线／粗糙度。坐垫中央和扶手有轻微磨白，接缝与低处有积灰；以纤维方向变化表现轻微压痕，没有改变模型尺寸或碰撞。
- 四台闸机：机身使用现有Brushed Iron 01完整拉丝金属贴图，读卡壳与底座使用分开的涂层材质。加入局部金属擦伤、触摸区域的光泽变化、底座积灰与磨耗。绿灯、玻璃翼、四台位置、宽度及三条通路保持。

所有效果固定在表面，不使用时间噪声或屏幕滤镜。没有恢复排线、明暗交界抖动、黑描边或调色板。640×360、Nearest、32采样／米、Forward+／Vulkan保持。墙地、红毯、灯光、角色、相机、六部电梯和交互实现不改。

复用已有来源的22张图片，散列全部与原始清单一致。Caban三图增加导入缩小级别；Metal012四图也采用带缩小级别的正式纹理资源，替代运行时读取PNG的旧做法，修复该路径的导出依赖警告。NormalGL导入保持OpenGL方向，并启用法线缩小级别处理。原图没有改写、裁片或重绘。来源见 `art/Dream/ReceptionLobby/SOURCES.md`。
