## 有界性能样本

Godot 4.7.1 / Forward+ / Vulkan，1280×720原生显示，WASAPI；测试在启动前使用私有静音配置。每段先预备当前与后续分区，再预热90个物理帧，随后正常运行角色、镜头与原有场景逻辑，采样180个物理帧。每段记录435个显示帧；读取画面在采样结束后进行。

| 场景 | P50 ms | P95 ms | P99 ms | Max ms | >25ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| 展廊，关闭新增封边 | 6.882 | 8.803 | 9.534 | 11.578 | 0 |
| 展廊，启用新增封边 | 6.928 | 8.845 | 9.549 | 10.231 | 0 |
| 监控室，关闭新增封边 | 6.888 | 8.477 | 8.843 | 10.907 | 0 |
| 监控室，启用新增封边 | 6.918 | 8.477 | 8.752 | 9.363 | 0 |

此结果用于判断新增封顶在本机两个短样本中未带来明显持续开销，不代表完整章节、初次资源生成或所有电脑的稳定帧率。

本轮测试脚本为 `h06_gallery_topblack_probe.gd`、`h06_gallery_topblack_test.gd` 与 `h06_gallery_topblack_entry_test.gd`。初始截图辅助调用及首次类型声明错误的调试目录保留，不作为通过证据；以上两份正式通过结果的运行日志无脚本错误。
