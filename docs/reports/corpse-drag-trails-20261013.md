# 尸体地面拖痕实现与验收记录

用户批准在死亡后拖动尸体时留下断续地面血痕。本改动以真实尸体 Node2D 根节点位移为依据，不改变尸体运动、战斗数值或生命周期。

## 行为

- 静止不产生拖痕；移动距离每累计 8 px 采样一次，每段最多 6 px 长、基准 6 px 宽。短帧中段长随真实已走路径缩短；体表残留血量的慢速减弱与原滴血衰减分离。
- 每帧最多 2 段、每具尸体最多 24 段；超出帧预算的旧样本不在下一静止帧重播。
- 单次根位移超过 48 px 按传送处理，重置距离采样，不连接两个位置。
- 原滴血时间保持 2.2 秒。滴血结束后，只保留弱引用的移动采样，最长 15 秒，并在来源 `death_presentation_left` 到期时提前终止。
- 来源删除、楼层 token 变化、房间停用或跟踪超时都会停止并释放调度器。拖痕已生成的像素沿用本楼层清理与既有 settled 血迹合并流程。
- 调参集中在 `CorpseBloodEmitter` 的 `Corpse Drag Marks` 导出组；世界已有同时尸体调度器及血迹预算继续生效。

## 接入

`CorpseBloodEmitter` 调用新增的 `spawn_corpse_drag_trail`。该 API 经既有 `_add_3d_blood_effect` 创建效果、分配被动 capture，并通过既有刷新与 settled 合并入口收尾。

`BlackBloodEffect.setup_drag_smear` 为独立新增函数：只生成单像素地面 stamp，各像素检查真实地面及墙/门射线。闭合墙门阻断，真实开放通道允许通过；不会生成空中液滴或撞墙喷溅。完成后立即 settled 并停止逐帧模拟。本子任务未改原 pool、impact 或 trail 的形态算法。
