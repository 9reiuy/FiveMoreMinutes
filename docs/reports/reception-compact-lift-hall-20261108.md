# 按红线收缩电梯厅、前移闸机

用户澄清红线表示电梯区域收缩后的边界，闸机放到台阶上沿。当前正式大厅已按这一空间关系调整：宽前厅连接中间窄电梯厅，六部电梯随区域边界收回，闸机移至高台前缘。

![当前实际游戏Camera](../../.runtime/reception_gates_compact_20261108/final/lobby_game_camera.png)

## 当前实现

| 区域 | 调整 |
| --- | --- |
| 前厅 | 保留24米宽、口字形前台与NPC站位 |
| 后方电梯厅 | 从24米收为13米，边界为x=5.5和18.5 |
| 平面 | 原504格整矩形改为383格T形；两侧外扩地面实际移除，外墙与碰撞随新边界收回 |
| 六部电梯 | 左A1–A3、右B1–B3；纵向间距和侧开门保留，两组移至新边界 |
| 闸机 | 四个机身居中形成三条通道，中心z=9.7，前缘z=10.475，贴近z=10.5的台阶上沿且完整落在高台上 |
| 台阶与扶手 | 六级台阶收为13米，扶手置于两边；两侧前厅维持平地 |
| 等候区 | 随原外扩区域收回，移到前厅两翼 |

外边界、基础、顶梁、木饰面、灯位、地毯和角色楼面高度同步调整。此轮只修改前台布局及对应碰撞；当前材质、已推广的明暗交界网点、Forward+ / Vulkan、640×360和Nearest保持。
