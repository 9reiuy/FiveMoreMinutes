# 前台大堂重制 · 2026-11-08

本次直接修改正式前台 `Dream3D_ReceptionRoom.tscn` 的专用呈现。用户最后确认地毯方向为“深酒红素面短绒，细密材质和窄包边”。实现及实际 Camera 回归已完成，整体美术效果仍由用户游玩验收。

## 最终效果与范围

- 保持原14×8格大厅及右侧3×3格入口，共121个地面格；右侧入口、中间前台、左侧电梯的动线不变。
- 大堂使用暖灰磨面石材地面、浅色石材墙面、深色木饰面和少量古铜收边。墙厚0.32米，地面基础0.28米，前台石材台面0.11米，保留真实顶部和结构体量。
- 入口长毯、电梯前、前台和等候区统一深酒红素面短绒。地毯有实际薄绒厚度、细密表面和窄包边，去掉之前的大方格编织纹及粉蓝配色。
- 地毯使用 [Poly Haven Caban](https://polyhaven.com/a/caban) 的CC0羊毛材质贴图，原图、下载散列及署名保存在 `art/Dream/ReceptionLobby/`；运行时生成中性的64×64细绒贴图，以32像素/米采样，再施加酒红色。原图未改写。
- 使用暖白磨砂玻璃壁灯及两处间隔布置的顶光。删除电梯旁与前台左灯挤在一起的额外壁灯；顶灯硬件随剖切屋顶隐藏，照明保持开启，避免悬空灯盒遮挡人物。背景黑色，环境填光为0，亮度来自真实Light3D。
- 家具保留原图集和UV，前台实例改用原生受光材质，避开旧家具材质的光照噪声。沙发增加厚坐垫、靠背和底座，柜子集中到服务区域，通路保持清晰。
- 修复两类阴影问题：局部壁灯使用稳定硬阴影，避免低分辨率下软阴影采样斑点；顶灯的阴影投射层只纳入独立家具，墙和柜子的受光/阴影仍由壁灯负责，消除掠射自阴影条纹。没有修改共享阴影品质或其他地图材质。
- 前台专用电梯按参考制作拉丝钢板、窄竖窗、厚门套、上方绿色状态屏和右侧呼梯面板。两段门板在分离导轨上同向向右收起，保持原开关门信号及碰撞契约。固定石材侧袋在门打开时仍保持碰撞。
