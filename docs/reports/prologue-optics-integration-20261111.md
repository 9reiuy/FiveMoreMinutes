# 六关独立试玩：正式光效接入

2026-11-11。用户指出上一版独立包遗漏正式游戏的灯管光晕、立体薄雾与镜头污渍。本次在现有六关中接入共享生产组件，并重新导出 Windows 包。

## 原因与修改

正式游戏通过 `floor_reflections.gd` 安装 `office_light_optics.gd`。六关的反射由各关自己的材质和 SSR 负责，明确关闭了办公室反射视口，因此没有执行这条安装链；独立灯具也没有办公室 `RoomLight/FixtureMesh` 的结构。

现在六关显式安装同一个 `OfficeLightOptics`，由其原有两组槽位复用正式 `office_fixture_optics.gdshader`、`office_fixture_fog.gdshader` 和同一张确定性镜头污渍遮罩。未更改这三份生产资源的强度/图案。每次最多选两个在相机范围内的实际灯源；全局雾密度为零，仅灯下 FogVolume 有密度，其他灯不参与体积雾。

- 维修通道/车库/安检、仓库双管灯、通道面板灯、最终月台灯都绑定已有灯管及实际 Light3D。
- `packed_fixture_sources.gd` 从原地铁模型发光表面的连通几何读取灯段，匹配已有灯光；不增加替代灯具或光源。长灯带按局部灯段登记。
- 0-6 切开车顶时，原实现把整个 `InteriorLightDiffusers` 隐藏；现在保留其原有两侧灯带，仍移除遮住通道的中部顶灯部分。座椅和扶手没有恢复。
- 预制灯具完成自己的颜色/尺寸/功率调整后再绑定；光效跟随当前灯色与亮度。角色枪火、出口标识等保留原光照，不被当成灯管加镜头污渍。
- 移动场景在正常场景更新阶段同步位置，跳过相同变换及相同材质参数写入。区域卸载时清除失效源和槽位；更换区域后同步新的基准环境光。关卡重开/退出恢复摄像机及灯光状态。
- 正式办公室保留原安装位置、接口和渲染前选择逻辑；反射/手机摄像机继续排除主相机光学层。
