# 独立样板浮尘 V3：独立随机漂移

本次只将 V2 的偏顺向漂移改为独立随机漂移；保留闪亮、粒子尺寸/数量、房间遮挡、调色板规则、F8 对照及仅独立样板的接入范围。未修改正式随机楼层、家具、灯光或战斗。

## 实现

- 初始方向从整个 360° 独立取样，不再集中于固定顺风方向。
- 每颗拥有不同的弯曲幅度/方向、速度、曲线转向节奏和出生相位；轨迹平滑改变朝向，不是每帧乱跳或回到单格内蠕动。
- 完成一次轨迹时先淡出，再用独立周期参数决定后续行进方向；不可见时重置，不在可见过程中突然掉头。
- 生成时检查整条曲线的正/反弯曲包络和边缘净空，范围必须在本房间真实地板内；同步扩大包围盒避免转弯时被错误剔除。
- 全部动画仍由 GPU 执行，控制器每帧只更新时钟。未增加灯光、物理对象、视口或粒子数量。

## 验证

- 规则测试：314 项通过。包含实际速度方向覆盖四象限、总体方向合力不形成集中风向、多数粒子会改变朝向，以及完整曲线包络、闪亮、暂停、RNG、再生成清理和正式场景未接入。
- 正式样板 Camera3D / GPU 测试：13 项通过。Palette 关/方案 1 下的颗粒、闪亮、遮挡和实际移动均保留。
- 同一诊断粒子在最终截图中 0.7 秒移动约 9.48 个物理输出像素。
- 明暗亮度（实际变化像素）：Palette 关约 0.684 → 1.000；方案 1 约 0.699 → 0.959。被不透明几何体挡住时，颗粒区域开/关差异仍为零。
- 本轮共 327 项检查通过；差异空白检查通过。已检查正式镜头多帧图像，导出 6 秒静音录像。录像为 25fps、确定性效果步进，不是帧率性能录像。

RTX 5070 Ti / Compatibility，像素化及 Palette 1 的同镜头静态 off/on/off 中位帧耗时分别 6.891 / 6.893 / 6.918ms，P95 8.788 / 8.990 / 8.365ms。当前仍为 90 颗、13 批，运行时控制器 1000 次更新均值约 0.714 微秒。局部测试未测得显著中位帧开销变化，不外推为战斗峰值保证。
