# 正式特殊单位、弹反返还与近战释放引用修复 · 2026-10-23

## 接入

- 沿用已有送餐机器人、无人机低模及像素材质生成器，未另造替代模型。正式 Main 的随机楼层内容完成后生成一次：最多 1 台室内送餐机器人、2 架楼外无人机；无合法位置不强塞。安全接待区和 Boss 房不生成它们。
- 送餐机器人 100 HP，使用真实地板/墙门连接与家具碰撞规划室内路径。重用查询形状和参数，重寻路有节流；仍由 `move_and_slide` 执行移动，不瞬移穿家具。
- 左右真实模型枪口交替射击，分别朝玩家收束；共享正式步枪基础伤害、飞行速度、射程、总开火间隔、弹匣与公共换弹时间。两个枪口不是双倍总射速。火光走世界画面，像素化/Palette 继续生效。
- 无人机 100 HP，只选当前已有的建筑外窗，不把实体墙注入成窗。连续窗段上往返，单格窗也有短悬停巡逻；朝向经楼层坐标转换，不再把世界位置误作局部位置。受击代理与枪口跟随机身，子弹不再从窗内的虚假位置产生。
- 无人机使用正式手枪基础伤害、速度、射程、间隔与弹匣。首次发现/换弹后有探照预警，同弹匣按正式间隔射击。
- 两种单位的外观、受击代理和运行状态纳入楼层所有权，切房不重刷；暂存停更、成功换层销毁、失败恢复原对象。重挂节点不再误删无人机代理或机器人外观。
- 飞行代理及枪口明确标记为空中对象，不会被碎窗后的地面坠落系统误判并删除。

## 弹反

- 捕捉反弹前的原射手实例 ID；弹反瞬间朝其当前位置直线返还，不按鼠标瞄准、不持续制导。射手失效、死亡或等待删除时沿原方向反向返回。
- 保持原弹速，转为玩家阵营，重新计算返程已行距离。仍经过真实弹道碰撞、门窗、家具与穿透规则；不穿实体墙、不伤玩家。
- 实际撞到敌人后调用该类敌人的正常死亡入口，不用固定超大伤害模拟秒杀。普通敌人、机器人、无人机代理均支持；目标可以不是原发射者。普通攻击伤害、暴击和血量配置未改变。
- 更新旧弹反回归中“反弹只扣原伤害”的过时假设；不以旧断言失败解释为新功能通过。

## 近战报错

用户日志的 `lucille_weapon.gd:_resolve_sweep` 在把敌人缓存 Variant 转成 Node2D 后才检查有效性。现改为转换前检查实例、等待删除与在树状态，家具物理查询快照同样先验证，避免前一个受击回调释放后续候选时继续转换。范围、伤害、挥击动效不改。

## 诚实边界

- 尚未覆盖全部随机种子、全部窗口尺寸与长时间游戏；没有宣称稳定 60 FPS。
- Headless dummy renderer 在部分模型清理时仍报 `material_get_instance_shader_parameters: material is null`，真实 GPU 路径本次未出现该报错；不可把 Headless 退出码 0 表述为日志干净。
