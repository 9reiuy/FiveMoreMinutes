# 教程重制与电视、阴影修正

本轮在现有工作树内重制教程。独立试玩入口是 `Run_Tutorial.cmd`；已验收的 `0-1` 仍为独立关卡，没有加入正式游戏流程。本轮未提交代码，保留工作树中既有主菜单、屏幕墙、枪火及其他会话的改动。

## 当前关卡

- 三间教学室统一为 **8×6 格**，保留从左到右的游戏镜头方向、侧廊和唯一末端出口。第二间门已收至与其余房间相同的墙线。
- 混凝土地面、侧墙、Top_Black、32 texels/m、Forward+ 环境、局部冷灯及湿润反光来自 `0-1` 的共享维修环境工厂。地面由七块不重叠的连续区域组成，共 219 个可走格。
- 第一间只有参考图方向的横向桌面与电视，原人物和出现触发器已移除。靠近电视仍使用前台同款气泡，提示仅为“交谈”；没有新增操作说明框或地面文字。
- 第二、三间分别在完成前一间后才打开室内冷灯。第二间三条地面光条随房间供电启用、完成冲刺后转绿，只有材质自发光和光晕，没有 Light3D，也不向 GI 注入光照。
- 第三间假人采用 `art/Dream/enemy/Human body model.png` 第一格完整角色，原图未修改。保留真实子弹、200 点训练生命值、命中反馈和击倒完成判定；不运行人员 AI 或生成旧员工尸体。
- 角色沿用正式受光载体，局部可见度下限降为 0.025，受光倍率为 1.0。没有把角色改为无光照材质；实机红、绿灯开关对照确认角色内部像素会随真实场景光改变。

## 每间电视

每间各一台：第一间为桌上电视，后两间为壁挂电视，均复用主菜单的 CC0 CRT 机壳。玩家进入哪一间，只有该间亮屏；离开房间进入侧廊时全部熄屏。

电视直接显示当前游戏摄像机所在视口的最近完成帧，使用一个共享 GPU 帧纹理，不增加摄像机或复制玩法。复制在画面完成后进行，电视读取独立纹理，避免直接读写同一渲染目标。16:9 画面完整装入电视，采用最近邻采样。电视没有固定角色立绘或雪花内容。Forward+ 下运行记录为 `gpu_copy`、错误码 0；这是完成帧反馈，存在正常的帧间延迟，不声称零延迟。

## 条纹阴影来源与处理

实机定位到第二、三间冷光点灯落在壁挂电视机壳包围盒内；散热槽、指示灯及天线的小几何又产生了密集独立投影。对照图 `monitor_shadow_probe/a_baseline.png`、`b_detail_casters_off.png`、`c_lowered_clearance.png` 分别记录原状、只关闭细节投影、再调整高度的效果。

最终壁挂电视中心高度为 1.25 m，支架同步下降，并收起壁挂机型天线。点灯已在机壳外；细部停止独立投影，实体机壳和桌腿仍正常投影。未关闭墙体阴影或修改全局阴影质量。最终游戏镜头图见 `.runtime/tutorial_rebuild_20261107/run_20261107_233956/range.png`。

## 调色板退役

删除全局量化、蓝红配色和旧样板全屏换色着色器、对应 GPL 色板、设置字段、设置行、快捷切换和调用入口。旧配置中的相关字段不再恢复滤镜，重新保存时被丢弃。旧测试入口同步迁移，退役的调色板专项测试删除。

`world_semantic_decode.gdshader` 只保留战斗特效的专用标记解析，普通场景 RGB 原样通过。预览材料中的既有手绘墨色、角色原画颜色和局部材质风格不属于全局调色板；旧样板的房间换色开关与相关重映射分支也已删除。
