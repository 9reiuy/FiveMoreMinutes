# 教程电视说话时显示雪花，结束后恢复实时画面

用户已授权实现并推广。现已接入现有教程的三台电视，直接使用原入口 `Run_Tutorial.cmd`。

## 行为与整合

- 电视对白逐字出现时，整块屏幕切为动态黑白雪花；沿用已选雪花声和 −26 dB 音量。
- 文字出完立即恢复实时游戏画面，并停止雪花声；字幕仍可在原阅读时段继续显示。
- 两间后续房间的循环呼叫也按同一规则切换，呼叫间歇恢复实时画面。
- 只有正在说话且通电、开屏的电视进入雪花状态；关屏或断电会清除雪花状态。
- 继续使用原游戏 Camera 的持续 GPU 帧拷贝。雪花期间不停止取帧、不替换取帧纹理，
  因此恢复的是最新画面。没有新增相机或二次渲染世界。

本轮直接修改教程共用电视实现，三台电视都已生效，没有另外建立待接线的样板。
正常游戏是否进入教程的规则、既有渲染配置、640×360 游戏分辨率、灯光、对话内容与教学推进保持当前设置。
