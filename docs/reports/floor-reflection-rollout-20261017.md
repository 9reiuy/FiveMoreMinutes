# 地板反光与模糊倒影正式接入记录

用户认可第二版宽亮斑／细碎光泽后授权推广。正式入口现已默认接入全部办公楼层及塔罗大厅，不替换原地板纹理、配色、灯光能量或战斗规则。中档实机仍待验收；功能接入与稳定 60 FPS 验收分开记录。

## 接入与生命周期

`scripts/dream/floor_reflections.gd` 是唯一实现，旧 sample 脚本仅继承该实现，避免维护两套效果。地板生成时在实际材质上保留风格身份；反射绑定该身份与原始 atlas／normal 资源，不按场景名字统一套一种地板。重复表面共用同源反射材质，矩阵每个材质更新一次。大厅仍使用原接待区大理石。

反射仍为 256×144 单视口、共享实际 World3D、最高 15Hz，无第二套 AI、碰撞或角色时钟。更新使用真实经过时间，游戏慢动作不会把倒影拖到约 1.5Hz。新增角色、家具和灯光走有界队列；像素视口重挂接时忽略已注册节点，避免启动时积压数千个重复节点。

墙体、门洞和角色的实时参数保留在原有局部材质引用上；全进程共享的静态色块与家具 atlas 使用本场景副本，避免旧场景 queue_free 与下一场景短暂重叠时互相覆盖着色器。旧楼层暂存前显式恢复材质、层和摄像机，再释放反射视口；失败回滚在恢复的真实楼层重新接入。轿厢期间停止楼层反射，到站遮盖阶段提交最终姿态的倒影，开门后继续更新。

## 最终回归与连续运行

最终无界面回归 6 组、4780 项断言通过：四种骨架、原始材质资源、运行时角色和灯光、原材质实时参数、共享色块／atlas 隔离、失败回滚、大厅、原光照与角色投影。证据为 `regression_final/results.json` 与 `summary.json`。

实际 Camera 遮挡、玩家身体贡献、血迹、暂停与释放检查 15 项通过，见 `sample_final/report.json`。开启／关闭反射的橙色血迹覆盖均为 5130 像素。玩家身体在反射投影邻域确有 47 个像素贡献，实体遮挡物先于身体，移除后恢复真实倒影。

十分钟 Main 连续测试跑满 600 秒，完成三次真实换层，四轮交火均满足双边射击及至少两名敌方射手。轿厢可移动时长为 3.049／3.047／3.051 秒，实际移动约 25.25／27.59／25.25 像素；到站遮盖分别为 92.192／91.886／128.409ms，满足 150ms 目标。到站反射预热、旧视口释放、暂停恢复、退出及故意令生成尝试为零后的回滚通过。日志中的“staged building layout failed”是该故障注入的预期输出。

连续测试共 64 项检查，其中 12 项时间预算失败：首次黑屏、三次常规加载、五次可见阶段交接、三类阶段帧耗时。其余 52 项通过。首次黑屏为 14159.696ms，三次成功加载为 9737.362／8030.875／8605.343ms；另一次 699.788ms 是故障注入后的回滚加载，不混入正常换层平均。持续游戏阶段仅约 33.4% 的采样帧在 18ms 内，峰值 1308.568ms。没有修改验收线或把这轮标为整体通过。

这是一轮后台最小化、强制实际 GPU 绘制的结果，包含现有捕获池、枪械和破坏预热等待。未做前台同条件加载 A/B，不能据此判断这些加载时长全部由反射新增，或等同于前台等待。中档实机、前台实际帧呈现与更长时间运行仍未验收。

十分钟记录早于最后的共享静态材质隔离修正；该修正随后通过全部功能回归和真实 Main 场景切换／短时开销复测，未重复十分钟性能采样。因此长时记录用于报告已观察到的问题，不作为最终代码完整性能达标的证明。

## 最终画面与短时开销

`camera_visual/` 是最终可视化序列，使用安全接待区中的正常不闪烁角色；仅录制夹具采用不触发身体闪烁的免伤计时字段，正式游戏的受伤／出生反馈没有修改。持续战斗性能测试仍沿用其原有无敌夹具。`camera_final_view/` 等早期录制中普通无敌状态导致的身体闪烁不用于最终动图。

最终画面保持实际 Main 摄像机、原始自然房间和原有灯光，没有样例的额外暖灯。`delivery/formal_rooms.png` 展示大厅与四种骨架的原受光／已接入对照，`hall_walk.gif` 和 `floor_walk.gif` 按记录时间戳正常速度播放。原始图片未改绘，只裁切／缩放和加标签。

最终正式场景 GPU 检查 27 项通过，证据为 `gpu_visual.log`、`camera_visual/report.json`。在该轮真实场景短时采样中：

该轮 P95 差值约 +0.47 至 +2.47ms；先前重复采样曾约 +0.4 至 +1.4ms。两者都保留，反映短样本与动态场景波动，不能挑更低的一轮作为唯一成本。完整战斗与长时测试的预算失败仍见上文。

短时开销记录在对应 Camera 报告中，关闭／开启各取 120 个有效 process_frame，采样期间不保存截图。反射提交 CPU 仅为该组件的摄像机／材质参数提交，不含完整 GPU 时间。场景中的 AI、遮挡与待机仍在变化，因此顺序开关对照含调度和战局噪声；不把负差值当作性能提升。早期重复写入灯光遮罩已改为只在缺少接收层时写入，重复的 89–108 个地板表面只需更新 7–9 份同源材质。

最终 GPU 未出现脚本或着色器编译错误。无界面 dummy 渲染器释放阶段有 material 为 null 的诊断，实际 GPU 运行没有此类报错；GPU 退出仍有两张既有纹理 RID／RenderingServer 释放诊断。日志和断言结果均保留。

复测入口为 `tests/floor_reflection_rollout_manifest_20261017.json`，由原 `tools/run_regression_suite.ps1` 执行。使用 Headless 模式得到功能断言；GPU 模式含实际 Camera、四种 60 秒交火与十分钟测试，时间预算不通过仍返回失败。`tests/support/summarize_floor_reflection_rollout.py` 可从原始结果重新汇总功能和性能，避免人工把二者混为全绿。
