# 0-6：Boss 车内站位、玻璃触发与两秒转弯

本轮按用户三项反馈修正 `scripts/testing/metro_station/train_chapter.gd`。继续使用原有列车、boss1 立绘、角色与武器、Forward+ / Vulkan 和 1280×720 游戏画面。未导出游戏版本。

## 修正结果

1. **站位在车厢内。** 原行走接触点在敌车局部 Z=-1.19375，靠近 Z=-1.4 的窗墙，实际镜头会裁掉身体。现在使用敌方首节车厢的局部接触点 `(4.25, 0.12, -0.30)`，落在原列车地板上，并避开窗墙和座位；根据角色碰撞偏移换算精灵原点。接近、对话、战斗、倒地和转弯期间都跟随同一实际车厢，无需用固定世界坐标重新猜测所属车厢。
2. **玻璃旁触发。** 玩家需要抵达第三节面向敌车的实际玻璃区域。中间恢复的半窗和两边主窗均可触发；连接处、走道中央、反侧窗、中央窗框和实体补板不触发。触发使用实际行走圆心，以兼容武器配置和翻滚后的精灵原点偏移。
3. **击败后等待两秒转弯。** 移除转弯前必须到达首节、清空全部车厢、两车偏移归零的条件。转弯点放在敌车实际前转向架处，计时结束便进入曲线，取消额外的直行前导距离。计时同时校验游戏时间和实际经过时间，防止物理补帧跳过停顿。

敌车离开后，如果玩家列车仍有敌人或尚未推进至首节，恢复玩家操作继续清理；满足条件后再沿原流程减速到站。演出期间暂停附近敌人与子弹，恢复和重开时释放状态。补齐了对话中重开导致玩家控制没有恢复的问题。

前一轮车厢连接处单爆点、固定高度向后退场的 `train_derailment.gd` 与原始记录的哈希一致。未调整生命、伤害、武器、20 秒车厢销毁期限或到站镜头角度。
