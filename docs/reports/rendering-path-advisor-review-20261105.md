## 决策与分工

保留Forward+独立候选，不推广正式、不改普通N2默认。停止两灯微调，不推进全图自制缓存。优化仍为唯一负责人：下一步先在证据侧准备最小颜色兼容补丁与首用证据方案，逐级核对材质输入、3D视口、反射采样、合成输出及后端阴影混色；不得用统一压暗或调色板掩盖错误。跨后端不要求不现实的逐像素零差，但必须恢复已认可的夜景明暗、颜色身份、遮挡和反射，并明确剩余结构性差异。

GPU已交主工作流电梯黑屏验证，优化目前只离线工作，不改被测公共源、不启动图形。电梯释放后，由顾问根据具体候选安排一次静音实机验证。若颜色等价需要大幅迁移或出现无法保留的视觉功能，应给准确差异和备选，不继续盲调。

自动测试静音修复已另行复核：PERF-007入口初始化、运行及设置重应用后静音，保留原音频驱动／数值。原ABBA为有声条件，未来静音对照需两边一致，不能与本批硬拼精确降幅。正式与普通试玩不受此设置影响。
