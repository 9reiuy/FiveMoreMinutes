# 连续浓烟与多团黏连：2026-10-24

## 当前实现及边界

- 生产烟体改用共同的局部距离场平滑融合，而非两两配对加胶囊连接。每个组最多读取四个邻居，同一组可同时影响多个组；GPU 三团案例确认三个组同时连接。仍不是全局流体模拟。
- 7–13 圆的组轮廓参与融合，靠近时中间鼓起，远离时平滑分离。延续像素边缘、圆形半调阴影、真实灯光和最外缘黑描边，不采用参考图的彩色渐变。
- 每个实际剪影格至少一个持续不透明的底层组，底层不随单组周期缩小、淡出开洞；上层组仍缓慢更新。源结束时两者统一消散。烟体高度乘 1.5，基础低层高度也抬高，避免只贴地。
- 只有实际剪影区外的可行走相邻格添加少量稀疏小烟团，最多十二组；不扩展逻辑烟区，不越墙/完整门、玻璃、坑洞或楼外，不填回子弹清空的格子。外缘小团不触发剪影、灭火或视线阻断。主体预算不变，包含短喷气和装饰团在内仍不超过 192 实例。
- 12 游戏秒寿命、实际烟区面积上限、子弹扫掠驱散、敌我视线和角色隐藏/恢复保持原规则。

## 性能处理

局部邻域按楼层格缓存候选，只选最近四个，不遍历全楼；邻域数据每 0.08 游戏秒更新，慢速烟团的绘制/淡出仍逐帧更新。布局、清烟或相机朝向变化立即刷新。纹理行号在透明排序前分配，避免排序改变后读取别团数据。沿用两个共享绘制批次，不增加灯光或实时投影。

本轮正式楼层测试 84 主体组、27 格逻辑烟区；CPU 手动调用中位数 0.469 ms、P95 3.525 ms。相较初版局部融合扫描的 7.396 / 9.096 ms 有降低，但 P95 仍高于旧配对实现。数据仅为单来源控制器 CPU 调用，不代表整帧、显卡时间或峰值稳定 60 FPS。
