# 近战统一80与挥击可见性修复

## 范围

本轮按上下文调整玩家持有的球棍、书本，统一为80游戏像素。拳头、踢击、敌人和枪械不变；球棍160度、书本150度、伤害、攻速、击退和刘海均保持。单智能体执行，不提交或推送。

## 为什么上一版容易看不到

旧shader只绘制最外圈：球棍射程112时只画98至112之间的14px细环，书本只画78至88之间的10px细环。弧面与武器附近脱离；当墙或高柜将有效可见距离裁到环内，整个方向的细环都会被discard。旧弧带主体alpha仅0.28，叠加环境和Palette后进一步减弱。

## 本次修改

- 正式配置及武器默认距离均为80；视觉载体与射线仍直接读取同一距离。
- 增加从距角色10px附近延伸至有效射程的短促挥动前缘，与连续扫过角度同步。外弧主体宽度改为球棍22px、书本18px；前缘使用亮色、弧带提升不透明度。书本保留纸页缺口，1游戏像素栅格不变。
- 不关闭深度测试，不取消墙/门/高柜射线裁切，不新建视口或光源。收尾仍跟随原攻击快照渐隐，伤害时钟没有延长。

- melee_sweep_world_test：24项0失败，正式实体、74px敌人、门和跨层清理。
- melee_presentation_test：229项0失败，图层高度、刘海与恢复。
- melee_sweep_delivery：69项0失败，实际Main、随机办公室、正式Camera、1920×1080，RTX5070Ti；四种像素化/Palette组合、八方向、书本移动、静止刘海与真实家具。
- 合计379项通过。新增GPU可见性检查：同一受控动作快照，仅隐藏/恢复弧面mesh，保存前后PNG并检查弧面投影区域实际RGB差异，不以Node.visible代替画面证明。四种球棍显示组合分别有17866、14062、15723、16272个明显变化像素，移动书本20607个。该值不是独立物件mask或性能指标。

- 逐图检查前缘连接、弧带、角色前后、柜体遮挡。GIF为固定60Hz动作采样，不是实时帧率证明。GPU退出仍有先前纹理/RenderingServer资源警告，本轮不宣称修复；未执行全库回归或长时性能测试。
