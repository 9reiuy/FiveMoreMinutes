# 烟雾画面与实际判定同步修复

> 用户随后明确要求人物经过后迅速回拢；最新人物扰动已改为侧向挤开并快速回位，见[雾团快速回拢](extinguisher-cloud-fast-recovery-20261117.md)。本页保留判定同步修复时的验证记录。

2026-11-17。用户反馈走动已将雾团散开，玩家却仍处于烟雾状态。已在原生 1280×720、实际 Camera 下复现并修复，正常游戏和测试场共享该修复。

## 原因与修改

原实现让 GPU 独立处理雾团位移及缩小，游戏逻辑仍只查询初始覆盖格子。格子尚在而雾团已移走时，玩家仍变黑、敌人视线仍被挡住。修改前的确定性复现中，这三项检查同时失败，原始日志、截图和源文件保存在 `.runtime/extinguisher_cloud_sync_20261117/before*`。

现在由有界的 `extinguisher_cloud_field.gd` 维护雾团位置、动量、扰动和最终大小。GPU 网格与影子直接读取同一份位置／尺寸快照，不再各自模拟另一份状态，也不读取 GPU 数据回传到 CPU。玩家烟雾状态、黑色剪影和敌人视线均查询当前雾团，而非把整个可达格子视为浓烟。

判定使用原始八个圆团构成的体积截面（0.65 米视线高度，带空间分桶），跟随同一位置、朝向和缩放。它是与网格形体对应的体积近似，并非逐屏幕像素的噪声孔洞检测。原覆盖格仍作为结构边界：墙、门、玻璃、无地板区域、弹道清空及来源生命周期限制继续生效。走动或翻滚造成的空隙会解除状态，雾团实际聚回后才恢复；子弹原有的清空规则仍保留。

实际走动检查还发现了更新先后问题：控制器早于玩家处理物理，导致边缘状态落后一帧。现只将该烟雾控制器排在人物移动之后，同一物理帧更新扰动、占据和剪影。保留 256 个主体槽＋24 个喷口槽、原网格、两色风格、真实影子、12 秒期限和原武器／人物数值。

## 验证与证据

使用私有 APPDATA、启动前静音 WASAPI、Godot 4.7.1 Forward+／Vulkan；未改正式保存音量、Windows 音量或用户进程。证据目录：`.runtime/extinguisher_cloud_sync_20261117/`。

- `before.log`：旧实现的空隙占据、玩家剪影和视线恢复三项失败；`before_cleared.png` 可见空地上的黑色玩家。
- `ordered.log` / `after_result.json`：13 项专项检查通过。真实走动 65 个采样中有 25 个点位仍在原格子覆盖内但当前无雾，残留烟雾状态为 0 帧；翻滚、弹道清空、重新聚拢、自然到期、原生显示与白盒禁音乐均通过。
- `after_cleared.png`：相同强扰动场景，空隙中玩家恢复原色；`after_dense.png` / `after_reformed.png` 保留有雾时的遮挡。
- `formal.log` / `formal_result.json`：15 项实际 app 入口检查通过，含正式教程与战役入口、真实命中灭火器、雾中剪影、暂停、跨层失败回滚、成功重建及旧池清理。记录到原有 Control 锚点尺寸提示，无脚本或 Shader 错误，退出 0。
- `final_gate.log` / `result.json`：最终源码的测试场与固定正式美术准入 28 项通过，包含首次／重复触发、实际开火、行走、翻滚、12 秒结束与重建。结果和逐帧数据在同目录保存，汇总见 `summary.json`。

全游戏画面像素化仍已退役，白盒背景音乐仍禁用，音效保留。当前修复不改变研究白盒的独立体积气体求解器。

## 性能范围

固定正式美术布局、8 个关闭 AI 的敌人、相同家具／灯光／投影／画质、原生 1280×720，采用旧卡片呈现和新共享雾团实现的 AB／BA 配对；不是与上一版 GPU 独立扰动实现的直接性能归因实验。逐帧墙钟数据保留在 `frame_times.csv`，不在计时窗口截图，不删除慢帧；P50／P95／P99／Max 与超标帧数由 `summary.json` 汇总。

最终新实现的窗口结果如下（空闲 240 帧，其余各 360 帧，两轮合计）：

| 负载 | P50 ms | P95 ms | P99 ms | Max ms |
| --- | ---: | ---: | ---: | ---: |
| 空闲 | 9.464 | 10.626 | 11.358 | 12.278 |
| 首次触发 | 11.078 | 13.935 | 20.548 | 35.011 |
| 重复触发 | 10.858 | 16.860 | 24.458 | 26.734 |
| 实际开火叠加 | 18.802 | 33.142 | 39.538 | 52.900 |

组合开火仍有明显长帧，未证明其 GPU 或外部根因。本轮功能修复通过，性能表单独如实记录，不将上述短测称为全游戏流畅性验收。

这是本次有界测试场检查，不能据此宣称整个游戏稳定 60 FPS 或所有长帧均已消除。工作树其他已有改动保持，未提交或推送。
