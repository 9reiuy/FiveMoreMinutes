# OTXO 血液表现调整与验证

> 本文为上一版记录。用户已否定其中的中心扩圈效果；正式血泊生成已按[动态生成修正](blood-deposition-correction-20261013.md)更新。本文1.2秒时长及径向轮廓参数不再描述当前默认生成过程。

依据本地解包资源和用户提供的 OTXO 实机画面，调整现有血液系统。保留橙色、最近邻采样、固定 1px 地面格、地面/墙/门遮挡与捕获池；没有导入参考游戏精灵或完整流体模拟。

## 实现

血泊使用不对称外溢轮廓与细碎边缘缺口，额外采样 90 组外围细滴和小块簇。命中喷溅保持主方向，将约三分之一地面落点分散到更宽扇区；空中滴数、速度和战斗数值沿用原逻辑。形态角向边界预先缓存，新增装饰复制随机流，不消耗世界内容/掉落随机流。

尸体拖痕沿真实 Node2D 地面根的位移采样。原滴血仍约 2.2 秒；停止滴血后仍能留下擦痕，最长跟随 15 秒或尸体实际到期。静止不新增，传送不连线。拖痕中残留血量慢速减弱，与伤口滴血衰减分开。已有像素不缩放，增长捕获最多 30Hz，落定冻结；单块 8192 格及原世界预算、弱引用、换层清理保持。

## 证据与限制

6 项针对性 Headless 测试共 409 项检查、0 失败，退出码均为 0：形态 276、拖痕调度/裁剪 22、正式世界接入 12、尸体跟随 23、血迹合并/跨层恢复 27、逐滴射线复用 49。原日志在 `.runtime/otxo_blood_investigation/`，文件与测试同名。

16 个固定 seed 的局部形态生成测试（无真实世界碰撞与渲染，两条形态路径均使用相同的新尺寸参数）：旧形态路径中位 8.009ms，新形态 7.558ms；P95 从 8.594ms 变为 11.334ms。新增溅点更多；该结果不能证明整场性能改善或 60 FPS 达标。

实际 Main 入口、正式 Camera、RTX 5070 Ti、1920×1080 已捕获增长、命中和晚期拖动。夹具使用真实已配置敌人和生产出血 API，但人工移动尸体根；它验证显示链路，不代表所有推踢情形已手动验收。早期夹具没有核实晚期拖痕，不作为该项证据；修正后的夹具记录了 20 段晚期拖痕。

GPU 测试改用最小化原生窗口与显式渲染帧，保持真实显卡和 1080p 图像。本机 `--headless` 使用 dummy renderer，不能替代 GPU 验收；后台性能数据与前台呈现数据分别标记。退出日志有共享纹理 RID / 音频资源清理告警，断言通过不等于退出无告警。全工程回归与正式交火验收仍独立进行，中档实机保持待验收。

## 手动复核

实际 Camera 图像：`.runtime/perf_delivery_20261013/blood_final/pool_final.png` 与 `corpse_drag.png`；同目录 `report.json` 记录最小化状态、真实 GPU、分辨率、20 段晚期拖痕和单次 setup 6.435ms。该单次值不作统计性能结论。

正式游戏击杀不同敌人，观察独立外围血点与不同血泊轮廓；落地后立即推踢，以及滴血停止后再推踢尸体，观察路径擦痕。闭门应阻断血迹，带血门转动时仍跟随表面。暂停停止增长，恢复后继续；换层及生成失败回滚不得残留旧层血迹或丢失当前血迹。
