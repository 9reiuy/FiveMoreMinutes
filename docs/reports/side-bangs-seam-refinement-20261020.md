# 刘海分段痕迹修正小样

2026-10-20。根据用户反馈继续修正，仍仅在预览中启用，正式玩家保持原版；独立完成，未使用子智能体。

## 原因与修改

上一版四个截面虽共用顶点，但三段直面在连接处切线突变，贴图沿折点改变方向，出现拼接感。没有把“顶点已连接”当作视觉问题已经解决。

保留三段角度模拟，显示改为单条三次曲线。发根切线向下，发中和发梢的控制点来自原三段驱动；沿弧长均匀采样，约半像素一行，共享横截面，避免在原 3px/7px 位置产生折点。渲染中心线重新归一为 11px，整体发梢方向和原摆幅限制保留。

从原图集读取相同的 4×11 像素，构造仅在内存使用的小纹理，并限制边界采样。没有重绘或修改 PNG，也没有靠模糊掩盖痕迹。原三段驱动、头部跟随、左右镜像、回血显示及正式 3D 捕获通道继续复用。
