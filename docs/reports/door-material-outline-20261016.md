# 正式门材质像素轮廓

用户选择在门材质中绘制轮廓并授权实施。本次直接修改原 `sample_wall_and_desktop_review.gd` 的门贴图生成器，不添加外部描边几何或全屏后处理。

外沿连续一纹素近黑线，内侧保留窄亮边，分块线较轻；观察窗及玻璃门孔洞有对应边框。原灰蓝漆面、铰链和锁具保留。单扇／双扇继续按各自实际叶片宽高和 32 px／世界单位生成，双扇中缝来自各门板原有边缘。侧面不再直接整面采样新增黑色外沿，而使用原漆面内层并只在前后边缘处理窄暗线，顶面使用内侧亮边。材质仍参与原夜景动态照明，无新增发光或灯光。

修改沿用原正式房间门材质准备和贴图缓存路径；不改变门扇网格、碰撞、阴影、铰链、破坏、完整高度显示、墙体 U 形裁切或房间墙面纹理。通用原始门及电梯材质不纳入本次房间门绘制。

## 验证与产物

根目录：`.runtime/door_outline_20261016/`。

- `delivery_camera/report.json`、`delivery_gpu.log`：实际 Main → V3 seed120，实心／观察窗／玻璃三种门，25 项检查通过。旧纹理和新纹理在同一原游戏 Camera、同一原网格中切换；仅冻结世界相机更新和玩家物理，保持完整 GPU 输出 1920×1080。所有材质比较的碰撞与阴影资源身份不变，无外部描边网格，门仍不裁切。原物理推动后铰链转动通过。
- `regression/`：门物理／裁切通用接口、正式墙体材质生命周期两组回归，73 项断言通过。
- `cache_gpu.log`：既有批准美术纹理缓存 GPU 测试 359 项通过，覆盖缓存／非缓存字节一致和缓存上限。
- 窗口屏幕外启动并最小化，RTX 5070 Ti / Compatibility。AI 暂停、初始站位为测试夹具；物理推门使用原 player_push 入口。不是战斗帧率测试。

`delivery_camera/door_outline_before_after.png` 为实心门前后对照，`door_outline_comparison.gif` 为交替对照，`door_push.gif` 为完整实际 Camera 推门动图，三类门原始完整截图及裁切均保留。旧纹理由 `tests/support/door_texture_before_outline.gd` 的冻结夹具提供；两幅对照均使用当前侧面映射，因此比较描述为纹理 A/B，不宣称旧版整个着色流程重现。

早期拍摄因相机轻微跟随不满足一致条件，另一次暂停树后输出尺寸改变导致黑色裁切，均已弃用；只有人工查看且通过完整尺寸检查的 `delivery_camera/` 是交付结果。GUI 锚点和 GPU 退出两张纹理清理诊断仍存在，最终日志无脚本错误。
