# 夜潮海岸：连续近海白浪、单座吊塔与行走

## 最终行为

- 白浪覆盖前方和左右的整片可见中近景，远海逐渐减弱。取消之前只在几个小区域显示的边界感；按约 8～13 组主要浪头的美术密度收敛，减少次级波与细碎支路，数量随起沫和消散浮动，并非固定数量的精灵对象。
- 泡沫由真实浅水网格的正压力波峰、挤压及曲率产生，沿局部流速输运，按独立寿命消退；白色浪唇读取泡沫前缘。不是整体平移一张白色波纹贴图。静水不凭空起沫，反向水流会反向输运泡沫。
- 只保存一座锈蚀桁架吊塔：塔身、长吊臂、支撑拉索、吊车小车、驾驶室、配重和吊钩，加入锈蚀材质及灰轮廓。模型放大至原小样的 2.2 倍；执行期间用户在 Godot 修改了它的位置和朝向，最终保留用户最新摆放，没有再次运行布局生成脚本覆盖。
- 风机塔身放大约 1.8～1.9 倍，并额外放大叶轮。最近风机的轮毂高约 30.6 米、叶轮直径约 34.7 米；左右风场保留中央海面视线。数字为本场景的美术尺寸，不作工程规格说明。
- 独立海岸角色接入原角色图集的分部行走：双脚交替、抬脚、身体起伏和双手反向摆动，随实际行走距离推进；停步恢复站姿、转向切换正背面及左右头部、暂停冻结。仅为视觉组件，没有加入另一套战斗或移动权威。

## 系统和可编辑性

当前 `night_coast.tscn` 保存 420 个子节点。新增吊塔与角色显示组件都是场景节点；所有摆放继续可编辑、可保存，运行不重建布局。具体节点见 [编辑说明](../night_coast_editing.md)。

细网格：48×40，间距 0.5 米，30Hz。连续近海粗网格：64×56，间距 3.75 米，覆盖 240×210 米，以 15Hz 调用同一水流求解器，并根据实际 CFL 条件拆分内部步长。粗网格初始化并在外边界维持三组不同方向的长波，波的后续传播与地形、障碍作用由浅水状态演化决定。其显示范围覆盖当前行走路径的 Camera，内部边界远于白浪的渐弱距离。

共享 `surface_flow.gd` 新增可配置 `maximum_substep`，默认仍为 1/60 秒；只有独立近海粗网格提高上限，CFL 限制继续生效。水流仍是高度平均的地表模型，尚非三维翻卷浪、完整海洋或正式血液系统接入。

总计 121 项检查。最新实景采样中，中近景新增可辨认白浪像素 2983 个；左、右可见侧区分别 798、1252 个，证明两侧均有新增浪线。这是像素覆盖验证，不把像素数等同于浪头组数。连续近海水量账本容差为 3ppm，以适应大体积网格的 Float32 累积误差。

最终定向 GPU 日志没有脚本/着色器错误。执行期间出现的两条新资源 UID 回退警告已只针对资源引用修正，未改动用户的场景变换。早期小区域方案的左侧覆盖检查曾失败；最终通过扩大为连续近海区域修复，并把检测 ROI 改为实际 Camera 可见侧区，避免把摄像机后方区域当作可见侧海。

性能边界：最新回归中，每个样本推进 0.1 秒模拟，含三次细网格更新及粗网格累积更新，CPU 模拟/上传 P50 约 42.14ms，P95 约 52.124ms。这里排除了 GPU 绘制、读回和写文件，不能把这些数值当作整帧时长或稳定 60FPS 验收。连续近海比初始单块细网格更耗 CPU；采用粗网格及 CFL 允许的较大内部步长控制开销。
