# 交互雾：灭火器烟团外观试用

本记录为带局部密度渐变的上一版。当前已按用户反馈改为完整烟团轮廓，见 [完整烟团修正](interactive-gas-whole-puffs-20261116.md)。

按用户要求，在独立白盒里试用现有灭火器的雾团。入口仍为 `Run_Interactive_Gas.cmd`，默认显示灭火器烟团；V 键在相同烟气状态下切换上一版体积显示。G 补雾、P 暂停烟气，开枪、走路和翻滚继续输入同一 GPU 流场。未接入正式关卡。

## 复用与适配

- 继承正式 `fire_extinguisher_system.gd` 的 MultiMesh 烟团、邻近团块融合和透明排序；每团 7–13 个圆形细团、32px/m 像素轮廓、颗粒阴影沿用正式 Shader。
- 白盒适配器关闭罐体生成、覆盖判定和 AI 影响，仅负责外观。正式灭火器的控制器与 Shader 文件没有修改。
- 试用 Shader 从正式公共源码复制，仅增加 GPU 密度／速度纹理采样：密度控制烟团大小和透明度，速度提供局部偏移。它是随流场变化的烟团显示，没有新增完整粒子轨迹求解。
- 128 个烟团、两层摆放，使用原有外缘与填色两遍绘制，保持在正式系统每个实例池 192 的上限内。关闭试用显示时停止烟团上传。
- 原生 3D 材质接收实际场景灯光与阴影；不改已认可的普通场景后处理。显示提示移回项目的 640×360 逻辑画布范围，避免与左下时间倍率文字重叠。

去除明确的场采样适配段后，试用公共 Shader 与正式公共源码逐字一致；校验和及恢复比对记录在证据目录的 `production_style_provenance.json`。正式控制器及三份正式 Shader 的 Git 差异为空。

## 验证与证据

Godot 4.7.1、Forward+/Vulkan、RTX 5070 Ti、私有静音 WASAPI，后台真实 GPU 绘制。`tests/interactive_gas_whitebox_test.gd` 在 640×360 和 1280×720 世界视口下各通过 34 项检查，输出画幅均为 1280×720。

覆盖实际弹道、走动、现有飞扑翻滚、烟道回填、实体内零密度、有限速度／密度、完整重建与资源释放；新增 V 键互斥切换、GPU 空密度输入让烟团消失、逐灯画面变化与前景不透明遮挡检查。前景中心开／关烟团的 RGB 最大误差两种模式均为 0。

模拟参数沿用增强版。固定弹道区域密度总量仍为 303.703 → 4.684，24 步后回填至 42.973；这证明外观适配没有替换原有模拟。画面已单独检查烟团轮廓、颗粒阴影、实际射击、走路和翻滚录制。

证据目录 `.runtime/interactive_gas_extinguisher_20261116/`，关闭像素化的对照在 `native/`。包含实际 Camera 静帧、三段动作半速预览 `interactive_gas.webp`、原画幅视频、原始 `frame_times.csv`、`result.json` 和 `summary.json`。本轮以前的局部源码存于 `previous_source/`。

有效日志位于 `.runtime/interactive_gas_20261116/`：

- 默认模式 `extinguisher_test1.log`，引擎 PID 51828，34 项通过，退出 0。
