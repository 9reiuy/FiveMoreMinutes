# 冲刺彩色残影与反馈增强

## 改动范围

保持 168px、0.14s、0.8s、16px 胶囊半径、携带槽伤害及直接击杀刷新规则。未新增全屏模糊、时间减速、摄像机缩放或玩家染色。

- 起步：短促局部光圈，身体前倾幅度增加；仅显示节点做轻微拉伸／压缩，结束和取消还原。
- 位移：六段青绿、蓝、紫、洋红、橙黄错位人物残像，读取已有角色捕获纹理；交替偏移 3px，分段变色并消散。池固定为六个 Sprite3D，无额外捕获视口、AI 或角色副本。
- 到达：拖尾收束与局部扩散圈；视觉尾段延长至 0.24s，不延长位移、无敌或伤害窗口。
- 命中：继续使用原小停顿与轻镜头反馈；击杀时镜头反馈略加强，刷新圈扩大并改青绿色，播放独立 100ms 升调提示音。新增音效走现有 Characters 音轨，不新增独立音频系统。
- 保色：与血迹等特效相同，使用指定颜色的语义保色；只匹配五种残影颜色及其暗部，允许 Compatibility 的少量颜色误差，不采用全场景饱和色豁免。其余世界仍按原调色板处理。
- 遮挡：保留深度测试，残影沿用正式角色的参考深度平面并同步位移，不设穿墙显示。透明度以覆盖率消散，避免混色破坏保色标记。清空时释放捕获纹理引用。

## 未通过／尚未验证

- GPU 进程退出仍出现两个纹理释放诊断和窗口锚点警告；本轮不宣称运行完全无警告。
- `sfx_integration_test` 的卧室手机脚本在独立脚本入口中报 SettingsManager 标识符未找到，继而对话音效断言失败，不计通过；正式 Main 的冲刺刷新事件验证通过。未修改无关卧室逻辑。
- 全程静音，因此新提示音的音量和听感需正常游玩验收，未声称已听音验收。
- 未完成所有分辨率、所有家具／墙体遮挡位置的动态图验收，也未进行专门性能采样。不以截图录制帧耗时作为性能数据。
