# 0-1 彩蛋汽车：车身细化、轮拱修正与做旧

用户反馈初版形体像积木、轮子陷进车身。本次重建这一辆彩蛋汽车的视觉网格，保留西侧长路、摆放、灯光、火痕、碰撞与关卡连接。只更新工程，没有导出。

## 形体与材质

- 以连续纵向截面重建前低后高的楔形车身；侧板、翼子板和肩线相连，轮拱是真正留空的几何，而非在整块侧板上覆盖轮胎。肩线、车顶、轮胎侧壁和保险杠保留有限的倒角。
- 修正前后轮中心及轮距。四个轮拱的侧壁留出间隙，防擦条和侧裙在轮拱前结束，轮胎、轮毂不会被完整侧板或长条饰件挡住。
- 四个前灯采用窄边框、内退反光槽、玻璃和竖向棱纹；降低前缘厚度。增加前格栅、门锁和把手、后视镜支架、雨刷、小开口侧窗、鸥翼门缝、三角后窗、尾部百叶、分格尾灯和排气口。
- 胎肩与胎侧分开塑形；涡轮轮毂有叶片厚度、内凹轮盘、中心盖和螺栓，胎面有纵向沟槽及短斜槽。
- 沿用已有拉丝金属贴图，加入固定模型坐标的划痕、下沿道路尘土、把手附近油污、黑塑料褪色、玻璃边缘污痕、轮毂刹车灰和轮胎磨损。没有为不锈钢添加大片剥漆或重锈。
- 做旧覆盖按每米32格取样，纹理保持Nearest。没有全局调色、排线或随时间／屏幕移动的噪声，也没有改分辨率、相机、其他关卡材质或灯光参数。
- 缓存为一个ArrayMesh、9个材质面、23,808个三角形。远处的展示灯、火焰与烟仍按原逻辑停用，进入0-2后仍随旧区域卸载。
