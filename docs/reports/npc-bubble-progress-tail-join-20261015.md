# 气泡进度条与角标衔接

生长气泡将进度条与角标的蓝灰色用同色区域连通，连接层绘制在背景边框上方，消除底边黑色断缝。连接部分和角标内部与进度条共用横向倒计时裁切位置，扫过时同步消退。纯省略号提示保持原有同款气泡，不显示进度条。

气泡因屏幕边缘限制翻到说话人下方时，进度条随角标移至上缘，文字留出独立空间，避免用连接色穿过文字。

NPC 逻辑 97 项检查及接待交互范围回归通过；实际 Main GPU Camera 流程 19 项检查通过。已查看实际截图，连接处连续。窗口屏幕外启动并最小化。旧有锚点与退出纹理清理诊断不在本轮修复范围。
