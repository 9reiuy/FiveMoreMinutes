# 尸体与拖痕的位置连接修正（2026-10-14）

用户反馈的是尸体与拖痕之间的空间空隙。上一轮缩短生成等待未解决这项问题。

## 原因及改动

出血跟随器取敌人根节点的碰撞坐标；倒地角色旋转后，经正式 3D 角色投影显示，其躯干不在这个点上。当前场景的可见躯干对应地面点与碰撞根节点相差约 19～20px。

角色投影桥现在利用已有的不透明纹理边界缓存，取得当前躯干的可见中心，将对应画面点投射回本层地面。敌人向出血跟随器提供此点；初始化、后续出血及拖痕均使用同一地面位置。拖痕由身体下方向移动路径后方延伸。未移动碰撞根节点、修改伤害或死亡受力。

角色静止时，镜头投影变化或肢体收敛不会单独生成新拖痕；停下仍提交此前真实移动的未完成尾段。保留墙门与楼层裁剪、单像素纹理、原宽度和生成数量上限。
