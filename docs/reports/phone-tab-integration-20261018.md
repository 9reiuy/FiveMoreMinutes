# 游戏内 Tab 手机正式接入

日期：2026-10-18。依据已确认 Q1–Q13 实施；正式 Main 入口使用，不依赖预览开关。

## 最终行为

- 卧室、塔罗大厅、正式 3D 楼层按 Tab 打开左侧同一部手机；Tab 可从任何页直接收起。原卧室手机与购物入口接到同一部手机。
- 开始界面保留原设置；手机关闭时 Esc 仍为原暂停菜单。旧属性卡本轮没有快捷入口。
- 首页四宫格：讯息／电话／音乐／购物。底部设置与返回，Q 为左软键，右键／Esc 逐级返回。
- 浅蓝灰几何背景、12px 中文像素字体、页面标题／游戏时间／电量、三条常显音量滑杆；六项设置仍即时生效并保存。
- 实际鼠标移动悬停选中，左键确认／拖动。WASD／方向键与鼠标共享选择；静止鼠标不抢走键盘选择。方向盘按住倾斜下压，确认和软键分别反馈。
- 手机随鼠标小幅缓动，拖动、滚动及按住操作时冻结。屏幕与实体键点击使用实时投影坐标。
- 3D 手机暂停战斗与计时，镜头约 0.4 秒拉近并将角色置于右侧；关闭和中断恢复。卧室时间、配送继续推进。
- 讯息读取真实存档并保留特殊消息规则；电话说明占位；音乐控制现有 BGM。楼层购物只读，卧室购买继续调用原扣款、库存、限购和配送后端。
- 沿用银白实体 3D 机身及环境光／反射桥。环境反射为低清近似，未添加世界几何投向机身的完整阴影。

## 实现位置

`scripts/ui/game_phone.gd` 管理单实例、暂停原因、输入隔离、相机权重和环境捕获生命周期；Main 统一路由。`phone_settings_screen.gd` 负责可读布局和交互，`phone_apps_model.gd` 读取真实应用数据，`flip_phone_shell.gd` 负责独立的开合、轻摆及实体按压。

大厅与正式楼层把手机镜头修饰纳入原相机权威，暂停时只刷新展示。卧室保留旧后端并隐藏旧机身。特殊消息的原故障效果转发到新手机层，原 shader 同步修正为当前引擎的屏幕采样接口。

## 实测与范围

- `tests/phone_apps_ui_test.gd`：38 项通过，退出码 0；包括四宫格边缘导航、真实悬停、设置、消息规则、音乐所有权、原购买后端、实际 GUI 单次购买和滚动不误买。
- `tests/phone_tab_delivery.gd`：实际 Main + GPU，32 项通过。覆盖卧室与大厅 Tab、右键、Q、按住回弹、真实斜屏拖动、购物权限、时间、镜头恢复、对话模态优先级、独立暂停原因与特殊效果清理。
- `tests/phone_tab_full_dungeon_test.gd`：完整正式楼层实际 GPU，31 项通过。Main 正常生成 16 个房间、12 名敌人，完成初始电梯流程；使用引擎真实 Input 单例按下／释放事件，不以视口事件代替物理按住状态。验证 W 按住不移动、右键不扔枪、左键跨 Tab 收起不射击、松开恢复原输入门闩、再次按下可正常射击，以及实际场景切换中断清理。
- GPU：RTX 5070 Ti，GL Compatibility，输出 1920×1080、逻辑界面 640×360。相机实际 FOV 40 → 28.5714 → 40，角色横向位置约 68.5%。窗口始终最小化且无焦点。
- 60 帧短样本（另有 30 帧预热，无 PNG 回读，60 FPS 限帧）：大厅空闲关闭手机 median 16.729 ms / P95 18.674 ms；打开手机并暂停世界 median 16.674 ms / P95 17.676 ms。这比较的是两种实际使用状态，不能视为手机独立开销或战斗性能验收。

完整楼层实际 FOV 35 → 25 → 35。关闭后恢复原镜头权威，允许正常的鼠标 lookahead 继续推进，而不是锁死打开前坐标。完整楼层测试中首入约 14.22 秒，包含生成、资源准备及原轿厢流程，不等同于加载黑屏耗时；本轮未改换层时长目标。未使用空楼层测试代替正式生成。

日志与证据在 `.runtime/phone_tab_20261018/`，完整楼层专项位于 `.runtime/game_phone_full_dungeon_20261018/`，以该目录 `gpu_console.log` 和 `results.json` 的 31 项零失败为成功证据。应用测试日志干净；真实场景日志仍有既存锚点警告及退出时 2 个纹理 RID 残留，每个 6888 bytes，完整楼层还记录了 4 个 ObjectDB／2 个资源的退出诊断，未把这些称为零错误。Headless 完整楼层的 dummy 材质诊断与真实 GPU 运行分开记录。额外重启曾出现原生 -1 退出且没有断言输出，这些尝试没有计入通过结果。

首次资源／shader 缓存可能造成额外停顿；镜头已改用真实起始时间，避免卡顿后继续延迟抵达。开合短动图标明为预热后正常速度，不代表冷启动耗时。

## 输入隔离补充

完整物理输入回归发现，消费 UI 事件不能阻止全局 Input 轮询，原武器还直接轮询鼠标左键。手机现在同时释放玩法动作，并通过玩家原有的 `presentation_pointer_gate` 组合原检查。跨越关闭仍按住的按键／鼠标在松开前隔离；松开恢复原门闩，避免误射与永久锁住。没有修改武器攻击数值或通过隐藏武器规避输入。
