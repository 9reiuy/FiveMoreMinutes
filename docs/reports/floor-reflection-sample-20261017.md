# 按材质反光与模糊倒影：小样验收

后续状态：用户已认可新版并授权推广。正式接入及新一轮验收见 [推广记录](floor-reflection-rollout-20261017.md)；下文是小样阶段的历史记录。

已完成用户授权的小样，尚未推广至正式入口。保留了原有五类地板的图案和像素密度，只在样例中增加材质受光与模糊倒影。

## 最新修订：更宽的亮斑与细碎光泽

用户审阅初版后明确要求加强反光。此轮只调整表面高光：将单一窄高光改成宽磨砂亮斑、较亮核心和稀疏微表面高光。颗粒以世界坐标固定，不使用时间随机噪声；保留真实灯光衰减与阴影。瓷砖和大理石增强明显，水磨石更弱、更碎，木材很淡，地毯保持零高光。没有提高测试灯能量、环境亮度，也没有增加反射相机或更新频率；人物／家具倒影的强度和模糊参数仍沿用初版。

最终证据为 `camera_gloss_v2/`、`gpu_gloss_v2.log` 与 `delivery_gloss_v2/`。五类材质对照左侧为上一版，右侧为新版，同一次实际 Main Camera 运行内切换高光分支；原受光画面另存于 `*_before` 原始序列。截图及正常速度动图仅按原始时间戳裁切、最近邻缩放和加标签。使用同一自然办公房间与临时暖灯，未声称为五个正式房间的生产接入结果。

本轮 GPU 15 项检查、针对性无界面 18 项断言通过。遮挡验证初次出现单点采样失效：目标像素落在低分辨率动态角色的透明处。改为保留真实实体遮挡检查，并额外只隐藏反射通道的玩家身体，验证其投影邻域确实发生像素变化；最终真实身体贡献 47 个像素。没有以放宽颜色阈值代替实际角色存在的验证。血迹开启／关闭反射覆盖均为 5247 个橙色像素；暂停、移除视口、恢复材质与遮罩、后台最小化通过。最终无脚本／着色器编译错误，仍有原先的根证书与退出资源诊断。`camera_gloss_v1/` 含初次单点检查失败，不作为最终通过证据。

本轮短时性能：RTX 5070 Ti、Compatibility、世界 640×360、输出 1920×1080、反射 256×144／最高 15Hz；各取 120 帧有效样本，计时不读回图片。关闭／开启的中位帧耗时为 15.467／15.723ms，P95 为 29.908／29.933ms，峰值为 31.983／32.423ms。该对照是关闭全部样例效果与开启新版，不是单独测高光数学计算的 GPU 时间；短样本差值不能外推为持续交火开销。当前仍未达到稳定 60 FPS 的验收线，中档实机仍待验收。

此轮只重跑与高光和样例生命周期有关的检查。下文的 3140 项为初版历史回归，未将其冒充本轮全量重跑。正式推广继续等待用户认可新版。

## 画面与实现范围

- 瓷砖、大理石：较明显的局部高光和模糊人物／家具倒影。
- 水磨石：较弱且更碎的反光。
- 木地板：很淡的反光与倒影。
- 地毯：没有可辨认倒影，不加镜面高光。

对照取自正式 Main 入口及实际游戏摄像机。同一自然生成的办公房间临时换用各房间现有材质，家具、夜景、相机与灯光保持同一套条件。另有一盏测试暖灯用于观察受光变化，未修改生产灯光配置。不是把五个不同真实房间宣称为相同条件，也没有重画参考图作为游戏输出。

一个共享 World3D 的反射视口绘制实际场景，不复制 AI、碰撞、角色计时或战斗系统。家具直接使用真实几何。像素角色保留原捕获纹理，反射通道将主相机颜色平面投到角色原有空间参考面，再由反射相机渲染；主画面的角色朝向、材质引用和深度更新仍由原 bridge 控制。

地板只接收该通道，不递归反射自身。排除 HUD、地面血迹、瞬时特效与室外城市；保留室内实体遮挡。纹理采样的模糊仅作用于倒影，主画面像素化设置不变。

## 性能与当前取舍

RTX 5070 Ti，OpenGL Compatibility，输出 1920×1080，实际世界视口 640×360，主循环上限 60 FPS。倒影视口 256×144、最高 15Hz，单个局部反射相机，保留现有主画面光照与阴影，不分配第二套位置灯阴影图集。两组分别取 150 个 process_frame，弃前 30 个，剩余 120 个；采样不保存 PNG。固定夹具包含两名受控移动者及同一房间原有场景，不能代表持续交火压力。

| 指标 | 关闭 | 开启 |
| --- | ---: | ---: |
| 中位帧耗时 | 15.474 ms | 14.899 ms |
| P95 | 30.121 ms | 30.836 ms |
| 峰值 | 32.815 ms | 33.463 ms |
| 中位绘制调用 | 3302 | 3302 |
| 峰值绘制调用 | 3306 | 3846 |

反射提交端平均约 0.165 ms，不含独立 GPU 时间。第一轮 320×180／30Hz／独立位置阴影的实测中位约增加 5ms，已缩小范围、减至 15Hz、撤去第二套位置阴影。

最终中位值低于关闭值是短样本调度波动，不能解释成开启倒影提高帧率。P95 约增加 0.715ms，峰值约增加 0.648ms；当前整体仍未达到此前稳定 60 FPS 的 99% 帧耗时标准。测试时另有一个既有 Godot 实例存在，未关闭用户进程，数据不是空载独占环境。中档实机、密集交火和长时间游玩仍待验证。

性能优先的可见取舍：角色本体保持正常更新，倒影最高 15Hz；快速移动时倒影可能有轻微阶梯变化。反射的颜色视图不额外渲染位置灯阴影，室外、血液和瞬时特效不纳入倒影，背光下倒影与主画面亮度可能略有差异。跨房间及最终全楼层／大厅接入留待用户认可小样后完成，不能将本轮称为完整推广。

## 相关修复和日志

现有光照刷新读取可缺省的 `dither_origin` 时，`get_meta(key, null)` 在当前引擎会打印缺失键错误。已改为先 `has_meta`，不改变材质选择。小样自己的变体显式标记为已定稿，防止旧刷新覆写。

旧光照测试把现行字符串缓存键当作原材质对象，发生 Object 与 String 比较异常，尚未执行到断言结尾。测试改为从现有 `dither_origin` 取原对象，并核对现行家具／非家具的遮挡参数分支；没有为过测恢复旧实现。

最终 GPU 无脚本或着色器编译错误，仍有现有根证书存储读取、Control 锚点和 GPU 退出纹理 RID／RenderingServer 清理诊断；部分无界面测试有既有 ObjectDB／资源退出诊断。早期着色器适配失败、尚未包含玩家的录制与初始旧测试失败不作为最终通过证据。

回归清单在 `tests/floor_reflection_manifest_20261017.json`；可交给现有 `tools/run_regression_suite.ps1 -Mode Headless -ManifestPath tests/floor_reflection_manifest_20261017.json`。GPU 交付入口为 `tests/floor_reflection_sample_delivery.gd`，图像包装工具为 `tests/support/build_floor_reflection_delivery.py`。
