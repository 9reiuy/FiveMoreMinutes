# 玩家近战宽扇形与像素挥击 — 交付记录

日期：2026-10-21。用户确认全部设计问题后明确启动；单智能体实施，未提交/推送 GitHub。现有其他未提交修改保留。

## 实现结果

- 正式玩家球棍为 **56 游戏像素 / 160°**，书本为 **44 / 150°**；地格为32像素。
- `lucille_weapon.gd`以唯一物理时钟驱动前摇、连续扫击、恢复；不再用一个延迟计时器整片结算。每次攻击的目标登记贯穿所有角度切片。
- 前摇可修正朝向，主挥击锁定角色和武器朝向；中心跟随玩家真实位置。不增加自动前冲。武器失活、换枪、翻滚、翻越、踢击、死亡、失去控制和楼层令牌变化取消旧攻击。
- 正式伤害/暴击仍由 `resolve_player_hit` 结算；伤害、攻击间隔、击退、血色、拳头和踢击参数未改。新增玩家专用范围配置，敌人继续使用旧30px范围。
- 实体墙、门镜像和大件家具阻挡；低家具依据现有类别允许越过，也仍可被击中。耗尽射线迭代预算返回阻挡，而不是放行。
- 球棍为暖色风压弧，书本为短促纸页条带；使用真实3D平面、1游戏像素固定栅格、普通深度测试，不关闭墙体遮挡，不新增捕获视口，不扩大角色捕获纹理。
- 每种近战武器至多一个复用显示载体，属于 `floor_root`。楼层暂存、清理与销毁会同步处理显示。主挥击和身体倾斜直接读取同一快照，没有第二个独立Tween。
- 每次挥击只发一次汇总冲击。球棍40ms、书本20ms；合并敌人死亡时的全局重反馈，不叠加多目标停顿。保留逐敌人的血液、受击与击退。

## 技术与性能边界

- Godot 4.7.1 Compatibility，实际显卡 NVIDIA RTX5070Ti。正式脚本解析通过；GPU日志无运行期脚本错误或着色器编译错误。
- 受控攻击物理步CPU中位数0.409ms，P95为2.050ms；包含范围查询、姿态更新和弧面参数提交，不含PNG读回。该结果不是完整战斗帧耗时或中档显卡60FPS验收。
- 全局停顿和CPU统计使用不同的受控测试：真实多杀停顿由world测试测量；GPU动作序列人工固定60Hz、暂停自主AI/世界时钟，不据此宣称验证过完整实战节奏。
- 每次活动快照有33条有界射线裁切可见弧面，家具候选上限128；敌人先做距离拒绝。没有新增动态光源、阴影灯、SubViewport或全屏后处理。
- 退出时仍出现与10月20日准星/刘海GPU基线一致的2张6888字节纹理释放警告；部分受控测试还出现ObjectDB/资源退出警告。它们不是脚本断言失败，但本轮不声称引擎退出资源警告已清零。
- 尚未执行：中档GPU性能、60秒无人干预实战采样、所有房型/窗户破坏的逐镜头组合、全仓库全部回归。没有自动提交、上传或修改正式存档。
