# 敌人瞄准提示、弹反与楼层电闸（2026-10-22）

## 本轮红线修订

- 最终确认规则：自动武器每个弹匣只进行一次 0.5 游戏秒前摇，末尾 0.12 秒锁定目标；连射期间不重复红线。短暂丢失目标也不重置同一弹匣；打空并换弹后才进行下一次前摇。原有射击间隔及随机浮动不变。
- 线宽由 1.0 渐增至 3.5 逻辑像素；浅红、低透明度渐变为深红、高透明度。绘制在清晰 HUD 层，不进入调色板或像素化处理。
- 使用未被碰撞回缩的视觉枪口，而非会在附近家具间跳变的弹道枪口；在相机和角色常规更新后采样一次，世界空间短平滑，再统一绘制。
- 每个敌人 ID 每帧最多一条；楼层 HUD 有独占标记、暂存隐藏与销毁清理。实墙阻断，死亡、取消瞄准和加载期间隐藏。
- 实际发射时触发一次原创 95ms 双谐波短铃声。霰弹多颗弹丸不重复响；音量 -12dB、最多四重叠音，保持清脆，不随慢动作降低音高。原枪声保留。
- 敌人默认灰色单层像素描边；被玩家瞄准、或进入当前近战武器的有效扇形与可达范围时转白。近战预览沿用实际挥击采样及障碍查询，包含拳头、球棍和书本。玩家始终为白色描边；敌人死亡移除描边。不另叠一层武器白边。

## 同次集成的功能

- 球棍／书本有效挥击阶段弹反敌弹，朝鼠标方向返回，保留来弹速度与伤害；不会额外叠加玩家暴击。一次挥击可挡多颗霰弹，仅触发一次主要反馈。
- 成功弹反或真实近身擦弹触发 0.6 现实秒、20% 世界速度；玩家移动与近战补偿时间缩放。成功后新一次左键可连续弹反；按住不提供自动连续弹反。擦弹按真实受击胶囊计算，单弹仅一次，且有触发冷却。
- 楼层电闸优先机房，备用储藏／档案／打印区域。接近 E 在“断电／送电”间切换；子弹命中后本层不可修复。仅关固定室内照明与灯具自发光，不关窗外、手电及枪口效果，不改变 AI 视野。
- 新层重置，失败回滚恢复旧层电闸；暂停、死亡、加载与离开场景接入现有时间权威及清理流程。
