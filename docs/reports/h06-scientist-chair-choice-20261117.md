# 1-1 监控室科学家与返回机库分支

已接入当前 H06 第一章。科学家坐在监控室 CameraChair 上，玩家进入房间后，椅子约用 0.95 秒转向房间，依次用现有气泡组件说“卷帘门我已经打开了”“不要开枪!”。演出真正打开监控室通往西翼的卷帘门，第一句话出现前门已完全升起；玩家仍可移动、瞄准和攻击。

科学家使用现有 `Scientist2.png` 分件和正常角色比例，没有生成新原画。椅子新增位于座位中心的旋转轴，避免导入模型的偏移原点使椅子绕人物公转；双腿各自绕髋部调整，显示中的髋部按实际 Camera 对齐真实座面。她没有武器或敌对 AI，但能被真实玩家子弹击中，死亡使用现有布娃娃与血液路径。

## 生死选择与预加载

只有这名监控室科学家的实际死亡决定分支，非致命伤不改变选择。

- 击杀：返回楼下仍使用原三名死者的位置、姿势和橙色血迹演出。
- 未击杀：返回时三人保持存活，按正常敌人奔跑速度沿机库通路跑进右侧彩蛋／隐藏房间，最后各自停在房间内。入口会打开，路线绕开机位并穿过楼梯下方，没有直接传送。通过后恢复楼梯的正常遮挡。

`staff_story` 保存本次流程的选择，随正常换区和死亡重试传递；新流程默认未击杀。逃生已完成时重试，三人仍在隐藏房间内。

返回场景会在选择前预加载，因此真正进入时会再次按当前选择确认演出，并复用原三个角色。旧血迹资源在加载阶段准备，幸存分支保持隐藏；预热结束也会恢复正确的血迹可见性。科学家退场时立即停止碰撞和受伤资格，气泡隐藏，随后按原预算清理节点。
