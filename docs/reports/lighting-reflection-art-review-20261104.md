# LIGHT-REFLECT-001-A｜第一阶段美术观察标准

2026-11-04（Asia/Hong_Kong）。本阶段核对了任务书、原始参考图和当前工程的照明入口。候选的画面结论以第二阶段的实际游戏 Camera 对照为准。[任务书](../plans/lighting-reflection-lab-20261104.md) · [原始参考图](../references/lighting_reflection_lab_20261104/user_reference.png)

参考图可借鉴的是空间层次。室内有冷蓝灰底光，近窗和过道局部较亮，桌柜侧面与窗侧暗区仍分得开。瓷砖接缝穿过明暗区，家具脚下有清楚的暗部，室外楼体退在更暗的背景。静态图足以判断这些关系。亮区中哪些是镜像、直射或材质高光，以及原图采用的技术，需要各自的动态证据才能区分。

用户实测反馈当前正式精简灯光版的混合战斗尖峰已解决，A 版以这一工作树状态为准。源码可见正式配置使用 Compatibility，楼层保留冷环境光、主方向光与形体补光。反射组件也保留按地面类型绑定的档位，办公室档位为零，部分瓷砖用途有更高反射。源码只能确认这些路径存在，各接收面的实际显示由 A 版实拍确定。旧慢帧记录保留其历史范围。[工程设置](../../project.godot) · [精简布光](../../scripts/dream/office_sparse_lighting.gd) · [地面反射档位](../../scripts/dream/floor_reflections.gd)

| 观察项 | 可验收的画面 |
| --- | --- |
| **物体反射** | 在瓷砖上选一个轮廓明显的柜体或桌脚。镜像能辨认出来源的轮廓或色块，其位置、方向和比例与地面平面及当前镜头相符。移动角色或家具时，镜像同步移动，接地处没有漂浮缝。移动镜头时，镜像按视角变化，地面上没有粘屏、明显跳位和残影。近处及远处各看一次。候选若受屏幕边缘或遮挡限制，保留触发画面并标为近似范围。 |
| **直射光与投影** | 窗光落点和方向能从开口追到地面。窗框、墙体和家具能切出合理的暗形，跨门槛、开关门或破坏遮挡后，明暗边界与当前几何相符。地面亮区体现受光范围，暗形体现遮光，只有能对应来源轮廓和位置的镜像计入反射。三者分别观察。 |
| **冷色空间与材质分区** | 窗口亮、通路清楚、墙边和家具下保留较暗区域。冷蓝灰底光把墙、地面和室外分开，亮处仍能辨认接缝。瓷砖可见较清楚的反射，粗糙地面更弱，地毯保持哑光。跨材质边界时镜像按接收面收止，地毯和木板保有各自纹理。 |
| **像素与战斗信息** | 在当前游戏镜头、像素化和调色设置下看通路、门洞、人物、掉落物及橙色血迹。亮面和镜像仍让这些信息一眼可辨，反射中的角色不会被误认成第二个目标。移动时观察细线和亮部是否闪碎，并看短暂枪口或机器人功能光是否冲掉地板和敌人轮廓。角色原画、血色和整体半调风格沿用基线。 |

最小审阅材料是同一房间、同一机位、同一像素与调色设置的 A/B 实拍。画面同时带窗、一个可辨认物体和两种地面接收材质。再给正常速度片段，依次展示物体或角色移动、镜头移动和一次原生遮挡变化。有 C 版时沿用同组条件。候选应标出真正用于观察镜像的位置，以及窗光和投影各自的检查位置。美术结论分别给出镜像对齐、照明与可读性判断，性能由独立配对测量交付。

当前交付为观察标准，试验范围限独立入口。
