# 左侧银白翻盖手机与环境效果小样

日期：2026-10-18。依据用户新增实体手机照片与“继续执行”指令完成本轮修订。仍是可操作小样；正式设置、暂停与卧室入口等待小样外观确认后推广。

## 本轮结果

机身改为照片中的银白长方翻盖比例：薄圆角上下壳、窄白色屏框、细深灰嵌槽、顶部镜头与听筒、厚方形铰链、白色圆盘及中心钮、左右四方键、三枚功能键及十二枚数字键。没有 Logo。保留完整背面和实际铰链旋转；数字区可越出画面，顶部镜头也允许按最终构图裁出。

手机从右侧移到左侧，基准位置为 `(16,6)`，旋转方向相应调整。完整 LCD 与七个操作键均在画面左半区域；预览场景切换栏移到右侧。保留此前修复的透明绘制余量与坐标正反投影，不能让高分辨率纹理改变实际机身尺寸。

仍使用 148×230 的真实中文界面。声音／画面六项设置、鼠标拖动、键盘、实体键、聊天滚动与原购买权威保持；屏幕加入微弱静态液晶暗角、列采样差异及自发光，不添加闪烁。

## 光照与反射来源

- 正式 3D 大厅／楼层：从真实 Main 当前世界读取环境光与最多四盏实际灯具，映射灯具类型、方向、位置、颜色、能量、范围和聚光角。3D 模式关闭原有两盏固定展示灯。
- 六个 64×64 子视口共享真实游戏 World3D，在玩家附近捕获环境；手机继续位于另一 World3D，因此不会把自己捕获进反射。每帧只更新一面，完成后静止停更；灯光／位置变化时重新采集。
- 机身和玻璃按反射方向采样低清环境；粗糙度决定模糊范围。画面内容仍为独立实时 LCD，玻璃反射叠加在其表面。
- 菜单与卧室为 2D 场景，采用手机及遮罩出现前冻结的实际背景作为环境近似，保留柔和展示灯。诊断明确标记 `fallback_2d`，不是重建的三维卧室灯光。
- 闭合后恢复原材料并释放环境桥、六面视口及世界引用。源场景离树但尚未销毁时同样自动停止；此生命周期测试发现的越树 Camera 访问错误已修复并复验。

这是来源真实的低清环境反射与局部灯光近似，不是光线追踪或精确平面镜。没有复制世界遮挡几何到手机世界，源场景投到手机上的遮挡阴影未实现；空间单位作 20 倍换算，未校准物理照度单位。没有修改原世界的灯光遮罩、主 Camera 遮罩或材质资源。

## 实景与量测

最终原始证据：`.runtime/phone_settings_sample_20261018/camera_silver_review/`，日志 `gpu_silver_review.log`。RTX 5070 Ti、Godot 4.7.1 GL Compatibility、输出 1920×1080／UI 640×360；自动窗口全程最小化、无焦点。

同一大厅场景中加入测试专用 OmniLight，保持能量、范围、手机姿态与 UI 不变，只切换暖／冷色。机壳边框二十个固定投影采样点的平均 RGB 差值为 **9.00/255**。测试灯随后删除，不改变正式场景资产。

默认直立玻璃的反射方向朝向剖切后近乎全黑的空间，因此入口与部分朝向不应凭空出现明亮倒影。另将真实上盖倾斜至 0.52 弧度，让反射朝向现有地板／家具，再以完全相同姿态切换环境反射开关；空白 LCD 区采样平均 RGB 差值为 **0.67/255**。这是细微反射变化，不应描述成强烈镜面倒影。六面更新计数及真实世界身份保存在 `report.json` 的 `lighting_evidence`。

初次冷缓存运行曾因新着色器编译导致两秒开盖等待期限不足；录制改为等待动画状态、六秒上限。最终动图为已有着色器缓存的运行，不代表冷缓存首开耗时；本轮没有作稳定 60 FPS 或完整游戏性能验收。
