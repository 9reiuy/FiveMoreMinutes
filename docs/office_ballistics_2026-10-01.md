# 3D Dream 弹速、射程与门窗穿透

## 已实施

| 项目 | 原有基础值 | 本轮基础值 |
|---|---:|---:|
| 三类枪弹速 | 715 px/s | 2500 px/s |
| 手枪射程 | 350 px | 1024 px / 32 格 |
| 步枪射程 | 500 px | 1536 px / 48 格 |
| 霰弹枪射程 | 220 px | 640 px / 20 格 |

玩家和敌人共用独立 3D Run 配置。开火间隔仍为 0.24 / 0.12 / 0.64 秒，伤害、散布、弹匣、换弹、敌人视野和前摇未调整。已有射程升级继续叠加，自定义 Run 基础参数按同一比例转换；跨层不重复乘倍率，旧 2D 资源数值和门碰撞行为保持不变。

实体弹丸仍是唯一命中权威。门受到原有伤害/冲击但不消耗子弹；玻璃受击破碎后子弹继续。门窗不占用原有敌人穿透次数。通过已命中记录防止重复伤害，同一物理帧继续扫掠未走完的距离。实墙、高家具和角色命中仍按原规则终止；低桌保留既有高度过滤。射程不会因穿过门窗重置。

贴墙时保留角色→枪口的首帧检测：即使枪口被摆到墙后，子弹仍被实墙截住；门允许穿过。查询次数有上限，异常堆叠不会无条件向前跳跃。

3D 拖尾使用实际本帧位移决定长度，出生时只显示弹头，后缘上限仍为 42 个源纹素。弹头锚点、56×11 图集、发光 UV、摄像机投影和正式枪口快照不变。至多缓存 43 张小型拖尾纹理，不逐粒子创建灯；沿用原六个枪口灯槽和命中反馈。

这些数值是针对本项目房间尺度的调校，不是 OTXO、Hotline Miami 或 Midnight Animal 的原版数值。研究记录参考：

- Midnight Animal 作者公开的后期实验版本仓库：https://github.com/spncryn/midnight-animal （未核实弹道数值）。
- 同类改作开发日志：https://somewhere-else.itch.io/1-900-cult/devlog/193431/the-november-surprise （描述有限寿命霰弹和门穿透）。

## 静音验证

- `3d_firearm_tuning_test.gd`：97 检查，0 失败。覆盖 Run 副本、玩家/敌人一致、开火间隔不变、射程升级、跨层幂等、旧 2D 不变。
- `office_ballistics_test.gd`：66 检查，0 失败。覆盖八方向门→玻璃→角色同帧命中、重复伤害、实墙/高家具阻挡、真实连续玻璃破碎、真实门受伤和保持挡人、贴墙首帧保护、全射程末端不被寿命截短、出生拖尾与正常世界接入。
- `office_firearm_integration_test.gd`：15 检查，0 失败。2500 px/s 下薄碰撞体扫掠、命中反馈类型/预算与清理。
- `random_floor_lifecycle_test.gd`：38 检查，0 失败。三层清理、延迟令牌拒绝及失败回滚。
- `office_muzzle_visual_test.gd`：通过。旧 2D 火光和 3D 火光/灯池检查。
- 本轮相关脚本均随目标场景解析/加载成功；改动文件和新文件空白检查通过。

## 实际画面与未完成项

正式应用的 Dream 显示入口、RTX 5070 Ti / Compatibility、Dummy 音频驱动已运行；三类枪及 Palette 画面位于 `.runtime/ballistics_review/`。捕获脚本已适配正式像素化包装层，并等待初始电梯出门结束后再移动至办公室。截图时暂停敌人，仅用于检查画面，不能代替移动交火手感验收。捕获确认枪口灯池仍为六槽。

`character_weapon_projection_test.gd`：Headless 107 检查中 5 失败；GPU 118 检查中同样 5 失败。四个对角方向的合成探针连续性和一个腾空高度断言，与此前 `.runtime/task018_character_weapon_projection_test.log` 的五项失败一致，本轮未修改角色投影桥/投影算法。不能把这些检查标为通过。

此前近距离墙门测试包含“门必须消耗子弹”等已过时假设，不能用于本轮门窗穿透验收；本轮使用新增测试验证真实门和玻璃，并独立保留实墙防穿透检查，没有通过删除新规则测试来制造通过结果。

尚未完成全部八方向移动交火的动态录像、完整敌人实战与预热长时间性能采样，因此不宣称手感/性能全面验收。捕获退出仍出现少量纹理/延迟资源释放警告；证书库、Wacom 和着色器缓存路径警告属于本机环境，未用退出码代替画面验收。
