# 性能与换层验收

请将同一版本的完整 FiveMinuteMore 工程及 Godot 4.7.1 Windows console 可执行文件复制到待测机器的 SSD。关闭其他游戏、录屏及 GPU 测试。运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\run_performance_acceptance.ps1 -GodotExecutable 'C:\Godot\Godot_v4.7.1-stable_win64_console.exe'
```

脚本顺序运行四骨架各 10 秒预热 + 60 秒交火、正式 Main 入口 600 秒连续游戏和至少三次换层、投影回归。1920×1080、固定 60 FPS、真实 GPU Camera 输出；保持生产 AI 与规则。测试辅助仅包括玩家无敌、选取自然敌人房间、对墙连续射击和自动获取换层工牌；不减少敌人生命、不冻结交火 AI。直接楼层夹具与 Main 连续流程各自报告，不合并为同一负载。

为避免占用屏幕，启动器使用小窗口启动，再由测试最小化窗口并通过真实 RenderingServer 显式请求帧；1080p 输出仍会检查。后台数据应标为后台渲染，不与前台呈现数据混称。当前 Windows Godot `--headless` 只用 dummy renderer，不能作 GPU/FPS 验收。

帧目标：至少 99% ≤18 ms，最大 ≤33.3 ms；加载黑屏常规 ≤1500 ms，首次进入 ≤2000 ms，出场 ≤150 ms。首次入口按真实 draw 中完全覆盖的首帧至第一帧解除覆盖计时；Main 转场整体耗时另行记录。换层黑屏使用生产 cover 报告计时，从帧预算单独计时。阶段交界帧另列并要求 ≤33.3ms，避免混入持续阶段统计或悄悄忽略。每层交火都必须满足玩家与敌方各至少十发、至少两名敌方射手。600 秒场景检查每次轿厢可见至少三秒，并通过真实移动输入检查轿厢内可移动。

结果 ZIP 包含硬件、驱动、内存、磁盘记录、原始日志、Camera 截图及退出码。每次运行和每项测试使用独立输出目录，失败仍保留本次证据，绝不复制旧结果。硬件查询失败会尝试注册表 CPU 与 nvidia-smi GPU；无法读取的字段为 null 并记录原因，不阻止测试。中档基线 RTX 3060 / Ryzen 5 5600 / 16 GB / SSD 必须由相应实机运行确认；本机或降低分辨率结果不能代替中档验收。

`-Quick` 仅检查启动与负载，600 秒与三次换层断言会失败，不可用于验收。`-SkipCombat` 仅重跑正式连续流程与投影。脚本将测试存档隔离在输出目录中。
