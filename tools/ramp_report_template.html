问题

现在的第 3 档是 #6E398B，那是品红紫 —— 偏冷、偏艳，读起来像魔法或能量，不像火焰余烬。 火焰冷却下去该是「暗红 → 酒红 → 褐紫 → 灰」，紫只能作为余烬里最冷最暗的那一端出现，而且必须是暖紫（带红调）而不是品红紫。

一个先说清楚的事：第 4 档在实机里看不见

逐档数了实机画面里各档颜色的像素数，第 4 档（消失色）六个方案全是 0。 原因是 BOUNDS 到 0.80 才进第 4 档，那时烟已经缩到出生的 17%、alpha 也开始淡出，肉眼根本捕捉不到。

所以真正决定观感的是前 3 档，第 4 档基本只在烟将死的一瞬间存在。选配色时重点看第 2、3 档。 （如果希望末段也有存在感，可以把 BOUNDS 从 [0, 0.18, 0.55, 0.80, 1.0] 调成 [0, 0.20, 0.60, 0.72, 1.0]，让后段提前。）

六个方案 · 完整色阶（每格 = 一个色阶时刻）

当前

#C27132 #EFCD4C #6E398B #3D3445

第 3 档品红紫，偏冷偏艳，不像火光。这就是要换掉的那档。

A · 余烬暗红最像火光

#D9762E #F2C548 #8E2F26 #3A3038

把紫整段换成暗血红，全程暖色，走的是真实火焰冷却的路径：高温黄 → 橙 → 血红 → 暖灰。余烬感最强，也最不会让人想到魔法。

B · 酒红紫折中

#D9762E #F2C548 #7E2C46 #40303F

保留一点紫的意向，但改成暖的酒红紫（带明确红调），末段收在紫灰。你最早说原版是「橙→红→紫→灰」，这一档最接近那个描述，同时不再像品红。

C · 高温白核最爆

#FFF0A8 #FFB03A #C93A22 #3D3445

第一档接近白热，枪口爆闪感最强，然后迅速掉到橙黄、赤红、冷灰。整体最亮最抢眼 —— 如果你嫌现在的烟太闷，选这个。

D · 橙红余烬

#FF9E3D #FFC65C #A83A2C #3D3445

整体更「橙」，亮黄退到第二档当高光，红收到暗部作砖红。比 A 亮一档，比 C 收敛，属于稳的选择。

E · 暗紫压暗最保守

#C27132 #EFCD4C #4A2B52 #3D3445

只把紫压暗去艳，其余完全不动。注意：实测这一档在画面里只有 0 个可辨认像素 —— 太暗，缩小的烟团上基本融进背景了。改动最小但收益也最小。

第 3 档特写（横向滚动，3 倍放大）

从左到右：当前 / A / B / C / D / E。这是差别最大的一档，也是你说的「不像火光」的那一档。

选好之后怎么落地

  • 改 scripts/dream/muzzle_smoke.gd 里的 RAMP，把 4 个 Color("...") 换成你选的那套即可，其他都不用动。
  • 如果选了 A 或 B，建议顺手微调 BOUNDS：现在第 3 档从 55% 寿命才开始，而那时烟已经很小。 改成 [0.0, 0.18, 0.48, 0.75, 1.0001] 能让冷却色更早登场、看得更清楚。
  • RAMP 现在是 var 而不是 const，采集脚本支持 --ramp=#XXXXXX,#XXXXXX,#XXXXXX,#XXXXXX， 以后想再比配色直接跑采集就行，不用改代码。
  • 回归测试不受配色影响：muzzle_smoke_reach_test 6/0、muzzle_smoke_direction_test 30/0、muzzle_smoke_motion_test 6/0、启动 0 错误。
