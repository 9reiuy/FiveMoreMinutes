# 四骨架正式接入验证

日期：2026-10-01。单智能体执行，所有运行使用 Dummy 音频驱动。

## 接入结果

- 正式场景 `scenes/dream/Dream3D_RandomDungeon.tscn` 使用共享骨架世界实现；主程序原有接待→正式游戏入口不变。
- 原生 GDScript 按种子构建房间尺寸、连接、嵌套、镜像、家具功能组合和可选吸烟室。四类在重试前等概率选定，不循环预览地图，不调用 Node，不强套旧五种轮廓。
- 静态规则通过预加载脚本随导出包含；运行时不读取预览 JSON。独立试玩仍可查看此前已检查的 JSON。
- 连续玻璃与布局适配供正式/试玩共用；玻璃整段碰撞、破碎状态和逐地格边界同步。
- 固定样板保留原生成路径，旧 2D 未接入。`use_native_office_skeletons=false` 保留旧五轮廓回退能力。失败候选不静默换型，生成失败沿用跨层事务回滚。
- 新布局、玻璃组及家具计划纳入失败回滚快照；正式场景不含预览切换控件。
