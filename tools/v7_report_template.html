顺带修的一个可见度问题

上一轮发现第 3 档（现在 #8E2F26 暗血红）在实机只有 99 个像素 —— 因为 BOUNDS 要到 55% 寿命才进第 3 档， 那时烟已经缩得太小。这次把 BOUNDS 改成 [0, 0.18, 0.48, 0.75, 1.0001]，冷却色提前登场。 另外 RAMP/BOUNDS 从 const 改成了 var，采集脚本可以用 --ramp=#XXXXXX,#XXXXXX,#XXXXXX,#XXXXXX 直接换配色实拍，不用改代码。

接下来还能对齐参考的点

  • 参考图白点似乎没有可见描边（深色地板上白点边缘很干净）。如果实际游戏里也想要无描边的白点，可以把白层的暗色拷贝 alpha 降到 0.35 左右，或干脆跳过 —— 一行的事。
  • 参考白点的间距比我的略密。如果想让它们更聚拢，把 WHITE_REACH_MAX 1.30 → 1.05 即可。
  • 火光烟的形态这轮没动（你之前确认过「火光是对的」），只换了配色和它登场的时机。
